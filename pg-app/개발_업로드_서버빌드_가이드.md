# 개발 → FTP 업로드 → 서버에서 빌드·실행 가이드

> Cursor에서 개발 → FTP로 업로드 → 서버(otlpay)에서만 빌드·실행하는 흐름입니다.

---

## 1. 워크플로우 요약

| 단계 | 하는 일 |
|------|----------|
| 1 | **Cursor**에서 코드 수정 (Windows) |
| 2 | **FTP**로 pg-app 폴더(또는 변경된 파일)를 **서버에 업로드** |
| 3 | **서버에 SSH 접속** (PuTTY) |
| 4 | 서버에서 **빌드**: `gradle wrapper` 후 `./gradlew bootJar` (또는 이미 올려둔 gradlew 사용) |
| 5 | 서버에서 **실행**: `java -jar build/libs/pg-app-0.0.1-SNAPSHOT.jar` |
| 6 | 브라우저에서 **http://서버IP:8080** 접속 |

Windows에는 **JDK 설치 불필요**. 서버에만 Java 17 있으면 됩니다.

---

## 2. FTP 업로드 시 올릴 것

- **전체** `pg-app` 폴더를 서버 한 폴더(예: `/root/pg-app`)에 업로드해 두면 됩니다.
- 또는 **변경된 파일만** 업로드해도 됩니다 (그때는 서버에서 해당 경로에 덮어쓰기).

---

## 3. 서버에서 빌드·실행 (한 번만 설정)

### 3-1. 서버에 Gradle Wrapper 넣기

서버에 **gradle-wrapper.jar** 가 없으면, 한 번 만들어 둡니다.

**방법 A**: Windows에서 Gradle을 설치한 뒤, `pg-app` 폴더에서 `gradle wrapper` 실행 → 생성된 `gradle/wrapper/gradle-wrapper.jar` 와 `gradlew` 를 FTP로 서버에 올립니다.

**방법 B**: 서버에 Gradle 설치 후 wrapper 생성:

```bash
# 서버에서 (Ubuntu/Debian)
sudo apt install -y unzip
cd /root
# Gradle 8.7 바이너리 다운로드 (또는 SDKMAN 등으로 설치)
# 설치 후
cd /root/pg-app
gradle wrapper
```

이후에는 서버에서 `./gradlew bootJar` 만 사용하면 됩니다.

### 3-2. 빌드

```bash
cd /root/pg-app
./gradlew bootJar
```

생성 파일: `build/libs/pg-app-0.0.1-SNAPSHOT.jar`

### 3-3. 실행

```bash
export DB_PASSWORD='line2025!@'
nohup java -jar build/libs/pg-app-0.0.1-SNAPSHOT.jar --server.port=8080 &
```

## 4. DB 수정 방법 (PostgreSQL)

서버 DB는 **PostgreSQL** 이라 **phpMyAdmin은 사용할 수 없습니다.** (phpMyAdmin은 MySQL/MariaDB 전용입니다.)

### 4-1. 서버에서 직접 (psql)

```bash
sudo -i -u postgres
psql -d pgdev -U pgadmin
```

접속 후 SQL 입력. `\q` 로 종료.

### 4-2. PC에서 접속 (권장)

Windows PC에 **클라이언트**를 설치하고, **서버 IP + 포트 5432** 로 접속합니다.

| 도구 | 설명 |
|------|------|
| **pgAdmin** | PostgreSQL 전용 GUI. https://www.pgadmin.org/ 에서 다운로드. |
| **DBeaver** | DB 종류 무관. https://dbeaver.io/ 에서 다운로드. PostgreSQL 선택 후 서버 IP, DB pgdev, 사용자 pgadmin, 비밀번호 입력. |

**주의**: 서버 **방화벽**에서 5432 포트를 열어야 PC에서 접속 가능합니다. 보안이 걱정되면 **SSH 터널**로만 접속하는 방법을 쓰는 것이 좋습니다.

### 4-3. 서버에 웹 기반 관리 도구 설치 (phpPgAdmin 등)

PostgreSQL용 **웹** 관리 도구는 **phpPgAdmin** (PHP 기반)이 있습니다.

- 서버에 **PHP + Apache/Nginx** 가 있으면 phpPgAdmin을 설치해 웹에서 DB를 조회·수정할 수 있습니다.
- 설치 절차는 서버 OS와 웹 서버에 따라 다르므로, 필요하면 "Ubuntu에서 phpPgAdmin 설치" 로 검색해 진행하면 됩니다.

---

## 5. 정리

- **개발**: Cursor (Windows)  
- **전달**: FTP로 서버에 업로드  
- **빌드·실행**: 서버에서만 (Windows에 JDK 불필요)  
- **DB 수정**:  
  - **psql** (서버에서),  
  - **pgAdmin / DBeaver** (PC에서 서버 DB 접속),  
  - 또는 **phpPgAdmin** (서버에 웹으로 설치)  
- **phpMyAdmin**: MySQL용이라 이 서버(PostgreSQL)에는 사용 불가. 대신 **pgAdmin, DBeaver, phpPgAdmin** 중 하나를 쓰면 됩니다.
