# gradlew "지정된 경로를 찾을 수 없습니다" 해결 & 실행 방법

`gradle-wrapper.jar` 파일이 없어서 **.\gradlew.bat** 이 실패하는 경우입니다. 아래 **방법 1** 또는 **방법 2** 중 하나로 진행하세요.

---

## 방법 1: Cursor에서 바로 실행 (가장 쉬움)

Gradle 없이 **Cursor가 Java로 직접 실행**하는 방식입니다.

1. Cursor에서 **pg-app** 폴더가 열린 상태에서, 왼쪽 파일 트리에서  
   **src/main/java/com/pg/PgAppApplication.java** 를 엽니다.
2. **PgAppApplication** 안의 `main` 메서드 옆이나 위에 있는 **Run | Debug** 버튼(▶)을 클릭하거나,  
   파일 안 아무 곳에서 **우클릭 → Run Java** 를 선택합니다.
3. **실행이 안 되거나 DB 연결이 필요하면**:  
   **Run → Add Configuration** (또는 .vscode/launch.json) 에서 **Program arguments** 에  
   `--spring.profiles.active=local` 를 넣고 다시 실행합니다.

이렇게 하면 **gradlew 없이** 로컬에서 앱이 실행됩니다.  
브라우저에서 **http://localhost:8080** 접속 후 **admin** / **admin1!** 로 로그인하면 됩니다.

---

## 방법 2: Gradle 설치 후 wrapper 생성

PC에 **Gradle**을 설치한 뒤, 프로젝트에서 **gradle wrapper** 를 만들어서 **.\gradlew.bat** 이 동작하도록 합니다.

### 2-1. Gradle 설치 (Chocolatey 사용 시)

PowerShell **관리자 권한**으로 열고:

```powershell
Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
choco install gradle -y
```

(Chocolatey가 이미 있으면 `choco install gradle -y` 만 실행)

### 2-2. wrapper 생성 후 실행

**일반 PowerShell**에서 (Cursor 터미널에서도 가능):

```powershell
cd d:\Delopment\PG\pg-app
gradle wrapper
```

끝나면 **gradle/wrapper/gradle-wrapper.jar** 가 생깁니다. 그 다음:

```powershell
.\gradlew.bat bootRun --args="--spring.profiles.active=local"
```

---

## 방법 3: wrapper JAR 수동 다운로드

1. 브라우저에서  
   **https://github.com/gradle/gradle/raw/v8.7.0/gradle/wrapper/gradle-wrapper.jar**  
   로 접속해서 **gradle-wrapper.jar** 파일을 다운로드합니다.
2. 다운로드한 파일을  
   **d:\Delopment\PG\pg-app\gradle\wrapper\gradle-wrapper.jar**  
   로 이름을 맞춰서 저장합니다 (폴더가 없으면 **gradle\wrapper** 폴더를 만든 뒤 넣기).
3. 터미널에서:
   ```powershell
   cd d:\Delopment\PG\pg-app
   .\gradlew.bat bootRun --args="--spring.profiles.active=local"
   ```

---

## 정리

- **가장 간단한 방법**: **방법 1** — Cursor에서 **PgAppApplication.java** 를 Run으로 실행.
- **gradlew를 꼭 쓰고 싶을 때**: **방법 2** (Gradle 설치 후 `gradle wrapper`) 또는 **방법 3** (wrapper JAR 수동 다운로드).

실행 후 브라우저에서 **http://localhost:8080** → 로그인 **admin** / **admin1!** 로 확인하면 됩니다.
