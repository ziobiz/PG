# 로컬 실행 & 서버 배포 가이드 (왕초보용)

---

## 1. "터미널"이 뭔가요?

**터미널** = 글자만 나오는 검은(또는 흰) 창에 **명령어를 입력해서** 컴퓨터에게 시키는 곳입니다.

- **Cursor 안**에서 쓰는 터미널: 화면 **아래쪽** 또는 **상단 메뉴 → Terminal → New Terminal** 로 열 수 있습니다.
- **Windows**에서는 PowerShell 또는 "명령 프롬프트" 창과 비슷합니다.
- 여기에 `cd ...` , `gradlew.bat ...` 같은 **영문/숫자 명령**을 **한 줄씩** 입력하고 **Enter** 를 누르면 실행됩니다.

정리하면, **"로컬에서 실행하는 방법 2번"** 에서 말하는 **터미널**은  
→ **Cursor 아래쪽 터미널 창**을 열고, 그 안에 적어 드린 명령어를 **그대로 입력(또는 붙여 넣기)** 한 뒤 **Enter** 를 치라는 뜻입니다.

## 2. 로컬에서 실행하는 방법 (단계별)

### 2-1. Cursor에서 프로젝트 열기

1. Cursor 실행
2. **File → Open Folder** (또는 Ctrl+K Ctrl+O)
3. **d:\Delopment\PG\pg-app** 폴더 선택 후 열기

### 2-2. 터미널 열기

1. 메뉴에서 **Terminal → New Terminal** 클릭  
   또는 단축키 **Ctrl+`** (백틱, 숫자 1 왼쪽 키)
2. 화면 **아래**에 터미널 창이 열립니다.

### 2-3. 프로젝트 폴더로 이동

터미널에 **아래 한 줄**을 입력하고 Enter 하세요.

```bash
cd d:\Delopment\PG\pg-app
```

### 2-4. 실행

아래 **한 줄**을 입력(또는 복사해서 붙여 넣기)하고 Enter 하세요.

```bash
gradlew.bat bootRun --args="--spring.profiles.active=local"
```

- 처음에는 Gradle·라이브러리를 받느라 1~2분 걸릴 수 있습니다.
- 끝나면 `Started PgAppApplication` 같은 문구가 나오고, 그때 브라우저에서 **http://localhost:8080** 으로 접속하면 됩니다.

### 2-5. 실행이 안 될 때

- **"gradlew.bat을 찾을 수 없습니다"**  
  → 터미널에서 현재 위치가 `pg-app` 폴더인지 확인하세요. `cd d:\Delopment\PG\pg-app` 다시 입력 후 2-4 실행.
- **"JAVA_HOME이 설정되지 않았습니다"**  
  → PC에 **Java 17(JDK 17)** 을 설치하고, JAVA_HOME 환경 변수를 설정해야 합니다. (설치 방법은 별도 안내 가능.)
- **DB 연결 실패**  
  → `application-local.yml` 에 적은 DB 주소·비밀번호가 맞는지, PostgreSQL이 실행 중인지 확인하세요.  
  로컬 PC에 PostgreSQL이 없으면 **서버(otlpay) DB 주소**를 `application-local.yml` 에 넣고, 서버 방화벽에서 5432 포트를 열어 두어야 합니다.

## 3. 서버에 배포하는 방법 (단계별)

"서버에 배포" = **로컬 PC에서 만든 JAR 파일**을 **otlpay 서버로 복사**한 뒤, **서버에서 실행**하는 것입니다.

### 3-1. 로컬에서 JAR 만들기

1. Cursor 터미널에서 `pg-app` 폴더로 이동한 상태에서:
   ```bash
   cd d:\Delopment\PG\pg-app
   gradlew.bat bootJar
   ```
2. 완료되면 **d:\Delopment\PG\pg-app\build\libs\** 안에  
   **pg-app-0.0.1-SNAPSHOT.jar** 파일이 생깁니다.

### 3-2. JAR 파일을 서버로 복사하기

서버(otlpay)로 파일을 보내는 방법은 보통 두 가지입니다.

#### 방법 A: FileZilla (FTP/SFTP 프로그램) 사용

1. **FileZilla** 설치: https://filezilla-project.org/
2. **파일 → 사이트 관리자** 에서 새 사이트 추가:
   - **호스트**: 서버 IP (예: otlpay 서버 IP)
   - **프로토콜**: SFTP
   - **로그인 유형**: 일반
   - **사용자**: root (또는 카페24에서 안내한 계정)
   - **비밀번호**: 서버 비밀번호
3. **연결** 후:
   - **왼쪽**: 로컬 PC → `d:\Delopment\PG\pg-app\build\libs\` 로 이동
   - **오른쪽**: 서버 쪽 폴더 (예: `/root` 또는 `/home`) 로 이동
   - **pg-app-0.0.1-SNAPSHOT.jar** 를 **오른쪽으로 드래그**해서 업로드

#### 방법 B: scp 명령 (PowerShell 등에서)

로컬 PC에서 PowerShell을 열고 (Cursor 터미널에서도 가능):

```powershell
scp d:\Delopment\PG\pg-app\build\libs\pg-app-0.0.1-SNAPSHOT.jar root@서버IP:/root/
```

`서버IP` 를 실제 otlpay 서버 IP로 바꾸고, 비밀번호 입력하면 서버의 `/root/` 에 JAR가 복사됩니다.

### 3-3. 서버에 접속해서 실행하기

1. **PuTTY**로 서버(otlpay) 접속 (이전에 했던 것처럼).
2. 접속한 뒤, JAR를 올려둔 폴더로 이동. (예: FileZilla에서 `/root` 에 올렸다면)
   ```bash
   cd /root
   ```
3. **환경변수** 설정 후 **실행** (한 줄씩 입력):
   ```bash
   export DB_PASSWORD='line2025!@'
   nohup java -jar pg-app-0.0.1-SNAPSHOT.jar --server.port=8080 &
   ```
4. 방화벽에서 **8080** 포트가 열려 있어야 합니다. (카페24 관리 페이지에서 방화벽 규칙에 8080 추가)
5. 브라우저에서 **http://서버IP:8080** 으로 접속해 보세요.

### 3-4. 서버에서 끄고 다시 켜는 방법

- **끄기**: 실행 중인 Java 프로세스 찾아서 종료  
  ```bash
  ps aux | grep pg-app
  kill 숫자
  ```
  (숫자는 위에서 나온 프로세스 번호)
- **다시 켜기**: 3-3의 `export DB_PASSWORD=...` 와 `nohup java -jar ...` 를 다시 실행하면 됩니다.

## 4. 한 줄 요약

| 하고 싶은 것 | 할 일 |
|-------------|--------|
| **터미널이 뭔지** | Cursor **아래쪽 터미널** = 명령어 입력하는 창. **Terminal → New Terminal** 로 연다. |
| **로컬 실행** | 터미널에서 `cd d:\Delopment\PG\pg-app` → `gradlew.bat bootRun --args="--spring.profiles.active=local"` |
| **서버 배포** | ① 로컬에서 `gradlew.bat bootJar` ② JAR를 FileZilla 또는 scp로 서버에 복사 ③ PuTTY로 서버 접속 후 `export DB_PASSWORD='...'; nohup java -jar pg-app-0.0.1-SNAPSHOT.jar --server.port=8080 &` |

이렇게 하면 "로컬에서 실행하는 방법 2번"의 **터미널** 의미와, **서버에 어떻게 배포하는지**까지 한 번에 따라 하실 수 있습니다.
