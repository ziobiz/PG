# 자동 로그인 도구 실행 방법

fxhj.soonpay.co.kr 로그인 및 메뉴 분석을 위한 두 가지 방법입니다.

---

## 방법 1: Cursor에서 MCP 브라우저로 실행 (권장)

MCP가 켜져 있으면 **채팅에서** 에이전트가 브라우저를 대신 조작할 수 있습니다.

### 1단계: MCP 브라우저 활성화

- **Cursor 설정** (`Ctrl + ,`) → **Tools & MCP** → **cursor-ide-browser** 또는 **Playwright** 켜기  
- 이미 `.cursor/mcp.json`에 Playwright가 있으면 설정은 완료된 상태입니다.
- **Cursor를 완전히 종료한 뒤 다시 실행**합니다.

### 2단계: 새 채팅에서 요청

재시작 후 **새 채팅**을 열고 예를 들어 이렇게 입력합니다:

```
https://fxhj.soonpay.co.kr/main 접속해서 로그인해 줘.
아이디: fxhj
비밀번호: adminfx!@
OTP: (그때 받은 6자리 입력)
로그인 후 메인 메뉴 구조(이름, 링크) 분석해서 정리해 줘.
```

에이전트가 브라우저 도구로 접속 → 로그인 → 메뉴 분석까지 진행합니다.

---

## 방법 2: 터미널에서 스크립트 실행

브라우저가 **직접** 열리고, 로그인 후 메인 페이지 HTML이 파일로 저장됩니다.

### 1단계: Node.js 및 의존성

- Node.js v18 이상 필요.
- 최초 1회: Playwright 브라우저 설치  
  `npx playwright install chromium`

### 2단계: 스크립트 실행

```bash
cd d:\Delopment\PG\scripts
npm install
node fxhj-login-save-menu.js
```

**OTP 없이 실행**하면 스크립트가 아이디/비밀번호까지 채운 뒤 30초 대기합니다. 그동안 브라우저에서 OTP를 입력하고 로그인 버튼을 누르면 됩니다.

**OTP를 미리 넣어서 실행** (Windows CMD):

```cmd
set FXHJ_OTP=254303
node fxhj-login-save-menu.js
```

### 3단계: 저장된 결과

- 로그인 후 페이지 HTML이 다음 경로에 저장됩니다.  
  `d:\Delopment\PG\output\fxhj-main-after-login.html`
- 이 파일을 열어 메뉴 링크/구조를 확인하거나, 에이전트에게 "output/fxhj-main-after-login.html 메뉴 부분 분석해 줘"라고 요청할 수 있습니다.

---

## 요약

| 방법 | 할 일 |
|------|--------|
| **MCP** | Cursor 재시작 → 새 채팅에서 "fxhj 로그인해서 메뉴 분석해 줘" + 계정 정보 전달 |
| **스크립트** | `cd scripts` → `npm install` → `node fxhj-login-save-menu.js` → OTP 입력 후 로그인 → `output/fxhj-main-after-login.html` 확인 |

둘 중 편한 쪽을 사용하시면 됩니다.
