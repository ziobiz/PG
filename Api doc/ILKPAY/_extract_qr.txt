1. 정의 
 
㈜큐뱅의 간편결제 중계서비스는 QR 코드를 활용한 국내∙외 간편결제 서비스를 통합∙중계하
는 시스템으로, 결제 시장의 QR 코드를 일원화 하는 것을 목표로 한다. 이를 통해 QR 코드 결
제 시장의 혼란을 줄이고, 사용자들이 더욱 편리하게 결제할 수 있도록 돕는 것에 목적이 있다.

8. 암호화 가이드 
 
■ 암호화 방법 
1. Token 요청을 통해 암호화 key와 iv 수신 
2. 요청 보낼 payload 데이터를 JSON 문자열로 변환 
3. 해당 문자열을 AES-256 암호화 알고리즘 (운영모드 CBC, 패딩모드 PKCS5) 으로 암호화 
4. 암호화된 문자열을 요청 데이터 payload 값으로 설정 
5. 데이터 전송 
 
 
■ 유의사항 
 발행된 암호화 key와 iv는 발행된 해당 거래 1건에 대해서만 유효하므로, 새로운 거래를 시작
할 경우 Token 요청부터 다시 진행해야 합니다.
