# 서버에서 개발할 때 — 업로드·재시작 가이드

**개발 기준 URL(사용자 합의):** `https://api.icopay.co.kr/index.html`  
(코드·문서에 예시 URL을 적을 때는 프로젝트 규칙상 `localhost`를 쓰는 경우가 있으나, **실제 확인·테스트는 위 서버**에서 진행한다고 가정합니다.)

---

## 1. 먼저 알아두기: 정적 파일이 어디서 나가나

`pg-app/build.gradle`의 `processResources`가 **`site/` 폴더를 JAR 안의 `static/`으로 복사**합니다.  
그래서 **Nginx가 `api` 도메인을 전부 8080(Spring)으로만 넘기는 구성**이면:

- `index.html`, `site/css`, `site/js` 변경도 **JAR를 다시 빌드·업로드·재시작**해야 브라우저에 반영됩니다.
- **FTP로 `site`만 올려도** Spring이 디스크의 `site`를 직접 읽지 않으면 **화면이 안 바뀝니다**.

반대로, **Nginx가 `/` 또는 `/css`, `/js` 등을 별도 문서 루트(예: FTP 업로드 경로)에서 직접 서빙**한다면:

- 그 경로에 맞게 **FTP만** 올리면 되고, **Java 재시작은 불필요**할 수 있습니다.  
  (이 경우는 서버 Nginx 설정을 한 번 확인해 두면 됩니다.)

**불확실하면:** `site`만 수정했을 때 JAR를 안 올렸는데도 반영되면 “Nginx 정적”; 안 되면 “JAR에 포함”으로 보면 됩니다.

## 2. 변경 종류별 — 무엇을 올리고, 재시작은?

| 바꾼 것 | 로컬에서 할 일 | 서버에 올릴 것 | Java(pg-app) 재시작 | Nginx |
|--------|----------------|----------------|----------------------|--------|
| **HTML/CSS/JS만** (`site/`) | JAR에 넣는 방식이면 `clean bootJar` 권장 | 새 **JAR** (또는 정적만 Nginx면 해당 파일만 FTP) | **필요** (JAR 반영 시) | 설정 안 바꿨으면 **불필요** |
| **Java만** (`pg-app/src/...`) | `clean bootJar` | 새 **JAR** | **필요** | 설정 안 바꿨으면 **불필요** |
| **설정만** (`application.yml`, 프로파일 yml) | 빌드에 포함되면 JAR에 들어감 | 새 **JAR** 또는 서버만 덮어쓰기 정책에 따름 | **필요** (JAR/실행 옵션 반영 시) | - |
| **DB 스키마** (`db/*.sql`) | 로컬에서 검증 | 서버 PostgreSQL에 **SQL 실행** | 스키마만 바뀌고 코드 없으면 **불필요**일 수 있음(앱이 새 컬럼 필요 시엔 JAR+재시작) | - |
| **Nginx 설정** | - | 설정 파일 반영 후 | - | **`nginx -t` 후 reload** |

## 3. JAR 배포 시 권장 순서 (로컬 Windows)

```bat
cd D:\Delopment\PG\pg-app
gradlew.bat clean bootJar
```

생성물: `pg-app\build\libs\pg-app-0.0.1-SNAPSHOT.jar`  
→ 이 파일을 서버에 올린 뒤 **기존 프로세스 종료 → 동일 방식으로 기동** (서버의 `restart-pg-app.sh` 등).

**팁:** `site`를 바꿨는데 화면이 옛날 그대로면, **증분 빌드** 때문에 리소스가 꼬였을 수 있어 **`clean bootJar`**를 습관화하는 것이 좋습니다.

## 4. AI/페어 개발 시 요청사항

이 저장소에서 작업할 때는 **매번** 다음을 알려 달라고 하면 됩니다.

1. **이번에 수정된 경로** (예: `site/js/screens.js`, `MerchantController.java` …)  
2. **업로드 대상:** JAR만 / FTP 정적만 / SQL만 / Nginx 설정 …  
3. **재시작:** Java **필요·불필요**, Nginx **reload 필요·불필요**

이 문서(`docs/서버_개발_업로드_재시작_가이드.md`)를 기준으로 답변합니다.
