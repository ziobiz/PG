1. 什么是聊天机器人支付？

ICOPAY聊天机器人支付是AI聊天机器人与客户对话，在一个流程中完成商品介绍 → 接收订单 → 支付的服务。无需开发独立的购物网站或应用程序，仅凭一个聊天机器人URL即可运营在线销售、预约和支付。

客户支付流程（示例：预付模式）

客户→访问商家发布的聊天机器人URL（点击链接/扫描QR码）
AI聊天机器人→介绍商家注册的商品并引导选择
客户→选择商品并填写订单信息
AI聊天机器人→引导至支付页面
客户→完成银行卡支付
商家→在订单管理页面查看订单

商家能直接操作的 vs 总部管理的

商家可直接操作总部（HQ）管理
聊天机器人运营模式、业务类型、预约设置聊天机器人支付的激活/停用
商品的添加、编辑、删除商品注册上限设置
查看订单列表审批邮件/LINE Notify通知设置
查看和复制聊天机器人URL/QR/嵌入脚本公司基本信息变更

2. 开始之前（需要总部激活）

聊天机器人支付需要总部在商家账户上激活才能使用。请确认以下内容：

确认项目确认方法
侧边栏是否显示聊天机器人管理菜单？显示则已激活。未显示则联系总部。
我的公司信息中是否显示聊天机器人支付URL？有URL显示则账户可用。
需要请求总部处理的事项
以下内容商家无法直接更改，请联系ICOPAY总部负责人：

• 聊天机器人支付的激活/停用
• 支付审批邮件通知设置
• LINE Notify通知设置
• 商品注册上限的调整
• 公司基本信息变更（商号、地址等）

3. STEP 1 查看聊天机器人信息 （仅查看）

商家管理 > 我的公司信息
此页面为仅查看模式。商家可以查看和复制信息，但不能直接修改任何设置。

3-1. 查看并复制聊天机器人支付URL

总部激活后，将自动显示以下格式的URL：

https://pay.icopay.co.kr/chatbot-pay/{商家代码}
操作方法
复制URL点击URL字段旁的复制按钮 → 保存到剪贴板
下载QR码点击QR图像旁的保存按钮 → 下载为PNG文件
如果总部将聊天机器人支付设为停用，URL将不会显示。请联系总部负责人申请激活。

3-2. 复制网站浮动小部件脚本

要在网站上显示聊天机器人图标，请从我的公司信息中复制聊天机器人浮动小部件代码：

<!-- 复制的代码示例 — 粘贴到所有页面的</body>标签前 -->
<script src="https://pay.icopay.co.kr/v1/embed-chatbot/{商家代码}"
        async defer charset="utf-8"></script>
在我的公司信息页面按复制按钮，即可直接复制包含商家代码的完整代码。

3-3. QR码的使用

  • 将下载的PNG文件发送给印刷店，或用于海报和名片设计
  • 张贴在店内桌卡、指示牌和菜单上
  • 客户扫描QR码 → 直接进入聊天机器人支付页面

4. STEP 2 聊天机器人基本设置 ✔ 商家自主操作

聊天机器人管理 > 基本设置
商家可直接配置并保存此菜单中的设置。

4-1. 选择运营模式

选择适合业务类型和付款时机的模式，AI将引导客户完成相应的对话流程。

运营模式说明适合行业示例
商品销售 · 预付选择商品后立即付款在线商店、商品销售
商品销售 · 后付接收订单后稍后付款定制订单、B2B供货
预约方式 · 预付预约时立即付款按摩、美发店、自习室
预约方式 · 后付接受预约 → 到店后付款餐厅、咨询服务
混合型（销售+预约）普通销售商品和预约商品混合复合服务业
面对面交易（销售+预约·后付）现场确认后付款VIP俱乐部、面对面服务

4-2. 选择业务性质

AI聊天机器人将自动构建适合行业的提问流程。请选择最接近您业务的类型。

业务性质AI响应特点
一般销售 / 电商重点收集商品名称、数量、配送地址
按摩（一般/俱乐部）收集预约日期、时间、套餐、人数
餐厅收集用餐人数、日期、时间、特殊要求
咨询/服务业收集咨询主题、希望时间、联系方式
房地产/汽车销售收集感兴趣的物件、预算、可参观日期
VIP俱乐部以会员资格和预约套餐为中心提供指引
业务性质补充备注（可选）： 输入特殊行业中必须收集的信息或应避免的表达方式，这些内容将反映在AI响应中。

4-3. 填写商家基本信息

AI在回答客户询问时参考的基本信息。若留空，将按商家注册信息进行说明。

  • 商家名称 / 地址 / 电话号码
  • 营业时间
  • 其他说明（停车场、交通方式等）

4-4. 预约设置（预约模式时）

设置项说明
预约基本时段（分钟）预约时间单位：15 / 30 / 45 / 60 / 90 / 120 / 180 / 240分钟
各商品需要不同时段时，可在商品管理中单独设置
预约时区（IANA）参考时区（默认值：Asia/Shanghai）
若所选时段已有预约，AI将自动建议其他时间。系统将按时段单位自动阻止重复预约。

5. STEP 3 商品管理 ✔ 商家自主操作

聊天机器人管理 > 商品管理
商家可直接添加、编辑和删除商品。

5-1. 商品类型

类型代码说明
SALE普通销售商品 — 按数量购买
RESERVATION_TIME时间预约商品 — 指定日期和时间进行预约
RESERVATION_PLACE场所预约商品 — 预约特定空间（房间、座位等）
可用的商品类型可能受总部政策限制。

5-2. 商品注册字段

字段必填说明
商品名称必填聊天机器人向客户介绍的商品名称
价格必填支付金额（适用商家基准货币）
商品描述可选AI响应时使用的详细说明
商品图片可选最多1~4张（上限由总部政策决定）
销售数量上限可选需要库存管理时填写
预约时段（分钟）仅预约与基本设置不同时，按商品单独设定
销售期间可选限时销售时设置开始和结束日期
激活状态必填停用时，该商品不会在客户聊天机器人中显示
每个商家可注册的商品数量在总部设定的商品注册上限以内。超出时请删除不必要的商品或向总部申请提高上限。

将STEP 1中获取的URL、QR码和嵌入脚本发布给客户。

6-1. 直接分享URL

https://pay.icopay.co.kr/chatbot-pay/{商家代码}
发布渠道使用方法
微信 / LINE在消息中附上链接发送给客户
SNS主页在Instagram、微博等主页链接中注册
邮件签名在邮件底部签名中插入链接
网站按钮将"立即订购"/"立即预约"按钮的href设置为该URL

6-2. QR码印刷品

使用场景示例
店内桌面QR码卡片、收银台指示牌
印刷品海报、横幅、菜单、传单
名片名片背面的QR码

6-3. 网站浮动小部件

当客户访问网站时，聊天机器人图标将自动显示在屏幕底部。将STEP 1中复制的脚本代码粘贴到网站所有页面的</body>标签前即可。

8. 各运营模式流程概要

预付模式 — 立即付款

客户→访问聊天机器人URL
AI→介绍商家注册的商品
客户→选择商品 + 填写订单信息
AI→引导至支付页面 → 完成银行卡支付
商家→在订单管理中查看订单（若总部已配置，可收到Email/LINE通知）

后付模式 — 接收订单，稍后付款

客户→访问聊天机器人URL → 选择商品并提交订单信息
商家→在订单管理中确认订单 → 联系客户
付款→通过其他方式处理（现场、银行转账等）

预约模式 — 选择日期和时间

客户→访问聊天机器人URL
AI→显示可预约的日期和时间（基于基本设置中的时段）
客户→选择日期、时间、人数 + 填写个人信息
预付→立即完成支付 → 确认预约
后付→接受预约 → 到店后付款
商家→在订单管理中查看预约日期时间和客户信息

9. 常见问题（FAQ）

侧边栏中没有显示聊天机器人管理菜单。
总部尚未在您的商家账户上激活聊天机器人支付。请联系ICOPAY总部负责人申请激活。商家无法直接更改此设置。
我的公司信息中没有显示聊天机器人支付URL。
这意味着总部将聊天机器人支付设为停用。URL仅在总部激活后才会显示。请联系总部负责人。
我想修改公司信息。
我的公司信息对商家来说是仅查看模式。如需更新任何信息，请联系ICOPAY总部负责人。
我想在支付获批时收到邮件或LINE通知。
通知设置无法由商家直接更改。请联系总部负责人，提供您的邮箱地址或LINE Notify令牌进行配置。
已注册商品但在聊天机器人中不显示。
请在商品管理中检查该商品的激活状态。停用状态的商品不会在客户聊天机器人中显示。如果设置了销售期间，还请确认当前日期是否在该期间内。
预约会重复吗？
若所选时段已有预约，AI将自动建议其他时间。系统将按基本设置中配置的时段单位自动阻止重复预约。
无法继续注册新商品。
已达到总部设定的商品注册上限。请删除不必要的商品或向总部申请提高上限。
我想修改或删除某个订单。
订单管理对商家来说是仅查看模式。如需变更订单，请联系ICOPAY总部负责人。
聊天机器人能否用多种语言回应客户？
ICOPAY聊天机器人根据客户浏览器的语言设置自动响应。无需额外设置，即支持多语言（中文、韩语、英语、日语、泰语等）。
