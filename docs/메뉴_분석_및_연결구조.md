## 2. 메뉴와 내용이 연결되는 방식

### 2.1 DOM 구조

- **좌측 메뉴**: `div.left-side-menu` → `#left-side-menu-container` → `ul.metismenu.side-nav`
  - 1뎁스: `li.side-nav-item` (대메뉴)
  - 2뎁스: `ul.side-nav-second-level` → `li.child-li` (하위 메뉴)
- **메뉴 클릭 시**: `fnTopMenuMove(url)` 호출 (예: `fnTopMenuMove('/calc/payList')`)
- **각 하위 메뉴**: `data-url`, `data-menu_id` 속성으로 URL·메뉴ID 연결

### 2.2 탭·컨텐츠 연결

- **상단 탭**: `#copyTopTabUl` 안 `li.copyTopTab`  
  - `top_tab_url`: 해당 화면 URL (예: `/calc/payList`)  
  - `a.tab-a`의 `menu_id`: 메뉴ID (예: M0301)  
  - `href="#payList"`: 탭 패널 id와 연결
- **컨텐츠 영역**: `#topTapMain` 안 `div.tab-pane.tabConDiv`  
  - `id`: 탭과 동일 (예: `payList`)  
  - `formurl`: 실제 로드되는 URL (예: `/calc/payList`)  
  - 해당 URL로 AJAX/폼 제출 후 HTML을 받아 해당 탭 패널에 삽입

### 2.3 URL → 탭 id 규칙

- URL 경로를 탭 id로 변환: **슬래시 제거 후 마지막 경로 사용**  
  - `/calc/payList` → `payList`  
  - `/system/noticeList` → `noticeList`  
  - `/comp/compMngTree` → `compMngTree`

### 2.4 브레드크럼·페이지 타이틀

- `input#_menuId`: 현재 메뉴ID (예: M0301)
- `li.breadcrumb-item.navi`: 상위메뉴명 > 현재메뉴명 (예: `결제관리 > 결제내역`)
- `h4#common__header__title`: 페이지 제목 (예: `결제내역`)

### 2.5 메뉴별 로드 스크립트 (예시)

- 컨텐츠는 URL별로 서버에서 HTML 조각을 내려주고, 해당 페이지에서 필요 시 전용 JS 로드  
  - 예: `/calc/payList` → `script src="/js/pages/calc/payList.js"`

## 3. 연결 요약

| 구분 | 역할 |
|------|------|
| **좌측 메뉴** | 모든 대/하위 메뉴 노출, 클릭 시 `fnTopMenuMove(url)` 호출 |
| **fnTopMenuMove(url)** | 1) 해당 url 탭이 없으면 탭 추가 2) 해당 탭으로 전환 3) formurl로 컨텐츠 로드 후 해당 탭 패널에 표시 |
| **data-url** | 화면 URL (컨텐츠 로드 및 탭 식별에 사용) |
| **data-menu_id** | 메뉴ID (권한·브레드크럼·타이틀 등에 사용) |
| **formurl** | 탭 패널별 실제 요청 URL |

## 4. 좌측 메뉴 구축 시 필수 사항

- **대메뉴 5개**: 업체관리, 결제관리, 정산관리, 통보관리, 사용자관리
- **하위 메뉴**: 위 표의 23개 항목 그대로 (순서·URL·메뉴ID 유지)
- **아이콘**: 대메뉴만 아이콘 클래스 지정 (dripicons-store, dripicons-card, uil-dollar-alt, mdi mdi-file-send, dripicons-user-group)
- **접기 버튼**: `#leftSideFoldBtn`, `#leftSideFoldSpan`(접기/펼치기 텍스트)
- **로고**: `#leftside-logo` → `/main` 링크, logo-lg / logo-sm 스팬
- **스크립트**: `/js/pages/frame/leftside.js` (메타메뉴 접기/펼치기 등)

이 문서와 `docs/menu-structure.json`을 사용하면 좌측 메뉴를 원본과 동일하게 구축할 수 있습니다.
