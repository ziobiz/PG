## 2. 메뉴와 내용이 연결되는 방식

### 2.1 DOM 구조

- **좌측 메뉴**: `div.left-side-menu` → `#side-nav-ul`
  - 1뎁스: `li.side-nav-item` (대메뉴)
  - 2뎁스: `ul.side-nav-second-level` → `li.child-li` (하위 메뉴)
- **메뉴 클릭 시**: `fnTopMenuMove(url)` → B안이면 `PG_MENU_LAYOUT_B.resolveNavUrl`
- **허브 화면**: `PG_HUB_SHELL`이 leaf `getScreenHtml` + `bindScreenEvents` embed

### 2.2 탭·컨텐츠 연결

- **상단 탭**: `#copyTopTabUl` — 허브는 path만 탭 키(`data-pg-full-url`에 쿼리 보관)
- **컨텐츠**: `#topTapMain` → `loadContent` → `PG_SCREENS.getScreenHtml` 또는 허브 shell

### 2.3 URL → 탭 id 규칙

- 쿼리스트링 제거 후 `/` → `_` (예: `/hq/hub/policy-fees` → `hq_hub_policy-fees`)
