# 정산리포트 (정산시트 기준)

## 메뉴

- SPA: **정산관리 → 정산리포트** (`http://localhost:8080/index.html` 에서 `/calc/settlementReport`)

## 리포트 형식 (`searchReportKind`)

| 값 | 용도 | 로그인 |
|----|------|--------|
| `MERCHANT_STMT` | **가맹점 정산 리포트** — 총본사·본사·총판·지사·대리점·영업점·가맹이 소속 가맹 거래를 가맹 단위로 조회 | 조직 트리에 맞는 하위 가맹만 |
| `REGIONAL_PAYOUT` | **본사 지급 리포트** — 총본사가 본사(REGIONAL)에 지급할 금액을 본사 단위로 합산 | **총본사(HEADQUARTERS)·본사(REGIONAL)** 만 화면에서 선택 가능 |

노출 여부: `GET /api/settlement/report/access` (`merchantStmt`, `regionalPayout`, `orgLevel`).

## 리포트 구분 (`searchReportSub`)

| 값 | 설명 | API |
|----|------|-----|
| 정산집계 (AGG) | 거래 집계(가맹 단위 또는 본사 단위) | `GET /api/settlement/report/aggregate` |
| 정산실시 (EXE) | 배치 정산 실행 결과 합산 | `GET /api/settlement/report/execute` |
| 정산집계표 (SUM) | 기간 합계 1행 | `GET /api/settlement/report/summary` |

본사 지급 리포트 시 선택 파라미터: `searchRegionalId` (본사 코드 필터).

## 비율·건당 요금 (백엔드 상수)

`SettlementReportService` 참고. 응답 `PageResult.meta`에 안내 문자열 포함.

- 예치(롤링): 10% (180일 보관은 표시용)
- Processing: 합계 5.6% (PG 4.2% + 파일 0.1% + 온라인 1.3%)
- 건당: 승인 50원 / 환불·취소 300원 / 배치 정산 11,000원 (KRW 예시)
- 지급 예정일: 결제일 + 7 **영업일** (주말 제외, 공휴일 미반영)

운영 시 HQ 정책 테이블·가맹별 수수료로 대체 가능.

## 권한

- 로그인 소속 조직 기준 하위 가맹만 조회 (유통망 정산과 동일 패턴).
- 가맹점 로그인: 본인 가맹 코드만.
