1. チャットボット決済とは？

ICOPAY チャットボット決済は、AIチャットボットが顧客と会話しながら商品案内 → 注文受付 → 決済まで一連の流れで処理するサービスです。ショッピングサイトやアプリを開発しなくても、チャットボットURLひとつでオンライン販売・予約・決済を運営できます。

顧客の決済フロー（例：前払い販売）

顧客→加盟店が配布したチャットボットURLにアクセス（リンクタップ / QRスキャン）
AIチャット→加盟店が登録した商品を案内・選択を促す
顧客→商品を選択し、注文情報を入力
AIチャット→決済ページへ案内
顧客→カード決済完了
加盟店→注文管理画面で注文内容を確認

加盟店が直接操作できる範囲 vs 本部が管理する範囲

加盟店が直接できること本部（HQ）が管理すること
チャットボット運営方式・業種・予約設定チャットボット決済の有効化 / 無効化
商品の登録・修正・削除商品登録上限数の設定
注文一覧の閲覧承認メール・LINE Notify通知の設定
チャットボットURL・QR・スクリプトの確認・コピー会社基本情報の変更

2. 利用開始前の確認（本部による有効化が必要）

チャットボット決済は、本部が加盟店アカウントを有効化することで利用可能になります。以下を確認してください。

確認項目確認方法
サイドバーにチャットボット管理メニューが表示されているか？表示されていれば有効化済み。表示されない場合は本部に連絡
自社情報にチャットボット決済URLが表示されているか？URLが表示されていれば利用可能な状態
本部への依頼が必要な事項
以下は加盟店が直接変更できません。ICOPAY本部担当者にご依頼ください。

• チャットボット決済の有効化 / 無効化
• 決済承認メール通知の設定
• LINE Notify通知の設定
• 商品登録上限数の変更
• 会社基本情報の変更（商号・住所など）

3. STEP 1 自社チャットボット情報の確認 （閲覧のみ）

業者管理 > 自社情報
この画面は閲覧専用です。情報の確認・コピーは可能ですが、内容を直接変更することはできません。

3-1. チャットボット決済URLの確認・コピー

本部が有効化すると、以下の形式のURLが自動的に表示されます。

https://pay.icopay.co.kr/chatbot-pay/{加盟店コード}
操作方法
URLのコピーURLフィールド横のコピーボタンをクリック → クリップボードに保存
QRコードの保存QR画像横の保存ボタンをクリック → PNGファイルとしてダウンロード
本部でチャットボット決済が無効に設定されている場合、URLは表示されません。本部担当者に有効化をご依頼ください。

3-2. フローティングウィジェットスクリプトのコピー

Webサイトにチャットボットアイコンを表示するには、自社情報のチャットボット フローティングウィジェット欄からコードをコピーします。

<!-- コピーされたコード例 — すべてのページの </body> 直前に貼り付け -->
<script src="https://pay.icopay.co.kr/v1/embed-chatbot/{加盟店コード}"
        async defer charset="utf-8"></script>
自社情報画面のコピーボタンを押すと、加盟店コード入りの完成コードをそのままコピーできます。

3-3. QRコードの活用

  • 保存したPNGファイルを印刷業者に渡すか、ポスター・名刺デザインに活用
  • 店内のテーブルカード・案内板・メニュー表に貼付
  • 顧客がQRをスキャン → チャットボット決済ページへ直接アクセス

4. STEP 2 チャットボット基本設定 ✔ 加盟店が直接運営

チャットボット管理 > 基本設定
このメニューは加盟店が直接設定・保存できます。

4-1. 運営方式の選択

業種と支払いタイミングに合った方式を選ぶと、AIが適切な会話フローで顧客を案内します。

運営方式説明適合業種の例
商品販売 · 前払い商品選択後に即時決済オンラインショップ、グッズ販売
商品販売 · 後払い注文受付後に後日決済受注製作、B2B納品
予約方式 · 前払い予約時に即時決済マッサージ、ヘアサロン、自習室
予約方式 · 後払い予約受付 → 来店後に決済レストラン、コンサルティング
ハイブリッド（販売＋予約）通常販売と予約商品を混在複合サービス業
対面取引（販売＋予約・後払い）現場確認後に決済VIPクラブ、対面サービス

4-2. 業種の選択

AIチャットボットが業種に合った質問フローを自動構成します。最も近い業種を選択してください。

業種AI応対の特徴
一般販売 / Eコマース商品名・数量・配送先を中心に収集
マッサージ（一般・クラブ）予約日時・コース・人数を収集
飲食店 / レストラン来店人数・日時・特記事項を収集
コンサルティング / サービス業相談テーマ・希望日程・連絡先を収集
不動産 / 自動車販売関心物件・予算・来場可能日を収集
VIPクラブメンバーシップ・予約コース中心の案内
業種補足メモ（任意）： 特定業種で必ず収集すべき情報や避けるべき表現を入力すると、AI応対に反映されます。

4-3. 店舗基本情報の入力

AIが顧客の問い合わせに答える際に参照する情報です。空白の場合は登録情報と同様に案内されます。

  • 店舗名 / 住所 / 電話番号
  • 営業時間
  • その他案内（駐車場・交通アクセスなど）

4-4. 予約設定（予約方式の場合）

項目説明
予約基本スロット（分）予約単位: 15 / 30 / 45 / 60 / 90 / 120 / 180 / 240分から選択
商品ごとに異なるスロットが必要な場合は商品管理で個別設定可能
予約タイムゾーン（IANA）基準タイムゾーン（デフォルト: Asia/Seoul）
同じ日時にすでに予約がある場合、AIが自動的に他の時間を案内します。スロット単位での重複予約は自動ブロックされます。

5. STEP 3 商品登録・管理 ✔ 加盟店が直接運営

チャットボット管理 > 商品管理
このメニューは加盟店が直接登録・修正・削除できます。

5-1. 商品タイプ

タイプコード説明
SALE通常販売商品 — 数量単位で購入
RESERVATION_TIME時間予約商品 — 日時を指定して予約
RESERVATION_PLACE場所予約商品 — 特定スペース（部屋・席など）を予約
利用可能な商品タイプは本部のポリシーによって制限される場合があります。

5-2. 商品登録項目

項目必須説明
商品名必須AIチャットボットが顧客に紹介する商品名
価格必須決済金額（加盟店の基準通貨適用）
商品説明任意AI案内時に使用する詳細説明
商品画像任意最大1〜4枚（本部ポリシーで上限決定）
販売数量上限任意在庫管理が必要な場合に入力
予約スロット（分）予約のみ基本設定と異なる場合に商品ごとに個別設定
販売期間任意期間限定販売の場合に開始・終了日を設定
有効化状態必須無効の場合は顧客チャットボットに表示されない
登録可能な商品数は本部が設定した商品登録上限以内です。超過時は既存商品を削除するか、本部に上限引き上げをご依頼ください。

7. STEP 5 注文内容の確認 （閲覧のみ）

チャットボット管理 > 注文管理
注文管理画面は閲覧専用です。注文内容・顧客情報の確認はできますが、修正・削除はできません。

確認できる注文情報

項目説明
注文番号ICOPAYが採番した注文識別番号
顧客名・連絡先チャットボット注文時に顧客が入力した情報
商品名・数量注文された商品と数量
注文メモ顧客がチャットボットで入力したリクエスト事項
予約日時予約方式注文の場合に選択された日時
決済ステータス決済待ち / 完了 / キャンセルなど

決済履歴の確認

  • 承認済み決済金額・カード情報・承認番号などを詳細確認
  • 期間・ステータス別フィルター検索
  • Excelダウンロード対応

8. 運営方式別フロー概要

前払い方式 — 即時決済

顧客→チャットボットURLにアクセス
AI→加盟店が登録した商品を案内
顧客→商品を選択し、注文情報を入力
AI→決済画面へ案内 → カード決済完了
加盟店→注文管理画面で注文を確認（本部設定によりメール/LINE通知も受信）

後払い方式 — 注文受付後に別途決済

顧客→チャットボットURLにアクセス → 商品選択・注文情報入力
加盟店→注文管理で注文を確認 → 顧客に連絡
決済→現場・銀行振込など別の方法で処理

予約方式 — 日時選択

顧客→チャットボットURLにアクセス
AI→予約可能な日時を案内（基本設定のスロット基準）
顧客→日時・人数を選択し、個人情報を入力
前払い→即時決済完了 → 予約確定
後払い→予約受付完了 → 来店後に決済
加盟店→注文管理で予約日時・顧客情報を確認

9. よくある質問（FAQ）

チャットボット管理メニューがサイドバーに表示されません。
本部がまだ加盟店アカウントのチャットボット決済を有効化していない状態です。ICOPAY本部担当者に有効化をご依頼ください。加盟店側でこの設定を直接変更することはできません。
自社情報にチャットボット決済URLが表示されません。
本部でチャットボット決済が無効に設定されているためです。URLは本部が有効化した後にのみ表示されます。本部担当者にお問い合わせください。
自社情報を修正したいのですが。
自社情報画面は加盟店にとって閲覧専用です。情報の変更が必要な場合はICOPAY本部担当者にご依頼ください。
決済承認時にメールまたはLINE通知を受け取りたいのですが。
通知設定は加盟店が直接変更できません。本部担当者にご依頼いただき、メールアドレスまたはLINE Notifyトークンをお伝えください。
商品を登録したのにチャットボットに表示されません。
商品管理画面で対象商品の有効化状態をご確認ください。無効状態の商品は顧客チャットボットに表示されません。販売期間が設定されている場合は、現在の日付が期間内かどうかも確認してください。
予約が重複して受け付けられることはありますか？
同じ日時にすでに予約がある場合、AIが自動的に他の時間を案内します。基本設定で指定したスロット単位での重複予約は自動的にブロックされます。
これ以上商品を登録できないと表示されます。
本部が設定した商品登録上限に達しています。不要な商品を削除するか、本部に上限引き上げをご依頼ください。
注文を修正または削除したいのですが。
注文管理は加盟店にとって閲覧専用です。注文の変更が必要な場合はICOPAY本部担当者にお問い合わせください。
チャットボットの応対言語を変更できますか？
ICOPAYチャットボットは顧客のブラウザ言語設定に応じて自動で多言語応対します。設定不要で日本語・英語・韓国語・中国語・タイ語などに対応しています。
