🔒 ข้อจำกัดการเข้าถึงสำหรับสำนักงานใหญ่

ผู้ดูแลระบบสำนักงานใหญ่ไม่สามารถเข้าถึงเมนูต่อไปนี้ หากต้องการกรุณาติดต่อผู้ดูแลระบบสูงสุด

  • การตั้งค่าสำนักงานใหญ่ — ไม่มีสิทธิ์เข้าถึงทุกเมนู
  • การจัดการการชำระเงิน — การชำระรวม, ดำเนินการ, แจกจ่าย, รอดำเนินการ: ไม่มีสิทธิ์
  • การจัดการการแจ้งเตือน — ไม่มีสิทธิ์ทุกเมนู
  • การจัดการผู้ใช้ — การจัดการลำดับรายการเมนู: ไม่มีสิทธิ์
  • การจัดการการดำเนินงาน — การดำเนินงาน, TAX, การตรวจสอบ, ประวัติตัวแทน: ไม่มีสิทธิ์
  • การตั้งค่าการเผยแพร่ — เฉพาะเอกสาร API เท่านั้น
  • การจัดการการแบ่งชำระ — การตั้งค่าอีเมล: ไม่มีสิทธิ์

1. การลงทะเบียนร้านค้า

การจัดการร้านค้า > ลงทะเบียนร้านค้า
①ไปที่การจัดการร้านค้า > ลงทะเบียนร้านค้า
②กรอกข้อมูลพื้นฐาน — ชื่อ, เลขทะเบียน, ผู้แทน, ติดต่อ, อีเมล, ที่อยู่
③ตั้งค่าการชำระเงิน — รอบ, ค่าธรรมเนียม, บัญชีธนาคาร
④เปิดใช้งานบริการชำระเงินที่ต้องการ
⑤บันทึก → URL ถูกสร้าง → สร้างบัญชีร้านค้าและแจ้ง
ตั้งค่าเป็น Y เพื่อแสดง URL ในพอร์ทัลร้านค้า N = ซ่อน URL

2. การตั้งค่าค่าธรรมเนียม

โครงสร้างค่าธรรมเนียมของ ICOPAY แบ่งเป็น 2 ระดับ: ค่าธรรมเนียมนโยบายพื้นฐาน (ค่าเริ่มต้นของระบบทั้งหมด) และ ค่าธรรมเนียมรายร้านค้า (สำหรับร้านค้าเฉพาะ)

ประเภทค่าธรรมเนียมเส้นทางเมนูเข้าถึงได้
ค่าธรรมเนียมนโยบายพื้นฐาน (ค่าเริ่มต้นระบบ)การตั้งค่าสำนักงานใหญ่ > การตั้งค่าค่าธรรมเนียม❌
ค่าธรรมเนียมรายร้านค้าการจัดการผู้ค้า > การจัดการค่าธรรมเนียม✅
🔒 ไม่สามารถเข้าถึงค่าธรรมเนียมนโยบายพื้นฐาน (การตั้งค่าสำนักงานใหญ่ > การตั้งค่าค่าธรรมเนียม)
เมนูการตั้งค่าสำนักงานใหญ่สำหรับซูเปอร์แอดมินเท่านั้น หากต้องการเปลี่ยนนโยบายค่าธรรมเนียมพื้นฐาน กรุณาติดต่อซูเปอร์แอดมิน

2-1. การตั้งค่าค่าธรรมเนียมรายร้านค้า

การจัดการผู้ค้า > การจัดการค่าธรรมเนียม

ตั้งค่าอัตราค่าธรรมเนียมรายบุคคลที่ใช้กับร้านค้าเฉพาะเจาะจง ใช้กับร้านค้าที่ต้องการเงื่อนไขต่างจากค่าธรรมเนียมนโยบายพื้นฐาน

①การจัดการผู้ค้า > การจัดการค่าธรรมเนียม เข้าเมนู
②เลือกร้านค้าที่ต้องการตั้งค่าค่าธรรมเนียม
③ป้อนอัตราค่าธรรมเนียมรายบุคคลแต่ละวิธีชำระเงิน
④ตั้งค่าระยะเวลาใช้งาน (วันเริ่มต้น·วันสิ้นสุด) (สามารถใช้ค่าธรรมเนียมโปรโมชั่นระยะเวลาจำกัด)
⑤บันทึก → ใช้กับร้านค้าที่เลือกทันที
รายการคำอธิบาย
อัตราค่าธรรมเนียมรายร้านค้าอัตราค่าธรรมเนียมรายบุคคลต่างจากนโยบายพื้นฐาน (%)
การตั้งค่าแต่ละวิธีชำระเงินการใช้รายบุคคลแยกตามบัตรเครดิต·โอนกระเป๋าเงิน·QR
การตั้งค่าระยะเวลาใช้งานการตั้งค่าเงื่อนไขค่าธรรมเนียมระยะเวลาจำกัด
ดูประวัติการเปลี่ยนแปลงค่าธรรมเนียมตรวจสอบประวัติการเปลี่ยนแปลงค่าธรรมเนียมรายร้านค้า
เมื่อลงทะเบียนค่าธรรมเนียมรายร้านค้าแล้ว จะถูกใช้ก่อนค่าธรรมเนียมนโยบายพื้นฐาน ร้านค้าที่ไม่ได้ลงทะเบียนค่าธรรมเนียมรายบุคคลจะใช้ค่าธรรมเนียมนโยบายพื้นฐานโดยอัตโนมัติ

3. การชำระเงินเว็บ

การจัดการร้านค้า > ข้อมูลร้านค้า > แท็บการตั้งค่าการชำระเงิน
①เลือกร้านค้า → ตั้ง เปิดใช้งานการชำระเงินเว็บ เป็น Y → บันทึก
②URL ถูกสร้างอัตโนมัติ → แจ้ง URL ให้ร้านค้า
🔒 การตั้งค่า Notify URL เป็นสิทธิ์เฉพาะผู้ดูแลระบบสูงสุด
สำนักงานใหญ่ไม่สามารถเข้าถึงการจัดการการแจ้งเตือน

4. การสมัครสมาชิก

การจัดการร้านค้า > ข้อมูลร้านค้า > แท็บการตั้งค่าการชำระเงิน
①ตั้ง เปิดใช้งานการสมัครสมาชิก เป็น Y → บันทึก
②ตั้งค่าแผน: ชื่อ, รอบ (รายเดือน/รายปี), จำนวนเงิน, สกุลเงิน
③แชร์ URL การสมัครสมาชิกกับร้านค้า

5. การซื้อซ้ำ

ช่วยให้ลูกค้าใช้โทเค็นบัตรที่บันทึกไว้จากการชำระเงินก่อนหน้าโดยไม่ต้องกรอกข้อมูลบัตรอีกครั้ง

①ตั้ง เปิดใช้งานการซื้อซ้ำ เป็น Y → บันทึก
②ลูกค้าเลือกซื้อซ้ำ → ระบบชำระด้วยโทเค็นที่บันทึกไว้ทันที

6. การแบ่งชำระ URL

การจัดการการแบ่งชำระ
🔒 การตั้งค่าอีเมลในการจัดการการแบ่งชำระเป็นสิทธิ์เฉพาะผู้ดูแลระบบสูงสุด
①ตั้ง เปิดใช้งานการแบ่งชำระ เป็น Y → บันทึก
②สร้างสัญญาแบ่งชำระ: จำนวนเงิน, งวด, วันครบกำหนด
③ส่ง URL แต่ละงวดให้ลูกค้า

7. แชทบอท

การจัดการแชทบอท
✅ การจัดการแชทบอทเข้าถึงได้สำหรับสำนักงานใหญ่ (รวมการลบ)
①ตั้ง เปิดใช้งานแชทบอท เป็น Y → บันทึก
②การจัดการแชทบอท → เลือกร้านค้า → เลือกโหมด → ตั้งสล็อตสินค้า
③แจ้ง URL แชทบอทให้ร้านค้า
🔒 การตั้งค่า LINE Notify และอีเมลแจ้งเตือนเป็นสิทธิ์เฉพาะผู้ดูแลระบบสูงสุด

คำถามที่พบบ่อย

เมนูการแจ้งเตือนไม่แสดง
เป็นเมนูเฉพาะผู้ดูแลระบบสูงสุด กรุณาติดต่อผู้ดูแลระบบสูงสุด
ร้านค้าไม่เห็น URL การชำระเงิน
ตรวจสอบว่าฟิลด์เปิดใช้งานตั้งเป็น Y แล้ว
ไม่สามารถเพิ่มสินค้าแชทบอทได้
ถึงขีดจำกัดสล็อต เพิ่มจำนวนสล็อตในข้อมูลร้านค้า
