# 담보금(롤링) 내역

## 개요

- **정산관리 → 담보금내역** (`/calc/collateralList`): 가맹점별 담보 적립·해지 내역 조회.
- **적립**: **정산 실행** 시 승인(결제) 거래 건마다, 수수료 정책의 롤링 비율(%)만큼 금액을 예치하고 `tb_rolling_reserve`에 적재합니다.
- **비율·보류 일수**: 본사 **수수료 정책**의 롤링(담보금) 또는 가맹 **정산설정**에서 `보류율 본사정책 따름 = N`일 때 `hold_rate` / `hold_days`를 사용합니다.
- **해지일**: 적용일(정산 실행 기준일)로부터 **영업일** `hold_days`일 후(주말 제외, 공휴일 미반영 — `BusinessDayCalendar`).
- **정산 반영**: 해지일이 도래한 건은 **다음 정산 실행** 시(기간 종료일 `toDate` 기준) 상태를 `RELEASED`로 바꾸고, 해당 가맹의 **지급액**에 합산합니다.  
  기간 내 신규 거래가 없어도 해지 대상만 있으면 지급 반환 전용 `SettlementRun`이 추가됩니다.

## API

- `GET /api/settlement/collateralList`  
  - `searchFromDate`, `searchToDate`: 담보 **적용일**(`hold_start_date`, 없으면 생성일) 기준  
  - `searchCompId`, `searchCompNm`, `searchStatus`(전체/HOLD/RELEASED), `page`, `size`

## DB

- `pg-app/src/main/resources/db/V26_rolling_reserve_hold_meta.sql`  
  - `hold_start_date`, `hold_business_days`, `released_at`

## 로컬 확인

- 로그인 후 **정산관리 → 담보금내역** 메뉴 (http://localhost:8080/index.html)
- 담보 적립을 보려면 롤링 비율·일수가 0보다 크게 설정된 뒤 **정산 실행** 수행
