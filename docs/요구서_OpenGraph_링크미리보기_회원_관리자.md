# 요구서: URL 공유 시 링크 미리보기 (Open Graph)

**문서 성격:** 타 사이트(회원 페이지 + 관리자 페이지만 있는 서비스)에 전달하는 개발 요구서  
**기능 영문명:** Link Preview / Open Graph (OGP)  
**작성일:** 2026-09-16

---

## 1. 한 줄 요약

사이트 URL을 LINE, WhatsApp, KakaoTalk, Facebook, Slack 등에 붙여 넣을 때 나오는 **카드(제목·설명·썸네일)** 를,  
**회원(결제) 페이지**와 **관리자 페이지**가 **서로 다른 문구·이미지**로 나오게 한다.

조직별 도메인(총본사·본사·총판 URL)은 **이 요구 범위에 없다.**  
도메인은 하나(또는 동일 서비스)이고, 화면이 **회원용 / 관리자용 두 종류**만 있다.  
따라서 설정은 **두 벌**만 둔다. 조직마다 따로 입력하거나 「본사설정 따름」 상속은 넣지 않는다.

---

## 2. 배경 · 문제

메신저·SNS는 주소를 열지 않고, 서버가 처음 내려 주는 HTML `<head>`만 읽는다.  
`og:title`, `og:description`, `og:image`가 없으면 페이지 본문의 아무 문장(관리자 안내, API 키 설명 등)이 설명으로 붙는다.  
자바스크립트로 브라우저 탭 제목만 바꿔도 **미리보기에는 반영되지 않는다.**

회원(결제) URL과 관리자 URL을 공유했을 때 같은 제목이 나오면 안 된다.  
구매자에게는 결제·서비스 안내, 관리자에게는 관리 콘솔 안내가 나와야 한다.

---

## 3. 용어 (요청·검수 시 이 이름을 사용)

| 구분 | 용어 |
|------|------|
| 기능 | 링크 미리보기 (Link Unfurl / Link Preview) |
| 표준 | Open Graph Protocol (OGP) |
| 필수 태그 | `og:title`, `og:description`, `og:image`, `og:url`, `og:type` |
| 보조 | `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`, `meta name="description"` |
| 설정 A | **회원 페이지 미리보기** (결제·회원 공개 URL) |
| 설정 B | **관리자 페이지 미리보기** (관리 로그인·콘솔 URL) |

---

## 4. 범위

### 4.1 포함

- 회원(결제)용 URL과 관리자용 URL에 각각 독립된 제목·설명·이미지
- 관리 화면에서 두 벌을 저장·수정
- 서버가 해당 URL의 **최초 HTML**에 메타 태그를 출력
- 다국어(서비스가 쓰는 언어. 권장: 한국어·영어·일본어·중국어·태국어)

### 4.2 제외

- 총본사 / 본사 / 총판 등 **조직·도메인별 상속**, 「본사설정 따름」
- 가맹점마다 다른 미리보기 (요청하지 않음)
- 게시글·상품 단위 동적 OG (이번 범위 아님. 필요 시 별도 요구)

---

## 5. 설정 구조 (두 벌)

관리자 **사이트 설정 / 브랜드 / SEO** 등에 섹션을 **두 개** 둔다. 서로 복사하지 않고 각각 저장한다.

### 5.1 회원 페이지 미리보기 (Member / Payment)

**적용 URL 예**

- 결제 페이지, 회원 로그인, 공개 결제 링크, 결제 완료 안내 등 **구매자·회원이 여는 주소**

**항목**

| 항목 | 설명 | 권장 |
|------|------|------|
| 제목 | `og:title` | 60자 이내. 예: 서비스명 + 결제 |
| 설명 | `og:description` | 80~120자, 최대 200자. 결제·이용 안내. 내부 운영 문구 금지 |
| 이미지 | `og:image` | 권장 1200×630, PNG/JPG, HTTPS, 약 1MB 이하 |
| 언어별 제목·설명 | 서비스 지원 언어 | 기본 언어 1벌은 필수 |

이미지가 비면 회원 페이지 로고(또는 지정 기본 이미지)를 쓴다.  
설명이 비면 **짧은 기본 카피**만 쓰고, 페이지 본문 첫 문단을 긁지 않는다.

### 5.2 관리자 페이지 미리보기 (Admin)

**적용 URL 예**

- 관리자 로그인, 관리자 메인, `/admin`, `/console` 등 **운영자만 쓰는 주소**

**항목**은 회원 페이지와 동일 형식이나 **문구·이미지는 별도**.

예:

- 제목: `{서비스명} 관리자`
- 설명: 관리 콘솔 안내. API 키·내부 매뉴얼 문장 사용 금지
- 이미지: 관리 브랜드 로고 또는 별도 썸네일

---

## 6. URL 매핑 규칙

동일 도메인이라도 **경로(또는 서브경로)로 두 벌을 가른다.**

예시 (실제 경로는 해당 사이트에 맞게 치환):

| URL | 사용 설정 |
|-----|-----------|
| `/`, `/pay`, `/checkout`, `/member`, `/login` (회원) | 회원 페이지 미리보기 |
| `/admin`, `/admin/login`, `/manage` | 관리자 페이지 미리보기 |

한 경로가 애매하면 **기본은 회원**, 관리자 경로만 관리자 설정을 쓴다.  
매핑 표는 구현 전에 해당 사이트 URL 목록으로 확정한다.

---

## 7. 기술 요건 (필수)

1. 크롤러는 JavaScript를 실행하지 않는다. **서버 렌더링(또는 게이트웨이에서 HTML head 삽입)** 으로 메타를 넣는다. SPA에서 `document.title`만 바꾸면 실패로 본다.
2. 응답 첫 HTML `<head>`에 최소:
   - `og:title`, `og:description`, `og:image`, `og:url`, `og:type=website`
   - `twitter:card` = `summary_large_image`
   - `twitter:title`, `twitter:description`, `twitter:image` (og와 동일 내용)
   - `meta name="description"` (og:description과 동일)
3. `og:image`는 **절대 URL + HTTPS**. 로그인·쿠키 없이 HTTP 200으로 받을 수 있어야 한다.
4. 회원용 HTML과 관리자용 HTML이 서로 다른 og 값을 가진다.
5. 관리 화면 저장 값이 해당 URL 응답에 즉시(또는 짧은 캐시 후) 반영된다.

---

## 8. 다국어

제목·설명은 서비스가 지원하는 언어로 저장한다. 권장 5개: 한국어, 영어, 일본어, 중국어, 태국어.

크롤러 `Accept-Language`가 있으면 해당 언어, 없으면 **기본 언어(한국어 또는 서비스 기본)** 한 벌을 출력한다.

관리 화면 라벨·오류 메시지도 동일 언어 정책으로 넣는다.

---

## 9. 캐시 (운영 안내 필수)

LINE, Facebook, Kakao 등은 미리보기를 수 시간~수일 캐시한다.  
설정 저장만으로 메신저 카드가 바로 바뀌지 않을 수 있다.

배포·문구 변경 후:

- Facebook Sharing Debugger 등에서 해당 URL 재수집
- LINE 등 해당 플랫폼의 캐시 갱신 도구 사용

운영 매뉴얼에 「저장 ≠ 메신저 즉시 반영」을 명시한다.

---

## 10. 검수 체크리스트

- [ ] 회원(결제) URL을 메신저에 붙여 넣으면 **회원용** 제목·설명·이미지만 나온다.
- [ ] 관리자 URL을 붙여 넣으면 **관리자용** 제목·설명·이미지만 나온다.
- [ ] 두 카드의 제목·설명이 서로 다르다.
- [ ] 설명에 관리자 내부 문구(API 키 마스킹 안내 등)가 나오지 않는다.
- [ ] 이미지 클릭 없이 썸네일이 로드된다 (공개 HTTPS).
- [ ] 페이지 소스 보기에서 `<head>`에 og 태그가 보인다 (JS 실행 전).
- [ ] 언어별 저장 시 해당 언어 크롤러/기본 언어 정책과 일치한다.
- [ ] 캐시 갱신 후 LINE·WhatsApp에서 재확인한다.

## 11. 산출물

- 관리자 설정 화면: 「회원 페이지 미리보기」「관리자 페이지 미리보기」 두 섹션
- DB 또는 설정 저장소에 두 벌 레코드
- 회원 URL / 관리자 URL HTML head 메타
- 운영 가이드 1페이지 (캐시 갱신 포함)

---

## 12. 비고

- 브라우저 탭 이름과 링크 미리보기는 별개 기능이다. 둘 다 필요하면 탭 이름은 기존대로 두고, 본 요구는 **공유 카드 전용**이다.
- 이 요구서는 **단일 서비스 · 두 화면(회원/관리자)** 전용이다.  
  총본사·본사·총판처럼 **조직 도메인이 나뉘는 플랫폼**은 별도 요구(본사설정 따름·상속)를 쓴다.
