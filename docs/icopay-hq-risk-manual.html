0. 개요 · 메뉴 · 화면 구성

화면의 두 핵심 영역인 리스크설정과 리스크 필터링의 동작·항목·운영 절차를 코드 기준으로 정리합니다.

영역한 줄 요약
리스크설정동일 카드 비성공 누적 → 1~4차 대기(쿨다운) → N차 도달 시 비활성카드 자동등록
리스크 필터링PG 송부 전 이상 요청 사전 차단 + JPAY 사후 고위험·PY0124 쿨다운/현황 반영

0.1 진입

  1. 좌측 본사정책
  2. 허브 수수료·리스크 (/hq/hub/policy-fees)
  3. 탭 리스크 → /hq/riskCardPolicy

권한: 본사정책 → 접근·권한 → 본사권한설정에서 메뉴 M0129 부여.

0.2 화면 섹션

순섹션역할
1리스크설정본사 기본 트리거(위험관리 ON/OFF, 1~4차 대기, 자동등록 차수, 추적기간)
2리스크 필터링사전 필터·개별 규칙·속도제한·JPAY 사후 쿨다운
3가맹점 리스크 현황가맹별 적용 방식·실효 대기시간·등록 건수
4일괄운영관리조직·가맹 로그인/정책 일괄(본 매뉴얼 범위 외)
하단 [저장] 한 번으로 §1·§2 설정이 tb_hq_risk_card_policy(id=1)에 저장되며 즉시 적용됩니다(재배포·재시작 불필요).

1. 리스크설정 (카드 비성공 트리거 · 쿨다운)

1.1 목적

동일 가맹점에서 같은 카드로 FAIL·취소·무효·미결제 등 비성공이 반복되면:

  1. 1~4차 대기시간만큼 결제 시도를 일시 차단하고,
  2. 자동 등록 트리거 N차에 도달하면 비활성카드(마스킹)에 자동 등록해 이후 결제를 막습니다.

1.4 동작 흐름

결제 시도 ├─ 비활성카드 → 즉시 차단 (INACTIVE_CARD) ├─ 쿨다운 대기 중 → 잔여 분 안내 후 차단 └─ 통과 시 PG 결제 ├─ 성공 → 실패 누적·대기 초기화 └─ 비성공 확정 → 실패 횟수 +1 ├─ 횟수 < N → N차 대기시간 └─ 횟수 ≥ N → 비활성카드 자동등록

예시 (N=3): 1~3회 비성공 완료 → 즉시 비활성 등록 → 4번째 시도부터 차단.

추적기간동작

일 / 월 / 년설정기간 밖 실패는 삭제·미집계

2. 리스크 필터링 (사전 필터 · JPAY 사후)

2.1 목적

구분시점대상동작
사전승인 API 직전JPAY·ChillPay·Eximbay 등PG 미호출 + 취소(20) + 리스크 현황
사후JPAY pay_index 실패 후JPAY고위험·PY0124 쿨다운·현황
호스티드(카드번호 미수집) 흐름: 이메일·전화·성명·IP·이메일 속도 적용. 카드번호 기반(카드 속도·연락처 불일치)은 skip.

2.2 사전필터 사용

미사용이면 개별 사전 필터 전부 OFF. JPAY 사후 쿨다운은 독립.

2.3 판정 순서

① 비정상 이메일 → ② 비정상 전화번호 → ③ 의심 holder명 → ④ 카드 속도 → ⑤ 이메일 속도 → ⑥ IP 속도 → ⑦ 구매자 연락처 불일치

2.4 주요 항목

  • 비정상 이메일/전화 — 형식·자릿수·반복·연속 숫자 등
  • 의심 holder명 — GIFTCARD HOLDER, PAYPAY USER, VPRECA 등
  • 속도 제한 — 창(분)·횟수 공통(기본 10분 / 3회), 가맹 단위
  • 구매자 연락처 불일치 — 동일 카드 최근 거래와 비교
자동기억은 리스크 필터링이 아니라 본사정책 → 결제·URL → 결제창 표시 기본값 → 자동기억에서 설정합니다.

2.6 사전 차단 결과

  1. PG 미호출
  2. 전산 1회 시도 → 취소(20)
  3. 운영관리 → 리스크 현황 기록
  4. 구매자 다국어 안내
  5. errorCode=PRESALE_RISK_FILTER

현황 조회: 운영관리 → 리스크 현황 (/risk/list)

4. FAQ

리스크설정만 끄면 사전 필터도 꺼지나요?
아니요. 위험관리 사용과 사전필터 사용은 독립입니다.
가맹만 트리거를 끄고 싶어요.
업체관리 → 위험 정책 = 미사용. 사전 필터는 본사 공통입니다.
정상 고객이 속도제한에 걸려요.
리스크 현황에서 코드 확인 후 창↓·횟수↑ 또는 해당 항목 미사용.
연락처 불일치가 잦아요.
결제·URL → 자동기억=사용, 가맹은 본사따름.
차단인데 PG 로그가 없어요.
사전 필터 정상입니다(PG로 보내지 않음).
비활성 등록 후 풀어주려면?
비활성카드등록 → 해지(사유·OTP). 누적도 초기화됩니다.
