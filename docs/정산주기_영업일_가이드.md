# 정산주기 · 영업일 정책 (요약)

## 공통: 워킹데이

- **워킹데이(영업일)**: 본사(REGIONAL)에서 지정한 **영업일** 기준입니다. 공휴일·추가 휴일 등 **비영업일은 제외**합니다.

---

## D+N (일자 기준)

- **의미**: 정산 **도래일**이 계산되었을 때, 그 날짜가 **워킹데이가 아니면** **다음 가장 빠른 워킹데이**로 정산일이 **미뤄집니다**.
- **저장값**: `D1` … `D30` → 화면 `D+1` … `D+30`

---

## W+N (달력 주 + 워킹데이 정산일, 하이브리드)

- **W(집계 구간)**: **워킹데이와 무관**하게, **월요일 0시 ~ 일요일 24시(달력 1주)** 를 하나의 주기로 묶어 결제 내역을 집계합니다.
- **+N**: 그 주기 규칙에 따라 **정산 도래 시점**이 정해지며, **실제 정산일(지급·마감 기준일)** 은 **워킹데이**를 적용합니다. (도래일이 비워킹데이면 **다음 워킹데이**로 보정하는 것과 동일한 취지로 운영합니다.)
- **저장값**: `W3`, `W5`, `W7`, `W10`, `W14` → 화면 `W+3` … `W+14`

---

## WK+ 계열 (달력 주·수요일 지급, 하이브리드)

집계 구간(월~일)은 **달력 기준**이며 **워킹데이에 영향받지 않습니다**. **정산 실행일은 수요일**이며, **수요일이 비워킹데이인 경우**에는 **다음 워킹데이**로 미룹니다(일반 D+/W+ 정책과 동일한 워킹데이 보정).

| 저장값 | 화면 | 집계 구간 | 정산일(수요일) |
|--------|------|-----------|----------------|
| `WK1W` | WK+1W | 월~일 1주 | **익주** 수요일 |
| `WK2W` | WK+2W | 월~일 **2주(14일)** | **익주** 수요일 |
| `WK1WT` | WK+1WT | 월~일 1주 | **다다음주** 수요일 |
| `WK2WT` | WK+2WT | 월~일 **2주(14일)** | **다다음주** 수요일 |

## 기타 주기 (실시간·분·시간)

| 저장값 | 화면 | 비고 |
|--------|------|------|
| RT | 실시간 | |
| M5, M10 | 5분, 10분 | |
| H1, H2, H4 | 1·2·4시간 | |

실시간·분·시간 주기의 **정산일 보정**은 운영 규칙·배치 구현과 함께 적용합니다.

- 과거 `WEEKLY`, `WEEKLY2` 는 **선택 목록에서 제거**되었습니다. 기존 데이터는 마이그레이션 또는 가맹점 설정 변경으로 `WK+` 계열 등으로 옮기는 것을 권장합니다.

## 본사(REGIONAL) — 영업일 · 휴일

- **공휴일 기준 국가** (`holidayCountryCodes`): 예 `KR,US,JP,TH` — 4국 공휴일 프리셋 불러오기 지원.
- **추가 휴일** (`businessHolidayExtraDates`): 구간별 수동 등록 시 일자가 자동 펼쳐져 한 줄에 하나(`YYYY-MM-DD`)로 저장되며, 영업일에서 제외됩니다.
- **구간 메타** (`holidayManualEntries`): 시작·종료일, 구분(공휴일/국경일/기념일/종교휴일/임시공휴일/대체공휴일), 내용 — 본사설정 **영업일설정** 화면에서 관리.
- **등록자** (`createdBy`): 설정 프로필 최초 저장 시 로그인 아이디가 자동 기록됩니다.
- **12개월 달력 UI**: 본사설정 **영업일설정**에서 연도별 미니달력으로 휴일 표시(구분별 색).

### 영업일설정 목록 열 (공식 / 추가 / 총)

저장 필드 `businessHolidayExtraDates`에 있는 **서로 다른 비영업 일자**를 기준으로 집계합니다. (API 응답 시 서버가 `holidayCountOfficial` / `holidayCountAdditional` / `holidayCountTotal` 로 내려줍니다.)

- **공식공휴일**: 저장된 비영업일 중 **토요일·일요일**이거나, 기준국가의 **법정·프리셋**(`holiday-presets.json`)에 포함되는 일자.
- **추가공휴일**: 저장된 비영업일 중 위 공식에 해당하지 **않는** 일자(달력·구간으로만 추가한 평일 등).
- **총공휴일**: 저장된 비영업 일자 수(중복 1회). **공식 + 추가 = 총**.
- **GLOBAL**: 프리셋이 토·일만이므로 공식=저장일 중 주말, 추가=저장일 중 평일.
