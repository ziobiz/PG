# 정산주기 · 영업일 정책 (요약)

## 정산주기 코드 (저장값 → 화면)

| 저장값 | 화면 표시 | 비고 |
|--------|-----------|------|
| RT | 실시간 | |
| M5, M10 | 5분, 10분 | |
| H1, H2, H4 | 1·2·4시간 | |
| D1…D30 | D+1 … D+30 | 영업일 기준(본사 휴일 설정 반영) |
| W3, W5, W7, W10, W14 | W+3 … W+14 | 영업일 기준 |
| WEEKLY | Weekly | **일반일(달력)** 7일 마감(일→월 자정) 후 **익주 금요일** 정산 |
| WEEKLY2 | Weekly2 | **일반일** 2주 묶음 후 **익주 금요일** 정산 |

- **영업일 적용**: 실시간·분·시간·D+N·W+N 등 **대부분의 정산주기**는 본사에서 지정한 **영업일**(공휴일 제외)로 산정합니다.
- **예외**: **Weekly / Weekly2** 만 **달력일** 기준으로 동작하며, **금요일 고정** 지급 규칙을 따릅니다.

## 본사(REGIONAL) — 영업일 · 휴일

- **공휴일 기준 국가** (`holidayCountryCodes`): 예 `KR,US,JP,TH` — 4국 공휴일 프리셋 불러오기 지원.
- **추가 휴일** (`businessHolidayExtraDates`): 구간별 수동 등록 시 일자가 자동 펼쳐져 한 줄에 하나(`YYYY-MM-DD`)로 저장되며, 영업일에서 제외됩니다.
- **구간 메타** (`holidayManualEntries`): 시작·종료일, 구분(공휴일/국경일/기념일/종교휴일/임시공휴일/대체공휴일), 내용 — 본사설정 **영업일설정** 화면에서 관리.
- **등록자** (`createdBy`): 설정 프로필 최초 저장 시 로그인 아이디가 자동 기록됩니다.
- **12개월 달력 UI**: 본사설정 **영업일설정**에서 연도별 미니달력으로 휴일 표시(구분별 색).

### 영업일설정 목록 열 (공식 / 추가 / 총)

저장 필드 `businessHolidayExtraDates`에 있는 **서로 다른 비영업 일자**를 기준으로 집계합니다. (API 응답 시 서버가 `holidayCountOfficial` / `holidayCountAdditional` / `holidayCountTotal` 로 내려줍니다.)

- **공식공휴일**: 저장된 비영업일 중 **토요일·일요일**이거나, 기준국가의 **법정·프리셋**(`holiday-presets.json`)에 포함되는 일자.
- **추가공휴일**: 저장된 비영업일 중 위 공식에 해당하지 **않는** 일자(달력·구간으로만 추가한 평일 등).
- **총공휴일**: 저장된 비영업 일자 수(중복 1회). **공식 + 추가 = 총**.
- **GLOBAL**: 프리셋이 토·일만이므로 공식=저장일 중 주말, 추가=저장일 중 평일.
