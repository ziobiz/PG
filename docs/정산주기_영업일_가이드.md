# 정산주기 · 영업일 정책 (요약)

## 정산주기 코드 (저장값 → 화면)

| 저장값 | 화면 표시 | 비고 |
|--------|-----------|------|
| RT | 실시간 | |
| M5, M10 | 5분, 10분 | |
| H1, H2, H4 | 1·2·4시간 | |
| D1…D30 | D+1 … D+30 | 영업일 기준(본사 휴일 설정 반영) |
| W3, W5, W7, W10, W14 | W+3 … W+14 | 영업일 기준 |
| WEEKLY | Weekly | **일반일(달력)** 7일 마감(일→월 자정) 후 **익주 금요일** 정산 |
| WEEKLY2 | Weekly2 | **일반일** 2주 묶음 후 **익주 금요일** 정산 |

- **영업일 적용**: 실시간·분·시간·D+N·W+N 등 **대부분의 정산주기**는 본사에서 지정한 **영업일**(공휴일 제외)로 산정합니다.
- **예외**: **Weekly / Weekly2** 만 **달력일** 기준으로 동작하며, **금요일 고정** 지급 규칙을 따릅니다.

## 본사(REGIONAL) — 영업일 · 휴일

- **공휴일 기준 국가** (`holidayCountryCodes`): 예 `KR,US,JP,TH` — 4국 공휴일 프리셋은 정산 엔진 연동 시 반영(현재는 JSON 저장).
- **추가 휴일** (`businessHolidayExtraDates`): `YYYY-MM-DD` 한 줄에 하나 — 영업일에서 제외.
- **12개월 달력 UI**: 이후 단계에서 본사설정에 연간 달력·체크 UI를 붙일 수 있음(현재는 텍스트 입력).
