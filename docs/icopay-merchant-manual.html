✅ ICOPAY 통합 결제 플랫폼 안내

ICOPAY는 가맹점과 단일 계약을 맺은 통합 결제 플랫폼입니다. 개별 PG사(결제대행사)의 정보는 노출되지 않으며, 모든 결제·정산은 ICOPAY 브랜드로 통합 처리됩니다.

  • 포털 주소: https://icopay.co.kr
  • 결제 URL: https://icopay.co.kr/checkout/{업체코드}
  • 고객 지원: https://icopay.co.kr

📋 명명 원칙

ICOPAY는 단일 API 뒤에서 여러 결제망을 통합하는 플랫폼입니다. 본 매뉴얼의 기능(체크아웃, URL결제, 통합거래 등)은 ICOPAY 용어만 사용합니다. 가맹점·구매자 화면과 API에는 개별 결제대행사 이름을 노출하지 않습니다.

3. API 연동 (가맹점 API 포털)

가맹점API > 가맹점 API 포털

3-1. 공식 연동 자료 위치

본사가 API 배포를 완료하면, 업체관리 → 가맹점API 화면이 공식 연동 키·문서·샘플입니다. 별도 메일·파일로 문서를 받을 필요가 없습니다.

항목설명용도
업체코드(compId)가맹점 식별 코드API 요청 body / 쿼리
공개 API 베이스 URLICOPAY API 호스트서버 연동 Base URL
브로커 시크릿서버 간 통신용 비밀 키헤더 X-Icopay-Merchant-Broker-Secret
연동 빠른 시작·파라미터 표Prepare / buyer / Status 규격서버·프론트 개발
다운로드 자료흐름 설명서·JSON/PHP 샘플연동 구현 참고
⚠️ 브로커 시크릿 보안 주의: 브로커 시크릿은 절대 클라이언트(웹 브라우저·앱 코드)에 노출하지 마십시오. 반드시 서버 사이드에서만 사용해야 합니다. 재발급은 본사만 가능합니다.

3-2. Checkout API (ICOPAY 통합)

가맹점API 화면에 표시되는 엔드포인트·표를 기준으로 연동합니다. 주요 경로:

API 유형엔드포인트 경로설명
일회성 결제 (준비)/api/middleware/v1/merchant/checkout/prepare결제 세션 생성
일회성 결제 (세션)/api/middleware/v1/merchant/checkout/session세션 조회
결제 상태 조회/api/middleware/v1/merchant/checkout/status결제 결과 확인
구독 준비/api/middleware/v1/merchant/checkout/subscription/prepare구독 결제 시작
구독 해지/api/middleware/v1/merchant/checkout/subscription/cancel구독 취소 처리
리다이렉트 결제/api/middleware/v1/merchant/checkout/redirect/prepare리다이렉트 결제
모든 응답의 pgVendor 필드는 항상 ICOPAY입니다. 결제대행사(운영 PG) 이름은 노출되지 않습니다. 결제창은 /checkout/{compId} 또는 /v1/embed-checkout/{compId} 만 사용하세요.

3-3. 연동 개발 순서

①본사에 API 배포·브로커 시크릿 발급 요청
②가맹점API에서 키·빠른 시작·파라미터 표 확인
③가맹 서버에서 Prepare → 브라우저에 sessionToken/embed만 전달
④서버 Status API 또는 Webhook으로 PAID 확정

5. URL결제 (웹결제) 사용

결제관리 > URL결제내역

5-1. URL결제 링크 확인 및 공유

URL결제는 결제 페이지 링크를 고객에게 공유하여 온라인으로 결제를 받는 방식입니다.

결제 URL 형식: https://icopay.co.kr/checkout/{업체코드}
업체 코드는 업체관리 > 업체정보조회에서 확인할 수 있습니다.
①업체정보조회에서 URL결제 URL 확인
②URL 복사 버튼을 클릭하여 클립보드에 복사
③이메일, SNS, 문자메시지 등으로 고객에게 링크 전달
④고객이 링크 접속 → 결제 정보 입력 → 결제 완료

5-2. 결제창 미리보기

URL결제 내역 화면에서 실제 결제창이 어떻게 보이는지 미리 확인할 수 있습니다.

  • PC 화면 / 모바일 화면 미리보기 전환 가능
  • 업체 로고, 결제 버튼 텍스트 등 표시 내용 확인
  • QR 코드 생성 — 모바일 결제를 위한 QR 코드 다운로드

6. 구독결제 관리

결제관리 > 구독결제내역

6-1. 구독 현황 조회

구독결제내역에서 현재 진행 중인 모든 구독 현황을 확인할 수 있습니다.

구독 상태설명
활성(Active)정상적으로 진행 중인 구독
일시정지(Paused)구독이 일시 중단된 상태
해지(Cancelled)구독 해지 완료
만료(Expired)구독 기간 종료
결제실패(Failed)결제 시도 실패 상태
①구독결제내역 메뉴 진입
②기간, 상태, 구독자 이메일 등 조건으로 검색
③개별 구독 클릭 → 상세 정보 확인 (결제 이력, 다음 청구일 등)

6-2. 구독 해지 처리

①구독결제내역에서 해지할 구독 선택
②상세 화면에서 구독 해지 버튼 클릭
③해지 사유 입력 (선택)
④해지 확인 → 즉시 해지 처리 완료
구독 해지 후에는 다음 청구일에 결제가 발생하지 않습니다. 이미 결제된 현재 주기 금액은 환불되지 않습니다 (서비스 정책에 따라 상이할 수 있음).

6-3. 구독 결제 내역 조회

각 구독별 결제 이력을 상세히 확인할 수 있습니다.

  • 구독 시작일, 다음 청구일, 총 결제 횟수 확인
  • 회차별 결제 성공/실패 이력
  • 결제 실패 시 재시도 일정 확인
  • 구독 금액 변경 이력

11. 자주 묻는 질문 (FAQ)

환불 신청 후 고객에게 환불이 완료되기까지 얼마나 걸리나요?
환불 신청 후 처리까지 통상 영업일 기준 3~7일이 소요됩니다. 결제 수단(신용카드, 지갑이체, QR 등)과 결제 처리 시점에 따라 달라질 수 있습니다. 환불 처리 현황은 결제내역 > 환불 탭에서 확인하세요.
API 키(브로커 시크릿)를 분실하거나 노출된 것 같습니다. 재발급이 가능한가요?
브로커 시크릿 재발급은 본사만 할 수 있습니다. 노출이 의심되면 본사에 재발급을 요청하세요. 재발급 즉시 기존 시크릿은 무효화되므로 가맹 서버 설정을 새 시크릿으로 교체해야 합니다. 연동 규격·샘플은 가맹점API 화면에서 확인합니다.
구독 해지 요청을 받았습니다. 고객이 이미 결제한 금액도 환불해야 하나요?
구독 해지 시 남은 구독 기간에 대한 환불 여부는 가맹점의 서비스 정책에 따릅니다. 구독결제내역에서 해당 구독을 해지하고, 필요한 경우 결제내역에서 해당 결제 건에 대한 부분 환불 또는 전액 환불을 별도로 신청하세요.
정산은 언제 지급되나요? 정산 일정을 미리 알 수 있나요?
정산 주기(일별/주별/월별)와 지급일은 ICOPAY와의 계약 조건에 따릅니다. 정산관리 > 가맹점정산내역에서 다음 정산 예정일을 확인할 수 있습니다. 정산 일정 변경이 필요한 경우 ICOPAY 담당자에게 문의하세요.
비밀번호를 잊어버렸습니다. 어떻게 초기화하나요?
ICOPAY 로그인 화면의 비밀번호 찾기를 클릭하여 등록된 이메일로 재설정 링크를 받으세요. 이메일 접근이 불가한 경우 ICOPAY 고객 지원(https://icopay.co.kr)으로 연락하여 본인 확인 후 비밀번호를 초기화할 수 있습니다.
결제 통보(Webhook/Notify) URL은 어디서 설정하나요?
결제 통보 URL 설정은 가맹점 포털에서 직접 변경할 수 없으며, ICOPAY 운영팀에서 관리합니다. 통보 URL 등록 또는 변경이 필요하면 ICOPAY 담당자에게 요청하세요. API를 통한 결제 상태 확인은 /api/middleware/v1/merchant/checkout/status로 직접 조회 가능합니다.
챗봇 상품 등록이 안 됩니다. 슬롯이 꽉 찼다는 메시지가 나옵니다.
계약 시 설정된 상품 슬롯 한도에 도달한 경우입니다. 기존 상품 중 사용하지 않는 것을 비활성화하거나 삭제하여 슬롯을 확보하거나, ICOPAY 담당자에게 슬롯 한도 증가를 요청하세요.
결제 내역을 엑셀로 다운로드할 수 있나요?
결제내역, URL결제내역, 구독결제내역, 정산내역 등 주요 조회 화면에서 CSV 내보내기 또는 엑셀 다운로드 버튼을 통해 데이터를 내보낼 수 있습니다. 조회 조건을 설정한 후 내보내면 필터링된 데이터만 다운로드됩니다.
분할결제 계약 중 고객이 한 회차 결제를 하지 않았습니다. 어떻게 처리하나요?
분할관리 > 진행관리에서 해당 계약의 미완료 회차를 확인하세요. 해당 회차의 결제 URL을 복사하여 고객에게 재전송할 수 있습니다. 결제 기한이 초과된 경우 이메일관리에서 재발송 처리를 하거나 ICOPAY 담당자에게 연체 처리 방법을 문의하세요.
