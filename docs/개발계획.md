# PG 솔루션 개발 계획

> 목표: **https://fxhj.soonpay.co.kr** 과 동일한 메뉴·기능을 가진, 더 나은 PG 통합관리자 솔루션 개발.  
> 참고: `output/fxhj-main-after-login.html`, `docs/메뉴_분석_및_연결구조.md`, `docs/menu-structure.json`

---

## 1. 진행 원칙

- **메뉴 구성**: fxhj와 **동일한 구조·형태**로 구축 (이미 반영됨)
- **기능**: 우선 fxhj와 **동일한 기능**으로 구현 → 이후 추가/수정 요청 반영
- **참고 소스**: 기존에 준 소스(저장된 HTML, 분석 문서)에서 필요한 내용 참고하여 개발

## 3. 구현 순서 (완료)

1. **로그인 화면** (fxhj와 동일한 항목: 아이디, 비밀번호, OTP, 초기비밀번호 변경 modal, 사칭 안내) — 구현 완료
2. **업체관리** — 구현 완료
3. **결제관리** — 구현 완료
4. **정산관리** — 구현 완료
5. **통보관리** — 구현 완료
6. **사용자관리** — 구현 완료

각 화면은 검색/필터 폼, 요약 라벨, 버튼(검색·엑셀다운로드·정산확정 등), 그리드, 페이지네이션 구조로 fxhj와 동일하게 구현됨.
