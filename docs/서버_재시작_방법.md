# 서버 재시작 방법 (파일 올린 후)

파일을 FTP로 올린 뒤 **pg-app(백엔드)** 를 재시작해야 변경 내용이 반영됩니다.

---

## 방법 1: 스크립트로 한 번에 (가장 쉬움)

### 1단계: 스크립트 준비 (최초 1번)

1. `server-scripts/restart-pg-app.sh` 파일을 서버의 **pg-app 폴더**에 FTP로 업로드
2. SSH로 서버 접속
3. 아래 명령 실행:

```bash
cd /root/pg-app
chmod +x restart-pg-app.sh
nano restart-pg-app.sh
```

4. `DB_PASSWORD="비밀번호"` 를 실제 DB 비밀번호로 수정 후 저장 (Ctrl+O, Enter, Ctrl+X)

### 2단계: 재시작할 때마다

SSH 접속 후:

```bash
cd /root/pg-app
./restart-pg-app.sh
```

끝.

---

## 방법 2: 명령어 직접 입력

SSH로 서버 접속한 뒤, 아래를 **순서대로** 실행:

```bash
# 1) 기존 앱 종료
pkill -f pg-app-0.0.1-SNAPSHOT.jar

# 2) 3초 대기
sleep 3

# 3) pg-app 폴더로 이동 (경로는 본인 서버에 맞게)
cd /root/pg-app

# 4) DB 비밀번호 설정 (비밀번호를 실제 값으로 변경)
export DB_PASSWORD=실제비밀번호

# 5) 앱 다시 실행
nohup java -jar build/libs/pg-app-0.0.1-SNAPSHOT.jar --server.port=8080 &
```

---

## pg-app 폴더 경로가 다른 경우

서버에서 pg-app이 `/home/ftpuser/pg-app` 등 다른 경로에 있으면:

- 방법 1: 스크립트 안의 `PG_APP_DIR="/root/pg-app"` 를 실제 경로로 수정
- 방법 2: `cd /root/pg-app` 를 `cd /home/ftpuser/pg-app` 처럼 실제 경로로 변경

---

## Java 파일만 수정했을 때 (재빌드 필요)

**Java 소스**를 수정해서 올렸다면, 재시작 전에 **다시 빌드**해야 합니다:

```bash
cd /root/pg-app
./gradlew bootJar
```

빌드 완료 후 위 **방법 1** 또는 **방법 2**로 재시작.

**site 폴더(HTML, JS, CSS)** 만 수정했다면 빌드 없이 **FTP 업로드만** 하면 됩니다. (pg-app 재시작 불필요)

## API 406 오류 / Nginx SSL 설정 (최초 1번)

api.icopay.co.kr 에서 406 Not Acceptable 이 나오거나 SSL 인증서가 없을 때:

1. `server-scripts/setup-api-nginx-ssl.sh` 를 서버 `/home/ftpuser/pg-app/` 에 FTP 업로드
2. SSH 접속 후:
   ```bash
   cd /home/ftpuser/pg-app
   chmod +x setup-api-nginx-ssl.sh
   sed -i 's/\r$//' setup-api-nginx-ssl.sh
   sudo ./setup-api-nginx-ssl.sh
   ```
3. 스크립트가 HTTP 설정 적용 → Nginx 재시작 → Certbot 설치 → SSL 발급 → 완료
