# 목록 그리드 컬럼 규칙

## 공통 (업무 목록)

체크박스 다음 컬럼 순서를 기본으로 합니다.

1. **번호** — `rowNo` (페이지네이션 기준 연번, 클라이언트에서 부여)
2. **업체명** — `compNm` (PG사·본사 권한 등 예외 화면은 동일 라벨로 `pgNm`·`hqNm` 등 필드 매핑)
3. **업체코드** — `compId` (또는 `pgCd`·`hqCd`·허용코드 `compCode` 등)

### 결제내역(`/calc/payList` 계열)

앞쪽 고정 순서:  
번호 → 업체명 → 업체코드 → 거래일 → 거래시간 → **Route No** → TransactionId(칠페이) → …  

`Route No`·거래일·거래시간은 **VIEW SETTING**에서 번호·업체명·업체코드와 같이 기본 고정 항목으로 두어 항상 노출됩니다 (`screens.js` `renderTableColumnGuide`의 `fixedKeys`).

## 정산 화면 동기화

- `/settlement/franchiseList` → `/calc/calcGmList`와 동일 API·그리드 (`screens.js` `mirrorSettlementScreensToCalc`)
- `/settlement/distributionList` → `/calc/calcList`와 동일
- `/calc/exCalcList` → `/settlement/execute`와 동일

## 백엔드

- 정산 실행 행(`toMap`), 보류 목록(`holdList`) 등에 `compNm`을 넣어 그리드와 맞춤.
