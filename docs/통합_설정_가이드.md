# icopay.co.kr 통합 설정 (api.icopay.co.kr 406 해결)

**api.icopay.co.kr** 대신 **icopay.co.kr** 하나에서 사이트+API 모두 사용합니다.

---

## 1. config.js (완료)

- `PG_API_BASE = ''` 로 변경됨 → API 호출이 같은 도메인(icopay.co.kr)으로 감
- **FTP로 site/js/config.js 업로드** 필요

---

## 2. icopay.co.kr Nginx 설정

서버에서 icopay.co.kr 설정 파일 위치 확인:

```bash
grep -r "icopay.co.kr" /etc/nginx/
```

또는:

```bash
ls /etc/nginx/conf.d/
ls /etc/nginx/sites-enabled/
```

### 설정 파일에 /api/ 블록 추가

`/etc/nginx/conf.d/icopay.conf` 또는 `sites-enabled/icopay` 등 icopay 설정 파일을 열고,  
`location /` 블록 **앞에** 아래를 추가:

```nginx
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Accept "application/json";
    }
```

### icopay 설정이 없을 때

`/etc/nginx/conf.d/icopay.conf` 생성 후 server-config/nginx-icopay.conf 내용 복사

---

## 3. 적용

```bash
sudo nginx -t
sudo systemctl restart nginx
```

---

## 4. 사용 방법

- **로그인**: https://icopay.co.kr/login.html
- **API**: https://icopay.co.kr/api/... (자동 호출)
- **api.icopay.co.kr** 사용 안 함

---

## 5. icopay.co.kr SSL

icopay.co.kr에 Let's Encrypt 인증서가 없다면, Cloudflare Origin Certificate를 사용하거나  
기존 api.icopay.co.kr용 Origin 인증서에 icopay.co.kr을 포함해 사용할 수 있습니다.
