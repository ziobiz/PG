  • 본사설정 — 전체 접근 불가
  • 정산관리 — 통합정산, 정산실행, 정산배포, 정산대기 접근 불가

  • 운영관리 — 운영관리, TAX 리포트, 검증 리포트, 대행거래내역 접근 불가
  • 배포설정 — API 배포문서만 접근 가능, 나머지 전체 불가
  • 분할관리 — 이메일 설정 접근 불가

1. 가맹점 등록

업체관리 > 업체등록 / 업체정보

1-1. 가맹점 신규 등록 절차

①업체관리 > 업체등록 메뉴 진입
②업체 기본 정보 입력 — 업체명, 사업자번호, 대표자명, 연락처, 이메일, 주소
③정산 구조 설정 — 정산 주기, 수수료율, 정산 은행 계좌 입력
④사용할 결제 서비스 활성화 (각 서비스별 설정은 아래 섹션 참조)
⑤저장 → 업체 코드(slug) 자동 생성 → 결제 URL 확인
⑥가맹점 계정(ID·임시 비밀번호) 생성 후 가맹점 담당자에게 전달

1-2. 업체 등록 시 활성화 가능한 결제 서비스

서비스활성화 항목명비고
웹결제 (URL결제)웹결제사용여부 Y/NChillPay 연동 기반
구독결제구독결제사용여부 Y/N정기 결제 플랜 설정 필요
재구매결제재구매결제사용여부 Y/N기존 결제 수단 재사용
URL 분할결제분할결제사용여부 Y/N분할관리에서 계약 추가 설정 필요
챗봇결제챗봇결제사용여부 Y/N챗봇관리에서 추가 설정 필요
활성화 여부(Y)로 설정해야만 해당 서비스 결제 URL이 가맹점 포털에서 표시됩니다. 비활성화(N) 상태에서는 URL이 숨겨져 가맹점이 사용할 수 없습니다.

1-3. 가맹점 계정 관리

사용자관리 > 가맹점 계정
  • 가맹점 ID 설정 및 임시 비밀번호 발급
  • 계정 활성/비활성 전환
  • 비밀번호 초기화
주의: 사용자관리 내 메뉴별 항목 순서 관리는 총본사 전용 메뉴로 총판은 접근할 수 없습니다.

2. 수수료 설정

ICOPAY 수수료 체계는 기본 정책수수료(시스템 전체 기준)와 가맹점별 개별 수수료(특정 가맹점 적용) 두 단계로 구성됩니다.

수수료 유형메뉴 경로접근 가능
기본 정책수수료 (시스템 기본값)본사설정 > 수수료설정❌
가맹점별 개별 수수료업체관리 > 수수료관리✅
🔒 기본 정책수수료(본사설정 > 수수료설정) 접근 불가
본사설정 메뉴는 총본사(슈퍼관리자) 전용입니다. 기본 수수료 정책 변경이 필요한 경우 총본사에 요청하십시오.

2-1. 가맹점별 개별 수수료 설정

업체관리 > 수수료관리

특정 가맹점에만 적용되는 개별 수수료율을 설정합니다. 기본 정책수수료보다 다른 조건이 필요한 가맹점에 사용됩니다.

①업체관리 > 수수료관리 메뉴 진입
②수수료를 설정할 가맹점 선택
③결제 수단별 개별 수수료율 입력
④적용 기간(시작일·종료일) 설정 (기간 지정 프로모션 수수료 적용 가능)
⑤저장 → 해당 가맹점에만 즉시 적용
항목설명
가맹점별 수수료율기본 정책과 다른 개별 수수료율 (%)
결제 수단별 설정신용카드·지갑이체·QR 별 수단별 개별 적용
적용 기간 설정기간 지정 수수료 조건 설정
수수료 변경 이력 조회가맹점별 수수료 변경 이력 확인
가맹점별 개별 수수료가 등록되면 기본 정책수수료보다 우선 적용됩니다. 개별 수수료 미등록 가맹점은 자동으로 기본 정책수수료가 적용됩니다.

3. 웹결제 사용 설정

업체관리 > 업체정보 > 결제설정 탭

3-1. 웹결제 활성화 설정

①업체관리 > 업체정보에서 해당 가맹점 선택
②결제설정 탭 → 웹결제사용여부를 Y로 변경
③저장 → 웹결제 URL(https://icopay.co.kr/pay/{업체코드}) 자동 생성·표시
④생성된 URL을 가맹점에 안내하거나 결제 페이지에 적용

3-2. 웹결제 주요 설정 항목

항목설명
웹결제사용여부웹결제 URL 활성화 여부 (Y/N)
웹결제 URL가맹점 전용 결제 링크 — 자동 생성
결제 통화 설정THB, USD, KRW 등 결제 수락 통화
리디렉션 URL결제 후 고객 이동 페이지

통보관리 메뉴는 총판 역할로 접근할 수 없습니다. 결제 통보 URL 변경이 필요하면 총본사에 요청하십시오.

3-3. 결제 내역 조회

결제관리 > 결제 내역
  • 거래 조회 조건: 기간, 가맹점, 결제 수단, 상태(성공/실패/취소)
  • 환불 처리: 결제 내역 상세 → 환불 신청
  • 영수증 재발송: 결제 상세에서 이메일 재발송

4. 구독결제 설정

업체관리 > 업체정보 > 결제설정 탭

4-1. 구독결제 활성화

①업체정보 → 결제설정 탭 → 구독결제사용여부 Y 설정 후 저장
②구독 플랜 설정: 플랜명, 결제 주기(월/연), 금액, 통화 등록
③구독 URL 생성 → 가맹점이 해당 URL을 통해 고객 구독 유도
④구독 결제는 등록된 주기에 따라 자동 청구됨

4-2. 구독결제 주요 설정 항목

항목설명
구독결제사용여부구독결제 기능 활성화 (Y/N)
결제 주기월간(Monthly) / 연간(Yearly) 선택
구독 금액1회 청구 금액 및 통화
구독 만료 처리만료 시 자동 해지 or 갱신 설정
구독 내역 조회가맹점별 구독자 목록 및 결제 이력
구독결제는 최초 1회 결제 시 고객 카드 정보를 토큰으로 저장한 뒤, 이후 주기에 따라 자동 청구합니다.

4-3. 구독 내역 조회 및 관리

결제관리 > 구독 내역
  • 구독 상태 조회: 활성 / 일시정지 / 해지 / 만료
  • 구독 즉시 해지 처리
  • 결제 실패 구독 재시도 설정
  • 다음 청구일 확인 및 일정 변경

5. 재구매결제 설정

업체관리 > 업체정보 > 결제설정 탭

5-1. 재구매결제란?

재구매결제는 고객이 이전 결제 시 등록한 결제 수단(카드 토큰)을 재사용하여, 새로운 결제를 간편하게 처리하는 기능입니다.

재구매결제는 최초 결제 시 카드 토큰이 저장된 고객에게만 적용됩니다. 구독결제와의 차이점: 구독은 주기별 자동 청구, 재구매는 고객이 직접 재결제를 선택하는 방식입니다.

5-2. 재구매결제 활성화

①업체정보 → 결제설정 탭 → 재구매결제사용여부 Y 설정 후 저장
②활성화 시 가맹점 결제창에 "이전 카드로 결제" 옵션이 노출됨
③고객이 재구매 선택 시 저장된 토큰으로 즉시 결제 처리

5-3. 재구매결제 주요 설정 항목

항목설명
재구매결제사용여부재구매결제 기능 활성화 (Y/N)
토큰 유효기간카드 토큰 보관 기간 (일 단위)
재구매 결제 내역재구매 거래 조회·환불
보안 주의: 카드 토큰은 PCI-DSS 규정에 따라 암호화 저장됩니다. 실제 카드번호는 저장하지 않습니다.

6. URL 분할결제 설정

분할결제 이메일 템플릿·발송 서버 설정은 총판 역할로 접근할 수 없습니다. 총본사에 요청하십시오.

  • 계약별 회차 결제 현황 — 완료 / 미결제 / 지연
  • 개별 회차 결제 강제 처리 또는 취소
  • 분할결제 완료 계약 정산 내역 연동

7. 챗봇결제 설정

챗봇관리
✅ 챗봇관리는 총판 역할도 전체 접근 가능합니다 (삭제 포함).

7-1. 가맹점 챗봇결제 활성화

①업체정보 → 결제설정 탭 → 챗봇결제사용여부 Y 설정 후 저장
②챗봇관리 메뉴 → 해당 가맹점 선택
③운영 모드 선택
④상품 슬롯 수 설정 (가맹점 등록 가능 상품 최대 수량)
⑤챗봇 결제 URL(https://icopay.co.kr/chatbot-pay/{업체코드}) 확인 후 가맹점 안내

7-2. 챗봇 운영 모드

운영 모드설명결제 방식
SALE_PREPAID판매 — 선불주문 즉시 결제 후 상품 제공
SALE_POSTPAID판매 — 후불상품 제공 후 결제 청구
RESERVATION_PREPAID예약 — 선불예약 시 즉시 결제
RESERVATION_POSTPAID예약 — 후불예약 후 현장 결제
HYBRID_RESERVATION_PREPAID하이브리드 예약 — 선불예약금 선결제 + 잔금 후불
FACE_TO_FACE_POSTPAID대면 — 후불현장 서비스 후 결제 링크 발송

7-3. 상품 관리

챗봇관리 > 상품관리
①가맹점 선택 → 상품 목록 진입
②상품 등록: 상품명, 설명, 가격, 이미지, 카테고리, 재고 여부 입력
③상품 활성화/비활성화 (챗봇 내 노출 여부 제어)
④상품 슬롯 한도 초과 시 추가 등록 불가 → 슬롯 수 조정 필요

7-4. KB(지식베이스) 관리

챗봇관리 > KB 관리

  • 카테고리별 문서 업로드
  • AI 학습 데이터 최적화 트리거
  • 답변 품질 점수 확인

7-5. 챗봇 주문 내역 조회

챗봇관리 > 주문 내역
  • 주문 번호·고객 정보·결제 상태·금액·일시 조회

자주 묻는 질문 (FAQ)

통보관리 메뉴가 보이지 않습니다.
통보관리는 총본사 전용 메뉴입니다. 결제 통보 URL이나 알림 설정 변경이 필요하면 총본사(슈퍼관리자)에게 요청하십시오.
분할결제 이메일 설정이 비활성화되어 있습니다.
분할관리 > 이메일 설정은 총본사만 접근 가능합니다. 이메일 템플릿 변경이 필요하면 총본사에 문의하십시오.
가맹점에 결제 서비스를 활성화했는데 가맹점이 URL을 볼 수 없다고 합니다.
업체정보에서 해당 서비스의 사용여부가 Y로 설정되어 있는지 확인하십시오. N 상태이면 가맹점 포털에 URL이 표시되지 않습니다.
챗봇결제 상품을 더 이상 추가할 수 없습니다.
가맹점의 상품 슬롯 한도에 도달한 경우입니다. 업체정보 > 챗봇설정에서 상품 슬롯 한도를 상향 조정하십시오.
정산실행·정산배포 메뉴가 보이지 않습니다.
정산실행·정산배포·정산대기·통합정산은 총본사 전용 메뉴입니다. 정산 처리가 필요한 경우 총본사에 요청하십시오.
API 배포문서는 어디서 확인하나요?
배포설정 > API 배포문서에서 확인할 수 있습니다. 본사 역할도 이 메뉴는 접근 가능합니다.
