## 1. V2.0 개요

| 구분 | LEGACY (이전) | V2.0 (기본) |
|------|---------------|-------------|
| 본사설정 | 개별 메뉴 나열 | **본사정책** 허브 (탭 통합) |
| 배포설정 | 개별 메뉴 나열 | **연동·배포** 허브 |
| 권한·URL | DB `menu_id` / `formurl` | **동일** (변경 없음) |

V2.0은 **기존 화면 HTML·API·권한 키를 그대로** 쓰고, 사이드바와 탭 shell만 허브로 묶습니다.

## 3. LEGACY 즉시 복원

```javascript
localStorage.setItem('pg_menu_layout', 'LEGACY'); location.reload();
```

또는 URL: `https://icopay.co.kr/?menu=legacy`

### V2.0 다시 켜기

```javascript
localStorage.setItem('pg_menu_layout', 'B'); location.reload();
```

또는: `https://icopay.co.kr/?menu=b`

> LEGACY HTML은 최초 V2.0 로드 시 `sessionStorage`에 백업됩니다.

## 4. 버전 정책

| 변경 규모 | 버전 | 예 |
|-----------|------|-----|
| 메뉴·API·아키텍처 등 큰 변화 | 메이저 | V2.0 → V3.0 |
