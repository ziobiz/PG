## 목적
총판 운영자에게 **리스크설정**·**리스크 필터링**의 **시스템 기본값** 기준으로, 트리거가 **언제·어떻게** 발동하는지 설명합니다.

## 기본값 요약
| 영역 | 기본 | 발동 |
|------|------|------|
| 리스크설정 1~3차 | 5분 / 10분 / 1시간 | 동일 카드 비성공 누적 쿨다운 |
| 자동 비활성 | 4회 | 비활성카드 등록(해제 전까지) |
| 속도 제한 | 카드 10분/3 · 이메일 30분/5 · IP 15분/10 | 창 내 횟수 초과 시 사전 차단 |
| 필터 스위치 | 전부 사용 | PG 송부 전 차단 · 리스크 현황 |
