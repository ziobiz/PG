1. 챗봇결제란?

ICOPAY 챗봇결제는 AI 챗봇이 고객과 대화하며 상품 안내 → 주문 수집 → 결제까지 한 흐름으로 처리해 주는 서비스입니다. 별도 쇼핑몰·앱 없이 챗봇 URL 하나로 온라인 판매·예약·결제를 운영할 수 있습니다.

고객 결제 흐름 (예: 선불 판매)

고객→가맹점이 배포한 챗봇 URL 접속 (링크 클릭 / QR 스캔)
AI 챗봇→가맹점이 등록한 상품 안내 및 선택 유도
고객→상품 선택 + 주문 정보 입력
AI 챗봇→결제 페이지로 안내
고객→카드 결제 완료
가맹점→주문관리 화면에서 주문 내역 조회

가맹점이 직접 운영하는 범위

가맹점 직접 가능본사(HQ)가 설정
챗봇 운영방식·업종·예약 설정챗봇결제 활성화 여부 (사용/미사용)
상품 등록·수정·삭제상품 등록 한도 설정
주문 내역 조회결제 승인 이메일·LINE 알림 설정
챗봇 URL·QR·스크립트 확인·복사업체 기본 정보 변경

3. STEP 1 내 챗봇결제 정보 확인 (조회 전용)

업체관리 > 내 업체정보
이 화면은 조회 전용입니다. 가맹점은 이 페이지에서 정보를 확인하고 복사할 수 있지만, 내용을 직접 변경할 수는 없습니다.

3-1. 챗봇결제 URL 확인 및 복사

본사가 챗봇결제를 활성화하면 아래 형식의 URL이 자동으로 표시됩니다.

https://pay.icopay.co.kr/chatbot-pay/{업체코드}
동작방법
URL 복사URL 입력 필드 옆의 복사 버튼 클릭 → 클립보드에 저장
QR코드 저장QR 이미지 옆의 저장 버튼 클릭 → PNG 파일로 다운로드
챗봇결제가 본사에서 미사용으로 설정된 경우, URL이 표시되지 않습니다. 본사 담당자에게 활성화를 요청하세요.

3-2. 홈페이지 플로팅 위젯 스크립트 복사

홈페이지에 챗봇 아이콘을 표시하려면, 내 업체정보에서 챗봇 플로팅 위젯 코드를 복사합니다.

<!-- 복사된 코드 예시 — 모든 페이지의 </body> 직전에 붙여넣기 -->
<script src="https://pay.icopay.co.kr/v1/embed-chatbot/{업체코드}"
        async defer charset="utf-8"></script>
내 업체정보 화면에서 복사 버튼을 누르면 업체코드가 포함된 완성 코드를 바로 복사할 수 있습니다.

3-3. QR코드 활용

  • 저장한 PNG 파일을 인쇄소에 전달하거나 포스터·명함 제작에 사용
  • 매장 내 테이블 카드, 안내판, 메뉴판 등에 부착
  • 고객이 QR 스캔 → 챗봇 결제 페이지로 바로 이동

4. STEP 2 챗봇 기본설정 ✔ 가맹점 직접 운영

챗봇관리 > 기본설정
이 메뉴는 가맹점이 직접 설정·저장할 수 있습니다.

4-1. 운영방식 선택

업종과 결제 시점에 맞는 방식을 선택하면 AI가 그에 맞는 대화 흐름으로 고객을 안내합니다.

운영방식설명적합 업종 예시
상품판매 · 선불상품 선택 후 즉시 결제온라인 쇼핑몰, 굿즈 판매
상품판매 · 후불주문 접수 후 나중에 결제주문 제작, B2B 납품
예약방식 · 선불예약 시 즉시 결제마사지, 헤어샵, 스터디룸
예약방식 · 후불예약 접수 → 방문 후 결제레스토랑, 컨설팅
하이브리드 (판매+예약)일반 판매 + 예약 상품 혼용복합 서비스업
대면거래 (판매+예약·후불)현장 확인 후 결제VIP 클럽, 대면 서비스

4-2. 업체성격 선택

AI 챗봇이 업종에 맞는 질문 흐름을 자동 구성합니다. 가맹점의 업종에 가장 가까운 항목을 선택하세요.

업체성격AI 응대 특성
일반판매 / 이커머스상품명·수량·배송지 중심으로 수집
마사지 (일반·클럽)예약 날짜·시간·코스·인원 수집
음식점 / 레스토랑방문 인원·날짜·시간·특이사항 수집
컨설팅 / 서비스업상담 주제·희망 일정·연락처 수집
부동산 / 자동차판매관심 매물·예산·방문 가능일 수집
VIP 클럽멤버십·예약 코스 중심 안내
업체성격 보조 메모 (선택): 반드시 수집해야 할 정보나 AI가 피해야 할 표현을 자유 텍스트로 입력하면 응대에 반영됩니다.

4-3. 업체 기본 안내 정보

AI가 고객 문의에 답변할 때 참조하는 정보입니다. 비워두면 업체등록 정보와 동일하게 안내됩니다.

  • 업체명 / 주소 / 전화번호
  • 영업시간
  • 기타 안내사항 (주차, 대중교통 등)

4-4. 예약 설정 (예약방식 운영 시)

항목설명
예약 기본 슬롯 (분)예약 단위 시간: 15 / 30 / 45 / 60 / 90 / 120 / 180 / 240분 중 선택
상품별로 다른 슬롯이 필요하면 상품관리에서 개별 설정 가능
예약 타임존 (IANA)예약 기준 시간대 입력 (기본값: Asia/Seoul)
같은 날짜·시간대에 이미 예약이 있으면 AI가 자동으로 다른 시간을 안내합니다. 슬롯 단위로 중복 예약이 자동 차단됩니다.

8. 운영방식별 사용 흐름

선불 방식 — 즉시 결제

고객→챗봇 URL 접속
AI→가맹점이 등록한 상품 안내
고객→상품 선택 + 주문 정보 입력
AI→결제 화면 안내 → 카드 결제 완료
가맹점→주문관리 화면에서 주문 조회 (본사 설정에 따라 이메일/LINE 알림 수신)

후불 방식 — 주문 접수 후 별도 결제

고객→챗봇 URL 접속 → 상품 선택·주문 정보 입력
가맹점→주문관리에서 주문 확인 → 고객 연락
결제→현장·계좌이체 등 별도 방법으로 처리

예약 방식 — 날짜·시간 선택

고객→챗봇 URL 접속
AI→예약 가능한 날짜·시간 안내 (기본설정의 슬롯 기준)
고객→날짜·시간·인원 선택 + 개인정보 입력
선불→즉시 결제 완료 → 예약 확정
후불→예약 접수 → 방문 후 결제
가맹점→주문관리에서 예약 일시·고객 정보 조회
