🔒 HQ Admin Access Restrictions

HQ Admin cannot access the following menus. Contact the Super Admin for these functions.

  • HQ Settings — No access
  • Settlement Mgmt — Integrated Settlement, Run Settlement, Distribute Settlement, Pending Settlement: No access
  • Notification Management — No access (includes Notify URL and alert settings)
  • User Management — Menu item order management: No access
  • Operations Management — Operations Mgmt, TAX Report, Verification Report, Agency Transaction History: No access
  • Deploy Settings — Only API Documentation accessible; all other deploy menus: No access
  • Split Pay Management — Email Settings: No access

1. Merchant Registration

Merchant Mgmt > Register Merchant / Merchant Info
①Go to Merchant Mgmt > Register Merchant
②Enter basic info — name, registration number, representative, contact, email, address
③Configure settlement structure — cycle, fee rate, bank account
④Activate desired payment services
⑤Save → merchant code auto-generated → review payment URL
⑥Create merchant account (ID + temp password) and deliver to merchant
ServiceActivation FieldNotes
Web PaymentWeb payment enabled Y/NChillPay integration

Setting a service to Y shows its URL in the merchant portal. N hides the URL.
Note: Menu item order management within User Management is Super Admin only.

3. Web Payment Setup

Merchant Mgmt > Merchant Info > Payment Settings tab
①Select merchant in Merchant Mgmt > Merchant Info
②Set Web payment enabled to Y
③Save → URL auto-generated (https://icopay.co.kr/pay/{merchant-code})
④Share URL with merchant
🔒 Notify URL setting is Super Admin only.
HQ Admin cannot access Notification Management. Request changes from the Super Admin.
  • Filter transactions by date, merchant, payment method, status
  • Process refunds from transaction detail
  • Re-send receipt email

4. Subscription Payment Setup

Merchant Mgmt > Merchant Info > Payment Settings tab
①Set Subscription enabled to Y and save
②Configure plan: name, billing cycle (monthly/yearly), amount, currency
③Share subscription URL with merchant
④System auto-charges per configured cycle
Tokenizes the card on first payment, then auto-charges each cycle.

5. Re-purchase Payment Setup

Merchant Mgmt > Merchant Info > Payment Settings tab

Re-purchase lets customers reuse a saved payment token without re-entering card details.

①Set Re-purchase enabled to Y and save
②Checkout shows "Pay with saved card" option
③Customer selects re-purchase → instant payment via saved token
Security: Card tokens encrypted per PCI-DSS. Actual card numbers not stored.

6. URL Split Payment Setup

Split Pay Management
🔒 Split Pay Mgmt > Email Settings is Super Admin only.
HQ Admin cannot access email template/SMTP settings.
①Set Split payment enabled to Y and save
②Split payment URL visible in merchant portal
③Create split contract for merchant in Split Pay Management
Split Pay Mgmt > Register Contract
①Select merchant
②Set total amount and installments (e.g. 300,000 / 3 = 100,000 × 3)
③Set due date per installment
④Save → per-installment payment URLs auto-generated
⑤Share each installment URL with customer via email/SMS/link

7. Chatbot Payment Setup

Chatbot Management
✅ Chatbot Management is fully accessible to HQ Admin (including delete).
①Set Chatbot payment enabled to Y and save
②Chatbot Management → select merchant → choose operation mode
③Set product slot limit
④Share chatbot URL (https://icopay.co.kr/chatbot-pay/{merchant-code}) with merchant

FAQ

Notification Management menu is missing.
Notification Management is Super Admin only. Request Notify URL changes from the Super Admin.
Split Pay Email Settings is greyed out.
Email Settings in Split Pay Management is Super Admin only. Contact the Super Admin.
Merchant cannot see the payment URL after activation.
Verify the service enabled field is set to Y in Merchant Info.
Cannot add more chatbot products.
Slot limit reached. Increase slot count in Merchant Info > Chatbot Settings.
Where is the API documentation?
Deploy Settings > API Documentation. Accessible to all roles.
