# 업체관리 – 업체등록 연결 분석 (fxhj.soonpay.co.kr 기준)

## 1. 분석 대상

- **사이트:** https://fxhj.soonpay.co.kr/main  
- **대메뉴:** 업체관리  
- **요구:** 업체관리 하위에 **업체등록** 페이지 연결 구조 분석 후 우리 솔루션에 반영

---

## 2. fxhj 저장본 기준 메뉴 구조 (output/fxhj-main-after-login.html)

업체관리 하위 좌측 메뉴는 아래 5개로 저장되어 있음:

| 순서 | 메뉴명         | URL 경로              | 메뉴ID |
|------|----------------|------------------------|--------|
| 1    | 공지사항       | `/system/noticeList`   | M0101  |
| 2    | 업체정보조회   | `/comp/myCompMng`      | M0102  |
| 3    | 업체관리       | `/comp/compMngTree`    | M0109  |
| 4    | 수수료관리     | `/commission/commisionList` | M0110  |
| 5    | 업체변경이력   | `/comp/compInfoHistList`    | M0114  |

**저장된 HTML에는 "업체등록"이라는 별도 메뉴 항목이 없음.**

---

## 3. 연결 방식 (fxhj 공통)

- **메뉴 클릭:** `fnTopMenuMove(url)` 호출  
- **탭 추가/전환:** `data-url` 값으로 탭 식별, `formurl`로 컨텐츠 로드  
- **URL → 탭 id:** 경로의 마지막 세그먼트 사용 (예: `/comp/compReg` → `compReg`)

업체등록을 **별도 화면**으로 둘 경우, fxhj와 동일하게:

- 좌측 메뉴에 **업체등록** 항목 추가  
- `data-url="/comp/compReg"` (또는 실제 fxhj에서 사용하는 URL)  
- 클릭 시 `fnTopMenuMove('/comp/compReg')` → 탭 추가 후 해당 URL로 컨텐츠 로드

---

## 4. 업체등록 URL 가정

fxhj의 comp 관련 URL 패턴:

- `/comp/myCompMng` (업체정보조회)
- `/comp/compMngTree` (업체관리)
- `/comp/compInfoHistList` (업체변경이력)

**업체등록**은 일반적으로 신규 등록 폼이므로, 다음 중 하나로 추정:

- `/comp/compReg` (권장)
- `/comp/compRegister`
- 또는 **업체관리(compMngTree)** 화면 내 "업체 등록" 버튼으로 모달/서브 화면 오픈

사용자 요청이 **"업체관리에서 업체등록 페이지"**이므로, **별도 메뉴 + 전용 URL**로 구성하는 것이 적합함.  
→ **URL: `/comp/compReg`**, **메뉴ID: M0108** 로 추가.

---

## 5. 우리 솔루션 반영 사항

| 항목       | 내용 |
|------------|------|
| 메뉴 위치  | 업체관리 하위, **업체정보조회 다음**, **업체관리(트리) 앞** |
| 메뉴명     | 업체등록 |
| URL        | `/comp/compReg` |
| 메뉴ID     | M0108 |
| 화면 구성  | 업체 등록 폼(업체코드, 업체명, 사업자번호, 대표자, 연락처 등) + 저장 버튼 (fxhj 실제 화면에 맞춰 추후 상세 구현) |

---

## 6. 정리

- **fxhj 메인 저장본:** 업체등록이 **별도 메뉴로는 없음**. (실제 운영 사이트에는 있을 수 있음.)
- **구현 방향:** 업체관리 하위에 **업체등록** 메뉴를 추가하고, **/comp/compReg** 로 탭/화면 연결.
- **다음 단계:** site 좌측 메뉴·MENU_INFO·screens·서버 API에 업체등록 추가 후, fxhj 실제 화면과 비교해 폼 항목·검증 보완.
