1. การลงทะเบียนร้านค้า

การจัดการร้านค้า > ลงทะเบียนร้านค้า / ข้อมูลร้านค้า

1-1. ขั้นตอนการลงทะเบียนร้านค้าใหม่

①ไปที่ การจัดการร้านค้า > ลงทะเบียนร้านค้า
②กรอกข้อมูลพื้นฐาน — ชื่อธุรกิจ, เลขทะเบียน, ผู้แทน, ติดต่อ, อีเมล, ที่อยู่
③ตั้งค่าโครงสร้างการชำระเงิน — รอบการชำระ, อัตราค่าธรรมเนียม, บัญชีธนาคาร
④เปิดใช้งานบริการชำระเงินที่ต้องการ (ดูรายละเอียดแต่ละบริการด้านล่าง)
⑤บันทึก → รหัสร้านค้าถูกสร้างอัตโนมัติ → ตรวจสอบ URL การชำระเงิน
⑥สร้างบัญชีร้านค้า (ID + รหัสผ่านชั่วคราว) และแจ้งให้ร้านค้าทราบ

1-2. บริการชำระเงินที่เปิดใช้งานได้เมื่อลงทะเบียน

บริการฟิลด์การเปิดใช้งานหมายเหตุ
การชำระเงินเว็บ (URL)เปิดใช้งานการชำระเงินเว็บ Y/Nใช้การเชื่อมต่อ ChillPay
การชำระเงินแบบสมัครสมาชิกเปิดใช้งานการสมัครสมาชิก Y/Nต้องตั้งค่าแผนบริการ
การซื้อซ้ำเปิดใช้งานการซื้อซ้ำ Y/Nใช้โทเค็นการชำระเงินที่บันทึกไว้
การแบ่งชำระผ่าน URLเปิดใช้งานการแบ่งชำระ Y/Nต้องตั้งค่าสัญญาใน Split Pay
การชำระเงินผ่านแชทบอทเปิดใช้งานแชทบอท Y/Nต้องตั้งค่าเพิ่มเติมใน Chatbot Mgmt
การตั้งค่าเป็น Y จะทำให้ URL การชำระเงินปรากฏในพอร์ทัลร้านค้า หากตั้งเป็น N URL จะถูกซ่อน

2. การตั้งค่าค่าธรรมเนียม

โครงสร้างค่าธรรมเนียมของ ICOPAY แบ่งเป็น 2 ระดับ: ค่าธรรมเนียมนโยบายพื้นฐาน (ค่าเริ่มต้นของระบบทั้งหมด) และ ค่าธรรมเนียมรายร้านค้า (สำหรับร้านค้าเฉพาะ)
ขอบเขตที่สามารถจัดการได้จะแตกต่างกันตามสิทธิ์การเข้าถึง

ประเภทค่าธรรมเนียมเส้นทางเมนูซูเปอร์แอดมินสำนักงานใหญ่ตัวแทน
ค่าธรรมเนียมนโยบายพื้นฐาน (ค่าเริ่มต้นระบบ)การตั้งค่าสำนักงานใหญ่ > การตั้งค่าค่าธรรมเนียม✅❌❌
ค่าธรรมเนียมรายร้านค้าการจัดการผู้ค้า > การจัดการค่าธรรมเนียม✅✅✅

2-1. การตั้งค่าค่าธรรมเนียมนโยบายพื้นฐาน ซูเปอร์แอดมินเท่านั้น

การตั้งค่าสำนักงานใหญ่ > การตั้งค่าค่าธรรมเนียม

ตั้งค่านโยบายค่าธรรมเนียมพื้นฐานที่ใช้กับระบบทั้งหมด ร้านค้าที่ไม่มีค่าธรรมเนียมรายร้านค้าจะถูกใช้ค่าเริ่มต้นนี้โดยอัตโนมัติ

①การตั้งค่าสำนักงานใหญ่ > การตั้งค่าค่าธรรมเนียม เข้าเมนู (ซูเปอร์แอดมินเท่านั้น)
②ป้อนอัตราค่าธรรมเนียมพื้นฐานแต่ละวิธีชำระเงิน (เช่น บัตรเครดิต 2.5%, โอนกระเป๋าเงิน 1.8%)
③ตั้งค่านโยบายค่าธรรมเนียมแต่ละสกุลเงิน (THB, USD, KRW เป็นต้น)
④บันทึก → สะท้อนทันทีในบัญชีร้านค้าที่ยังไม่ได้ตั้งค่าค่าธรรมเนียมรายร้านค้า
รายการคำอธิบายสิทธิ์การเข้าถึง
อัตราค่าธรรมเนียมพื้นฐานอัตราค่าธรรมเนียมพื้นฐานของระบบแต่ละวิธีชำระเงิน (%)ซูเปอร์แอดมิน
นโยบายค่าธรรมเนียมแต่ละสกุลเงินเกณฑ์ค่าธรรมเนียมแต่ละสกุลเงิน THB/USD/KRWซูเปอร์แอดมิน
วันที่เริ่มใช้ค่าธรรมเนียมวันที่ค่าธรรมเนียมที่เปลี่ยนแปลงจะเริ่มมีผลซูเปอร์แอดมิน
⚠ ค่าธรรมเนียมนโยบายพื้นฐานสำหรับซูเปอร์แอดมินเท่านั้น
หากตั้งค่าค่าธรรมเนียมรายร้านค้าไว้ จะถูกใช้ก่อนค่าธรรมเนียมนโยบายพื้นฐาน

2-2. การตั้งค่าค่าธรรมเนียมรายร้านค้า ทุกบทบาท

การจัดการผู้ค้า > การจัดการค่าธรรมเนียม

ตั้งค่าอัตราค่าธรรมเนียมรายบุคคลที่ใช้กับร้านค้าเฉพาะเจาะจง ใช้กับร้านค้าที่ต้องการเงื่อนไขต่างจากค่าธรรมเนียมนโยบายพื้นฐาน

①การจัดการผู้ค้า > การจัดการค่าธรรมเนียม เข้าเมนู
②เลือกร้านค้าที่ต้องการตั้งค่าค่าธรรมเนียม
③ป้อนอัตราค่าธรรมเนียมรายบุคคลแต่ละวิธีชำระเงิน
④ตั้งค่าระยะเวลาใช้งาน (วันเริ่มต้น·วันสิ้นสุด) (สามารถใช้ค่าธรรมเนียมโปรโมชั่นระยะเวลาจำกัด)
⑤บันทึก → ใช้กับร้านค้าที่เลือกทันที
รายการคำอธิบายสิทธิ์การเข้าถึง
อัตราค่าธรรมเนียมรายร้านค้าอัตราค่าธรรมเนียมรายบุคคลต่างจากนโยบายพื้นฐาน (%)ทุกบทบาท
การตั้งค่าแต่ละวิธีชำระเงินการใช้รายบุคคลแยกตามบัตรเครดิต·โอนกระเป๋าเงิน·QRทุกบทบาท
การตั้งค่าระยะเวลาใช้งานการตั้งค่าเงื่อนไขค่าธรรมเนียมระยะเวลาจำกัดทุกบทบาท
ดูประวัติการเปลี่ยนแปลงค่าธรรมเนียมตรวจสอบประวัติการเปลี่ยนแปลงค่าธรรมเนียมรายร้านค้าทุกบทบาท
เมื่อลงทะเบียนค่าธรรมเนียมรายร้านค้าแล้ว จะถูกใช้ก่อนค่าธรรมเนียมนโยบายพื้นฐาน หลังจากค่าธรรมเนียมรายบุคคลหมดอายุ ร้านค้าจะกลับไปใช้ค่าธรรมเนียมนโยบายพื้นฐานโดยอัตโนมัติ

3. การตั้งค่าการชำระเงินเว็บ

การจัดการร้านค้า > ข้อมูลร้านค้า > แท็บการตั้งค่าการชำระเงิน

3-1. เปิดใช้งานการชำระเงินเว็บ

①เลือกร้านค้าใน การจัดการร้านค้า > ข้อมูลร้านค้า
②แท็บการตั้งค่าการชำระเงิน → ตั้ง เปิดใช้งานการชำระเงินเว็บ เป็น Y
③บันทึก → URL ถูกสร้างอัตโนมัติ (https://icopay.co.kr/pay/{รหัสร้านค้า})
④แจ้ง URL ให้ร้านค้าหรือฝังในหน้าชำระเงิน
🔒 การตั้งค่า Notify URL เป็นสิทธิ์เฉพาะผู้ดูแลระบบสูงสุดเท่านั้น
สำนักงานใหญ่และตัวแทนไม่สามารถเข้าถึงการจัดการการแจ้งเตือน

4. การชำระเงินแบบสมัครสมาชิก

การจัดการร้านค้า > ข้อมูลร้านค้า > แท็บการตั้งค่าการชำระเงิน
①ตั้ง เปิดใช้งานการสมัครสมาชิก เป็น Y แล้วบันทึก
②ตั้งค่าแผนบริการ: ชื่อแผน, รอบการชำระ (รายเดือน/รายปี), จำนวนเงิน, สกุลเงิน
③แชร์ URL การสมัครสมาชิกกับร้านค้า
④ระบบจะเรียกเก็บเงินอัตโนมัติตามรอบที่กำหนด
การชำระเงินครั้งแรกจะบันทึกโทเค็นบัตร จากนั้นระบบจะเรียกเก็บอัตโนมัติตามรอบ

5. การซื้อซ้ำ

การจัดการร้านค้า > ข้อมูลร้านค้า > แท็บการตั้งค่าการชำระเงิน

การซื้อซ้ำช่วยให้ลูกค้าใช้โทเค็นบัตรที่บันทึกไว้จากการชำระเงินก่อนหน้าเพื่อชำระเงินใหม่ได้ทันทีโดยไม่ต้องกรอกข้อมูลบัตรอีกครั้ง

①ตั้ง เปิดใช้งานการซื้อซ้ำ เป็น Y แล้วบันทึก
②หน้าชำระเงินจะแสดงตัวเลือก "ชำระด้วยบัตรที่บันทึกไว้"
③ลูกค้าเลือกซื้อซ้ำ → ระบบประมวลผลด้วยโทเค็นที่บันทึกไว้ทันที
ความปลอดภัย: โทเค็นบัตรถูกเข้ารหัสตามมาตรฐาน PCI-DSS ไม่มีการบันทึกหมายเลขบัตรจริง

6. การแบ่งชำระผ่าน URL

การจัดการการแบ่งชำระ
🔒 การตั้งค่าอีเมลในการจัดการการแบ่งชำระ เป็นสิทธิ์เฉพาะผู้ดูแลระบบสูงสุด

6-1. เปิดใช้งานการแบ่งชำระสำหรับร้านค้า

①ตั้ง เปิดใช้งานการแบ่งชำระ เป็น Y แล้วบันทึก
②URL การแบ่งชำระจะปรากฏในพอร์ทัลร้านค้า
③สร้างสัญญาการแบ่งชำระสำหรับร้านค้าในเมนูการจัดการการแบ่งชำระ

6-2. การสร้างสัญญาการแบ่งชำระ

การจัดการการแบ่งชำระ > ลงทะเบียนสัญญา
①เลือกร้านค้า
②กำหนดยอดรวมและจำนวนงวด (เช่น 9,000 บาท / 3 งวด → 3,000 บาท × 3)
③กำหนดวันครบกำหนดของแต่ละงวด
④บันทึกสัญญา → URL การชำระแต่ละงวดถูกสร้างอัตโนมัติ
⑤ส่ง URL แต่ละงวดให้ลูกค้าทางอีเมล, SMS หรือลิงก์

7. การชำระเงินผ่านแชทบอท

การจัดการแชทบอท
✅ การจัดการแชทบอทเข้าถึงได้ทุกบทบาท (รวมการลบ)

7-1. เปิดใช้งานแชทบอทสำหรับร้านค้า

①ตั้ง เปิดใช้งานการชำระเงินผ่านแชทบอท เป็น Y แล้วบันทึก

โหมดคำอธิบายเวลาชำระเงิน
SALE_PREPAIDขาย — ชำระก่อนชำระเงินทันทีที่สั่งซื้อ
SALE_POSTPAIDขาย — ชำระหลังรับสินค้าก่อน ชำระภายหลัง
RESERVATION_PREPAIDจอง — ชำระก่อนชำระเต็มจำนวนเมื่อจอง
RESERVATION_POSTPAIDจอง — ชำระหลังยืนยันการจอง ชำระที่หน้างาน
HYBRID_RESERVATION_PREPAIDไฮบริด — ชำระก่อนมัดจำก่อน ส่วนที่เหลือชำระภายหลัง
FACE_TO_FACE_POSTPAIDพบหน้า — ชำระหลังบริการแล้วส่งลิงก์ชำระเงิน

คำถามที่พบบ่อย (FAQ)

เมนูการจัดการการแจ้งเตือนไม่แสดงในบัญชีสำนักงานใหญ่
การจัดการการแจ้งเตือนเป็นเมนูเฉพาะผู้ดูแลระบบสูงสุด สำนักงานใหญ่และตัวแทนมีสิทธิ์เหมือนกันและไม่สามารถเข้าถึงได้ กรุณาติดต่อผู้ดูแลระบบสูงสุด
ร้านค้าไม่สามารถเห็น URL การชำระเงินหลังจากเปิดใช้งาน
ตรวจสอบว่าฟิลด์เปิดใช้งานบริการใน ข้อมูลร้านค้า ตั้งเป็น Y หากเป็น N URL จะถูกซ่อนในพอร์ทัลร้านค้า
ไม่สามารถเพิ่มสินค้าแชทบอทได้อีกแล้ว
ร้านค้าถึงขีดจำกัดสล็อตสินค้าแล้ว เพิ่มจำนวนสล็อตใน ข้อมูลร้านค้า > การตั้งค่าแชทบอท
ดูเอกสาร API ได้ที่ไหน
