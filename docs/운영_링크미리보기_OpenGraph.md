# 운영: 관리자 링크 미리보기 (Open Graph)

> 플랫폼 **V4.21~V4.22** 반영 · 관리자 URL을 LINE·WhatsApp 등에 공유할 때 카드(제목·설명·이미지)  
> 상세 요구·검수 기준: [`요구서_OpenGraph_링크미리보기_회원_관리자.md`](./요구서_OpenGraph_링크미리보기_회원_관리자.md)

---

## 1. 무엇을 하나

메신저·SNS는 페이지를 열지 않고 **첫 HTML**의 `og:title` · `og:description` · `og:image`만 읽습니다.  
관리자 도메인(총본사·본사·총판 관리 URL)을 공유할 때 **조직 브랜드**에 저장한 미리보기가 카드에 나갑니다.

- 설정 위치: **업체관리 → 업체정보(브랜드)** 등 조직 브랜딩 화면의 **「링크 미리보기 (메신저)」**
- 언어: 제목·설명 **5개국어**(KOR·ENG·JPN·CHN·THA)
- 이미지: 미리보기 전용 이미지(없으면 브랜드 로고 등 폴백)

## 2. 적용 방식 (본사설정 따름)

| 조직 | 미리보기 적용 |
|------|----------------|
| 총본사(HEADQUARTERS) | 항상 **직접 입력** |
| 본사(REGIONAL) | **본사설정 따름**(총본사) 또는 **직접 입력** |
| 총판(MASTER_DIST) | 본사설정 따름 → (본사가 직접이면 그 본사, 아니면 총본사) / 또는 총판 **직접 입력** |

## 3. 운영 절차

1. 해당 조직 브랜드에서 「링크 미리보기」 제목·설명·이미지를 저장합니다.
2. 관리자 URL(예: `https://icopay.co.kr/` 또는 본사·총판 전용 관리 URL)을 메신저에 붙여 넣어 카드를 확인합니다.
3. **캐시**: LINE 등은 예전 미리보기를 오래 보관할 수 있습니다. 서버 HTML이 맞아도 앱 캐시가 남으면 잠시 후 재확인하거나 캐시 갱신 도구를 사용합니다.
4. 총본사 apex(`icopay.co.kr`)는 **pg-app이 HTML을 내려주도록** 프록시되어야 합니다. 정적 HTML만 나가면 기본값(ICOPAY…)이 카드에 남을 수 있습니다(V4.22 수정 참고).

## 4. 범위 메모

- 본 운영 문서는 **관리자 URL** 미리보기 중심입니다.
- 회원(결제) 공개 URL용 별도 미리보기가 필요하면 요구서의 「회원 페이지 미리보기」 절을 따릅니다.
- 가맹점마다 다른 OG·게시글 단위 동적 OG는 범위 밖입니다.
