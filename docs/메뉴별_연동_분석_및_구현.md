# FXHJ 메뉴별 연동 분석 및 우리 사이트 구현

> fxhj: 메뉴 클릭 → `fnTopMenuMove(url)` → 해당 url 탭 추가/전환 → `formurl`로 컨텐츠 로드 → 탭 패널에 표시  
> 우리 사이트: 동일하게 `fnTopMenuMove(url)` → 탭 추가/전환 → `PG_SCREENS.getScreenHtml(url, tabId)` 로 HTML 생성 → bindScreenEvents

## URL → 탭 id 규칙 (동일 적용)
- `/system/noticeList` → `noticeList`
- `/comp/myCompMng` → `myCompMng`
- `/comp/compMngTree` → `compMngTree`
- `/comp/compReg` → `compReg` (업체관리 화면에서 "등록" 버튼 클릭 시 열림, 좌측 메뉴에는 없음)
- `/commission/commisionList` → `commisionList`
- `/comp/compInfoHistList` → `compInfoHistList`
- `/calc/payList` → `payList`
- 기타: 경로의 마지막 세그먼트 (슬래시 제거 후)

## 업체 등록(compReg) 특수 연동
- **진입:** 업체관리(compMngTree) 화면에서 **등록** 버튼 클릭 시 `fnTopMenuMove('/comp/compReg')` 호출 → "업체 등록" 탭 추가 및 표시
- **화면:** 업체 정보, 업체 상세 정보, 기타, 첨부파일 섹션 (fxhj 이미지 기준)
