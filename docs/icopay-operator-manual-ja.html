📋 命名原則

ICOPAYは単一APIの背後で複数の決済代行会社を統合するプラットフォームです。本マニュアルの統合機能（チェックアウト、URL決済、統合取引等）では中立的なICOPAY用語を使用します。「JPAY専用」表記はJPAY固有機能にのみ使用されます。

1. 加盟店登録

加盟店管理 > 加盟店登録 / 加盟店情報

1-1. 新規加盟店登録手順

①加盟店管理 > 加盟店登録メニューへ移動
②基本情報入力 — 店舗名、事業者番号、代表者名、連絡先、メール、住所
③精算構造設定 — 精算周期、手数料率、銀行口座
④利用する決済サービスを有効化（各サービスの設定は以下の各章を参照）
⑤保存 → 加盟店コード（slug）が自動生成 → 決済URLを確認
⑥加盟店アカウント（ID・仮パスワード）を作成し担当者へ通知

1-2. 登録時に有効化できる決済サービス

サービス有効化項目名備考
Web決済（URL決済）Web決済利用可否 Y/NICOPAY統合checkout
定期購読決済定期購読利用可否 Y/Nプラン設定が必要
再購入決済再購入利用可否 Y/N保存済みトークンを再利用
URL分割決済分割決済利用可否 Y/N分割管理で契約設定が必要
チャットボット決済チャットボット決済利用可否 Y/Nチャットボット管理で追加設定が必要
Yに設定すると加盟店ポータルに決済URLが表示されます。Nの場合、URLは非表示になります。

1-3. 加盟店アカウント管理

ユーザー管理 > 加盟店アカウント
  • ログインIDの設定と仮パスワードの発行
  • アカウント有効/無効の切り替え
  • パスワードのリセット
注意: ユーザー管理内のメニュー項目順序管理は総本社専用です。

2. 手数料設定

ICOPAYの手数料体系は基本ポリシー手数料（システム全体のデフォルト）と加盟店別個別手数料（特定加盟店専用）の2段階で構成されます。
アクセス権限によって管理できる範囲が異なります。

手数料タイプメニューパススーパー管理者本社代理店
基本ポリシー手数料（システムデフォルト）本社設定 > 手数料設定✅❌❌
加盟店別個別手数料業者管理 > 手数料管理✅✅✅

2-1. 基本ポリシー手数料設定 スーパー管理者専用

本社設定 > 手数料設定

システム全体に適用される基本手数料ポリシーを設定します。個別手数料が設定されていない加盟店にはこのデフォルト値が自動適用されます。

①本社設定 > 手数料設定 メニューへ進む（スーパー管理者専用）
②決済手段別の基本手数料率を入力（例：クレジットカード 2.5%、ウォレット送金 1.8%）
③通貨別手数料ポリシーを設定（THB、USD、KRW など）
④保存 → 個別手数料未設定の加盟店アカウントに即時反映
項目説明アクセス権限
基本手数料率決済手段別システム基本手数料率（%）スーパー管理者
通貨別手数料ポリシーTHB/USD/KRW別の通貨別手数料基準スーパー管理者
手数料適用基準日変更された手数料が開始される日付スーパー管理者
⚠ 基本ポリシー手数料はスーパー管理者専用です。
加盟店別個別手数料が設定されている場合、基本ポリシー手数料より優先適用されます。

2-2. 加盟店別個別手数料設定 全役割

業者管理 > 手数料管理

特定の加盟店にのみ適用される個別手数料率を設定します。基本ポリシー手数料とは異なる条件が必要な加盟店に使用します。

①業者管理 > 手数料管理 メニューへ進む
②手数料を設定する加盟店を選択
③決済手段別の個別手数料率を入力
④適用期間（開始日・終了日）を設定（期間限定プロモーション手数料の適用が可能）
⑤保存 → 対象加盟店のみに即時適用
項目説明アクセス権限
加盟店別手数料率基本ポリシーと異なる個別手数料率（%）全役割
決済手段別設定クレジットカード・ウォレット・QR別の個別適用全役割
適用期間設定期間指定手数料条件の設定全役割
手数料変更履歴照会加盟店別手数料変更履歴の確認全役割
加盟店別個別手数料が登録されると、基本ポリシー手数料より優先適用されます。 個別手数料の期限切れ後は、加盟店が自動的に基本ポリシー手数料に戻ります。

3. Web決済設定

加盟店管理 > 加盟店情報 > 決済設定タブ

3-1. Web決済の有効化

①加盟店管理 > 加盟店情報で対象加盟店を選択
②決済設定タブ → Web決済利用可否をYに変更
③保存 → Web決済URL（https://icopay.co.kr/pay/{加盟店コード}）が自動生成
④URLを加盟店に案内または決済ページに適用

3-2. 主要設定項目

項目説明アクセス権限
Web決済利用可否Web決済URLの有効化（Y/N）全員
カード認証方式3DS / 2DS（非認証）。「本社ポリシーに従う」または加盟店指定。URL決済とAPIインラインで同一。定期購読の初回は常に3DS全員
Web決済URL加盟店専用決済リンク（自動生成）全員
決済通貨設定THB・USD・KRWなど全員
通知（Notify）URL決済完了後のサーバー通知受信先総本社のみ
リダイレクトURL決済後に顧客が移動するページ全員
🔒 通知（Notify）URL設定は総本社専用です。
通知管理メニューは本社・総販はアクセスできません。変更が必要な場合は総本社に依頼してください。

3-3. 取引履歴確認

決済管理 > 取引履歴
  • 期間・加盟店・決済手段・状態でフィルタ
  • 詳細画面から返金処理
  • 領収書の再送信

4. 定期購読決済設定

加盟店管理 > 加盟店情報 > 決済設定タブ
①加盟店情報 → 決済設定 → 定期購読利用可否をYに設定して保存
②購読プラン設定: プラン名、請求周期（月次/年次）、金額、通貨を登録
③購読URLを加盟店に共有
④設定した周期に従って自動請求
初回決済時にカードトークンを保存し、以降は周期に従って自動請求します。
決済管理 > 購読履歴
  • 状態フィルタ: 有効 / 一時停止 / 解約 / 期限切れ
  • 即時解約処理
  • 次回請求日の確認と変更

5. 再購入決済設定

加盟店管理 > 加盟店情報 > 決済設定タブ

再購入決済は、顧客が過去の決済で登録したカードトークンを再利用して、カード情報を再入力せずに新しい決済を行う機能です。

①加盟店情報 → 決済設定 → 再購入利用可否をYに設定して保存
②有効化後、決済画面に「保存済みカードで決済」オプションが表示
③顧客が再購入を選択 → 保存済みトークンで即時決済処理
セキュリティ注意: カードトークンはPCI-DSS準拠で暗号化保存。実際のカード番号は保存されません。

6. URL分割決済設定

分割管理
🔒 分割管理 > メール設定は総本社専用です。
メールテンプレート・送信サーバー設定は本社・総販はアクセスできません。

6-1. 加盟店の分割決済有効化

①加盟店情報 → 決済設定 → 分割決済利用可否をYに設定して保存
②加盟店ポータルに分割決済URLが表示
③分割管理で対象加盟店の分割契約を作成

6-2. 分割契約の登録

分割管理 > 契約登録
①加盟店を選択
②合計金額と分割回数を設定（例: 30,000円 / 3回 → 10,000円 × 3）
③各回の支払期日を設定
④契約を保存 → 各回の決済URLが自動生成
⑤顧客に各回の決済URLを送付（メール・SMS・リンク共有）

7. チャットボット決済設定

チャットボット管理
✅ チャットボット管理は総本社・本社・総販すべてアクセス可能です（削除含む）。

7-1. 加盟店チャットボット決済の有効化

①加盟店情報 → 決済設定 → チャットボット決済利用可否をYに設定して保存
②チャットボット管理 → 対象加盟店を選択
③運営モードを選択
④商品スロット数を設定（加盟店が登録できる商品の最大数）
⑤チャットボット決済URL（https://icopay.co.kr/chatbot-pay/{加盟店コード}）を加盟店に案内

7-2. 運営モード一覧

モード説明決済タイミング
SALE_PREPAID販売 — 前払い注文時即決済後、商品提供
SALE_POSTPAID販売 — 後払い商品提供後に請求
RESERVATION_PREPAID予約 — 前払い予約時に全額決済
RESERVATION_POSTPAID予約 — 後払い予約確定後、現地決済
HYBRID_RESERVATION_PREPAIDハイブリッド予約 — 前払い予約金前払い + 残額後払い
FACE_TO_FACE_POSTPAID対面 — 後払い現地サービス提供後、決済リンク送付

7-3. 商品管理

チャットボット管理 > 商品管理
  • 商品登録: 商品名、説明、価格、画像、カテゴリ、在庫有無
  • 商品の有効/無効切り替え
  • スロット上限超過時は追加不可 → スロット数を調整

7-4. KB（ナレッジベース）管理

チャットボット管理 > KB管理
  • FAQ登録・編集・削除
  • カテゴリ別ドキュメントアップロード
  • AI学習データの最適化トリガー
🔒 LINE Notify・メール通知設定は総本社専用です。
通知管理メニューは本社・総販はアクセスできません。変更が必要な場合は総本社に依頼してください。

よくある質問（FAQ）

本社アカウントで通知管理メニューが表示されません。
通知管理は総本社専用メニューです。本社・総販は同一権限でアクセスできません。変更が必要な場合は総本社に依頼してください。
分割決済のメール設定がグレーアウトされています。
分割管理 > メール設定は総本社専用です。テンプレートの変更が必要な場合は総本社にお問い合わせください。
加盟店が決済URLを確認できないと言っています。
加盟店情報で該当サービスの利用可否がYに設定されているか確認してください。Nの場合、URLは加盟店ポータルに表示されません。
チャットボットの商品がこれ以上追加できません。
商品スロット上限に達しています。加盟店情報 > チャットボット設定でスロット数を増やしてください。
API配布ドキュメントはどこで確認できますか？
配布設定 > API配布ドキュメントで確認できます。このメニューは総本社・本社・総販すべてアクセス可能です。
