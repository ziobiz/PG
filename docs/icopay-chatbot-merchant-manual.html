1. 챗봇결제란?

ICOPAY 챗봇결제는 AI 챗봇이 고객과 대화하며 상품 안내 → 주문 수집 → 결제까지 한 흐름으로 처리해 주는 서비스입니다. 별도의 쇼핑몰이나 앱 개발 없이도 챗봇 URL 하나로 온라인 판매·예약·결제를 운영할 수 있습니다.

고객 결제 흐름

고객→챗봇결제 URL 접속 (링크 클릭 또는 QR 스캔)
AI 챗봇→등록된 상품 목록 안내 및 선택 유도
고객→상품 선택 및 주문 정보 입력 (이름·연락처·수량 등)
AI 챗봇→결제 화면 안내
고객→카드 결제 완료
가맹점→이메일·LINE 알림 수신 + 주문관리 화면에서 내역 확인

주요 특징

특징내용
쇼핑몰 불필요AI 챗봇이 상담·주문·결제를 한 번에 처리
6가지 운영방식상품판매(선불·후불), 예약(선불·후불), 하이브리드, 대면거래
플로팅 위젯홈페이지에 스크립트 한 줄 삽입으로 챗봇 연동
QR코드 배포매장 인쇄물·명함에 QR 부착, 스캔 즉시 결제 진입
실시간 알림결제 완료 시 이메일 또는 LINE Notify 즉시 수신

2. 사전 준비 (활성화 조건)

챗봇결제를 사용하려면 아래 조건이 모두 충족되어야 합니다.

조건확인 위치비고
가맹점 계정 로그인—챗봇결제는 가맹점(MERCHANT) 전용 서비스
결제대행사(PG) 바인딩업체등록 > 결제대행사 설정WEB 유형, 운영(체크) 상태 필요
챗봇결제 사용여부 = 사용업체등록 > 챗봇결제 설정본사가 Y로 설정해야 메뉴 표시됨
챗봇결제 사용여부가 미사용(N)이면 사이드바에서 챗봇관리 메뉴 전체 (상품관리·주문관리·기본설정)가 숨겨집니다.
활성화 요청은 ICOPAY 본사 담당자에게 문의하세요.

3. STEP 1 챗봇결제 기본 설정

업체관리 > 내 업체정보 > 챗봇결제 설정

3-1. 챗봇결제 URL 확인

챗봇결제 사용여부를 사용(Y)으로 저장하면 아래 형식의 URL이 자동 생성됩니다. 

https://pay.icopay.co.kr/chatbot-pay/{업체코드}
복사 버튼을 클릭해 URL을 복사한 뒤, SNS·명함·QR·이메일 서명 등에 활용하세요.
챗봇결제가 미사용 상태이면 이 주소는 화면에 표시되지 않습니다.

3-2. 챗봇 상단 로고 설정

고객에게 보이는 챗봇 화면 상단에 표시할 로고를 등록합니다.

순서동작
① 파일 선택파일 선택 버튼 클릭 → PNG 또는 JPEG 선택 (원본 최대 40 MB)
② 업로드업로드·최적화 버튼 클릭 → 서버에서 자동 압축 후 저장 완료

3-3. URL 결제 방식 선택

챗봇 주문·결제 페이지에서 사용할 결제 UI 방식을 선택합니다.

선택값설명
STANDARDICOPAY 기본 결제 폼 화면
PG별 전용 결제 화면JPAY 전용 등 결제대행사 고유 UI (내부 라우팅)
이 설정은 챗봇결제 전용이며, 공개 URL결제·API 중계와는 별도로 독립 적용됩니다.

3-4. 홈페이지 플로팅 위젯 삽입 (선택)

가맹점 홈페이지·쇼핑몰에 챗봇 아이콘을 띄우려면 아래 코드를 HTML에 삽입합니다.

<!-- 모든 페이지 공통: </body> 직전에 붙여넣기 -->
<script src="https://pay.icopay.co.kr/v1/embed-chatbot/{업체코드}"
        async defer charset="utf-8"></script>
내 업체정보 화면에서 챗봇 플로팅 위젯 필드의 복사 버튼을 누르면 업체코드가 포함된 완성된 코드를 바로 복사할 수 있습니다.
워드프레스·쇼핑몰 테마의 공통 스크립트 영역에 붙여 넣으면 모든 페이지에 자동 적용됩니다.

3-5. QR코드 다운로드 (선택)

챗봇결제 URL의 QR코드를 매장 인쇄물·테이블 카드에 활용할 수 있습니다.

  • 챗봇결제 설정 카드 내 QR 이미지 오른쪽 저장 버튼 클릭
  • PNG 파일로 다운로드 → 인쇄 또는 디자인 작업에 활용

4. STEP 2 챗봇 기본정보 설정

챗봇관리 > 기본설정

4-1. 챗봇 운영방식 선택

업종과 결제 시점에 맞는 방식을 선택하면 AI가 그에 맞는 대화 흐름으로 고객을 안내합니다.

운영방식설명적합 업종 예시
상품판매 · 선불상품 선택 후 즉시 결제온라인 쇼핑몰, 굿즈 판매
상품판매 · 후불주문 접수 후 나중에 결제주문 제작, B2B 납품
예약방식 · 선불예약 시 즉시 결제마사지, 헤어샵, 스터디룸
예약방식 · 후불예약 접수 → 방문 후 결제레스토랑, 컨설팅
하이브리드 (판매+예약)일반 판매 + 예약 상품 혼용복합 서비스업
대면거래 (판매+예약·후불)현장 확인 후 결제VIP 클럽, 대면 서비스

4-2. 가맹점 업체성격 선택

AI 챗봇이 업종에 맞는 질문 흐름을 자동 구성하도록 업체 성격을 선택합니다.

업체성격AI 응대 특성
일반판매 / 이커머스상품명·수량·배송지 중심 수집
마사지(일반·클럽)예약 날짜·시간·코스·인원 수집
음식점 / 레스토랑방문 인원·날짜·시간·특이사항 수집
컨설팅 / 서비스업상담 주제·희망 일정·연락처 수집
부동산 / 자동차판매관심 매물·예산·방문 가능일 수집
VIP 클럽멤버십·예약 코스 중심 안내
업체성격 보조 메모 (선택):
특화 업종에서 반드시 수집해야 할 정보나 피해야 할 표현을 자유 텍스트로 입력하면 AI 응대에 반영됩니다.
예: "고객 국적을 반드시 질문할 것, 미성년자는 입장 불가임을 안내할 것"

4-3. 업체 기본 안내 정보 입력

AI가 고객 문의에 답변할 때 참조하는 업체 기본 정보입니다. 비워두면 업체등록 정보와 동일하게 안내됩니다.

  • 업체명 / 주소 / 전화번호
  • 영업시간
  • 기타 안내사항 (주차, 대중교통 등)

4-4. 예약 설정 (예약방식 운영 시)

항목설명
예약 기본 슬롯(분)예약 단위 시간 (15·30·45·60·90·120·180·240분 선택)
상품별로 다른 슬롯이 필요하면 상품관리에서 개별 덮어쓰기 가능
예약 타임존 (IANA)예약 기준 시간대 입력 (기본값: Asia/Seoul)
같은 날짜·시간대에 이미 예약이 있으면 AI가 자동으로 다른 시간을 안내합니다. 슬롯 단위로 중복 예약이 자동 차단됩니다.

알림 수단설정 방법
이메일 알림 승인 알림메일 → 사용 (대표 이메일) 선택

9. 운영방식별 사용 흐름 요약

선불 방식 (즉시 결제)

고객→챗봇 URL 접속
AI→상품 안내 및 선택 유도
고객→상품 선택 + 주문 정보 입력 (이름·연락처·주소 등)
AI→결제 화면 안내 → 카드 결제 완료
가맹점→이메일·LINE 알림 수신 + 주문관리에서 확인

후불 방식 (주문 접수 → 별도 결제)

고객→챗봇 URL 접속 → 상품 선택·주문 접수 완료
가맹점→주문관리에서 주문 확인 → 고객에게 연락
결제→현장·계좌이체 등 별도 방법으로 처리

예약 방식 (날짜·시간 선택)

고객→챗봇 URL 접속
AI→예약 가능한 날짜·시간 안내
고객→날짜·시간·인원 선택 + 개인정보 입력
선불→즉시 결제 완료 → 예약 확정
후불→예약 접수 완료 → 방문 후 결제
가맹점→주문관리에서 예약 일시·고객 정보 확인

10. 자주 묻는 질문 (FAQ)

챗봇관리 메뉴가 사이드바에 보이지 않습니다.
업체정보에서 챗봇결제 사용여부가 미사용(N)으로 설정되어 있기 때문입니다. ICOPAY 본사 담당자에게 활성화를 요청하세요.
챗봇결제 URL이 화면에 표시되지 않습니다.
챗봇결제 사용여부가 사용(Y)이어야 URL이 표시됩니다. 사용으로 설정 후 저장하면 URL이 자동 생성됩니다.
상품을 등록했는데 챗봇에서 보이지 않습니다.
상품의 활성화 여부를 먼저 확인하세요. 비활성 상태이면 고객 챗봇에 표시되지 않습니다. 판매 기간이 설정된 경우에는 현재 날짜가 기간 내에 있는지도 확인하세요.
예약이 중복으로 들어올 수 있나요?
동일 날짜·시간에 이미 예약이 있으면 AI가 자동으로 다른 시간을 안내합니다. 슬롯(분) 단위로 중복 예약이 자동 차단됩니다.
홈페이지에 챗봇 위젯을 넣었는데 뜨지 않습니다.
스크립트 태그가 </body> 직전에 올바르게 삽입되었는지 확인하세요. 브라우저 개발자 도구(F12) 콘솔에서 오류 메시지가 있으면 스크립트 URL과 업체코드를 점검하세요.
결제 승인 이메일이 오지 않습니다.
URL·챗봇 결제 승인 알림 카드에서 승인 알림메일이 사용으로 설정되어 있는지, 업체등록의 대표 이메일 주소가 올바르게 입력되어 있는지 확인하세요.
상품을 더 이상 등록할 수 없다고 나옵니다.
본사가 설정한 상품등록 한도에 도달한 상태입니다. 기존 불필요한 상품을 삭제하거나, 한도 상향을 본사에 요청하세요.
챗봇 응대 언어를 변경할 수 있나요?
ICOPAY 챗봇은 고객 브라우저의 언어 설정 또는 고객이 선택한 언어로 자동 응대합니다. 별도 설정 없이 다국어(한국어·영어·일본어·중국어·태국어 등)가 지원됩니다.
