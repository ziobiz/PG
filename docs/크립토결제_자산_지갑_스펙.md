## 4. 체크아웃 UI

1. (BOTH일 때) 카드 / 크립토 선택 타일  
2. 자산 선택(USDT·USDC·EURC — 가맹 허용분만)  
3. 네트워크 선택  
4. 지갑 타일 그리드(해당 네트워크 지원 지갑 전부)  
5. ICOPAY 수탁 주소·금액·만료·QR  
6. 입금 대기 → 상태 폴링  

구매자 UI에 PG명·내부 `CRYPTO` 코드 미노출.
