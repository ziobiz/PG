🔒 본사 / 총판 역할의 접근 제한 안내

본사·총판 운영자는 아래 메뉴에 접근할 수 없습니다. 해당 기능이 필요한 경우 총본사(슈퍼관리자)에게 요청하십시오.

  • 본사정책 (허브 그룹 전체 8개) — 수수료·리스크, 결제·URL, 노티 센터, 정산·영업일, 조직·화면, 접근·권한, AI·챗봇, 플랫폼
  • 연동·배포 — PG사 연동, 가맹 API 출시 접근 불가 (단, API 문서 탭 열람은 가능)
  • 정산관리 — 통합정산, 정산실행, 정산배포, 정산대기 접근 불가
  • 통보관리 — 전체 접근 불가 (결제 통보 URL·알림 설정 포함)
  • 사용자관리 — 메뉴별 항목 순서 관리 접근 불가
  • 운영관리 — 운영관리(메인), TAX 리포트, 검증 리포트, 대행거래내역 접근 불가
  • 분할관리 — 이메일 설정 접근 불가

2. 업체관리

업체관리

가맹점 등록·수정·수수료 관리·변경 이력을 담당하는 핵심 메뉴입니다. 본사·총판 모두 전체 접근이 가능합니다.

2-1. 가맹점 신규 등록

업체관리 > 업체관리
①업체관리 > 업체관리 메뉴 진입 → [신규 등록] 버튼 클릭
②업체 기본 정보 입력 — 업체명, 사업자번호, 대표자명, 연락처, 이메일, 주소
③정산 구조 설정 — 정산 주기, 수수료율, 정산 은행 계좌 입력
④사용할 결제 서비스 활성화 (웹결제·구독·재구매·분할·챗봇)
⑤저장 → 업체 코드 자동 생성 → 결제 URL 확인
⑥가맹점 계정(ID·임시 비밀번호) 생성 후 담당자에게 전달

2-2. 업체 정보 조회 및 수정

업체관리 > 업체정보조회
  • 가맹점명·사업자번호·상태(활성/비활성)로 검색
  • 업체 상세 → 기본정보·결제설정·정산설정 탭별 수정
  • 가맹점 활성화 / 일시 정지 / 비활성화 전환
  • 공지사항 탭: 가맹점 대상 공지 등록 및 관리

2-3. 수수료 관리

업체관리 > 수수료관리

가맹점별 개별 수수료율을 설정합니다. 기본 정책수수료(본사정책 → 총본사 전용)와 독립적으로 적용됩니다.

①수수료를 설정할 가맹점 선택
②결제 수단별 개별 수수료율 입력 (신용카드·지갑이체·QR 등)
③적용 기간(시작일·종료일) 설정 — 프로모션 수수료 적용 가능
④저장 → 해당 가맹점에만 즉시 적용 (기본 정책보다 우선)
가맹점별 개별 수수료가 등록되면 기본 정책수수료보다 우선 적용됩니다. 개별 수수료 미등록 가맹점은 자동으로 기본 정책수수료가 적용됩니다.
🔒 기본 수수료 정책(본사정책 > 수수료·리스크) 접근 불가
기본 수수료 정책 변경이 필요한 경우 총본사에 요청하십시오.

2-4. 업체 변경 이력

업체관리 > 업체변경이력
  • 가맹점 정보 변경 이력 전체 조회 (변경 일시·항목·변경 전후 값)
  • 담당자별 변경 이력 필터링
  • 이력 CSV 내보내기

3. 결제관리

결제관리

가맹점별 결제 내역을 조회하고 환불·취소 처리를 수행합니다.

3-1. 결제 내역 조회

결제관리 > 결제내역
조회 조건설명
기간결제 일시 범위 (최대 90일)
가맹점업체명 또는 업체 코드로 필터
결제 수단신용카드, 지갑이체, QR, 가상계좌 등
결제 상태성공 / 실패 / 취소 / 환불 / 대기
주문 번호가맹점 주문 ID로 직접 검색

3-2. 환불 처리

결제관리 > 결제내역 > 상세
①결제 내역에서 환불 대상 거래 선택
②거래 상세 화면 → [환불 신청] 버튼 클릭
③환불 금액 입력 (전체 또는 부분 환불 선택)
④환불 사유 입력 후 확인
⑤환불 완료 후 상태가 환불로 변경됨
주의: 환불은 결제 후 180일 이내만 가능합니다. 기간 초과 건은 총본사에 문의하십시오.

3-3. 취소 처리

결제관리 > 결제내역 > 상세
  • 당일 결제 건: 즉시 취소(Void) 처리 가능
  • 익일 이후 결제 건: 환불(Refund) 절차로 처리
  • 취소 완료 후 가맹점·구매자에게 자동 알림 발송

3-4. 통합내역 / 일별통합 / 통합체크

결제관리 > 통합내역 / 일별통합 / 통합체크
  • 통합내역: 전체 PG 채널 통합 거래 목록
  • 일별통합: 날짜별 집계 통계 — 거래 건수·금액 합계
  • 통합체크: PG사 통보 데이터와 내부 데이터 정합성 검증

4. 정산관리

정산관리

가맹점 정산 내역, 수수료 내역, 잔액·미수금·환수금 현황을 조회합니다. 정산 실행·배포는 총본사 전용입니다.

🔒 정산실행·정산배포·정산대기·통합정산은 총본사 전용 메뉴입니다.
정산 처리 요청이 필요하면 총본사에 요청하십시오.

4-1. 가맹점 정산 내역

정산관리 > 가맹점정산내역
항목설명
정산 기간정산 주기별 기간 조회
정산 금액총 결제액 − 수수료 = 정산 지급액
정산 상태예정 / 완료 / 보류 / 취소
정산 계좌지급 대상 은행·계좌 정보
정산 내역 출력PDF·CSV 형식으로 내보내기

4-2. 수수료 내역

정산관리 > 수수료내역
  • 가맹점별 수수료 부과 내역 조회
  • 결제 수단별 수수료 분류 확인
  • 월별 수수료 집계 리포트 다운로드

4-3. 잔액 / 미수금 / 환수금 / 담보금

정산관리 > 잔액내역 / 미수금내역 / 환수금내역 / 담보금내역
메뉴설명
잔액내역가맹점 보유 잔액 현황 조회
미수금내역미납 정산금 목록 및 금액
환수금내역환불·취소로 인한 환수 금액 내역
담보금내역계약 보증금·담보 설정 현황

4-4. 정산 보류 내역 / 정산 리포트

정산관리 > 정산보류내역 / 정산리포트
  • 정산보류내역: 리스크·계약 이슈로 보류된 정산 건 조회
  • 정산리포트: 월별·분기별 정산 통계 리포트 출력

5. 챗봇관리

챗봇관리
✅ 챗봇관리(기본설정·상품관리·주문관리)는 본사·총판 모두 전체 접근 가능합니다.

5-1. 기본 설정

챗봇관리 > 기본설정
①가맹점 선택 → 챗봇 운영 모드 선택
②상품 슬롯 수 설정 (가맹점 등록 가능 상품 최대 수량)
③챗봇 결제 URL·QR 코드 확인 후 가맹점 안내
④임베드 스크립트 발급 — 가맹점 홈페이지 위젯 삽입용
운영 모드설명결제 방식
SALE_PREPAID판매 — 선불주문 즉시 결제
SALE_POSTPAID판매 — 후불상품 제공 후 청구
RESERVATION_PREPAID예약 — 선불예약 시 즉시 결제
RESERVATION_POSTPAID예약 — 후불예약 후 현장 결제
HYBRID_RESERVATION_PREPAID하이브리드 예약 — 선불예약금 선결제 + 잔금 후불
FACE_TO_FACE_POSTPAID대면 — 후불현장 서비스 후 결제 링크 발송

5-2. 상품 관리

챗봇관리 > 상품관리
①가맹점 선택 → 상품 목록 진입
②상품 등록: 상품명, 설명, 가격, 이미지, 카테고리, 재고 여부
③상품 활성화 / 비활성화 (챗봇 내 노출 여부 제어)
④슬롯 한도 초과 시 추가 등록 불가 → 슬롯 수 조정 필요

5-3. 주문 관리

챗봇관리 > 주문관리
  • 주문 번호·고객 정보·결제 상태·금액·일시 조회
  • 주문 상세 확인 및 환불 처리
  • 후불 주문: 결제 청구 링크 재발송
  • 주문 통계: 일별·주별·월별 주문 현황

6. 분할관리

분할관리
🔒 분할관리 > 이메일설정은 총본사 전용입니다.
이메일 템플릿·발송 서버 설정 변경이 필요하면 총본사에 요청하십시오.

6-1. 진행 관리

분할관리 > 진행관리
①가맹점 선택 → [신규 분할 계약] 등록
②총 결제 금액 및 분할 횟수 설정 (예: 300,000원 / 3회 → 100,000원 × 3)

9. FAQ — 자주 묻는 질문

본사정책 메뉴가 보이지 않습니다.
V2.0에서 기존 '본사설정'은 '본사정책' 허브 그룹으로 변경되었으며, 총본사 전용 메뉴입니다. 수수료·리스크·결제 URL 등 정책 설정 변경이 필요하면 총본사(슈퍼관리자)에게 요청하십시오. 버전 변경 내역은 본사정책 > 플랫폼 > 업데이트 내용에서 확인할 수 있습니다.
통보관리 메뉴에 접근할 수 없습니다.
통보관리는 총본사 전용 메뉴입니다. 결제 통보 URL·알림 설정 변경이 필요하면 총본사에 요청하십시오. 본사·총판은 노티관리(운영관리 하위)에서 통보 수신 이력을 조회할 수 있습니다.
정산실행·정산배포 메뉴가 보이지 않습니다.
정산실행·정산배포·정산대기·통합정산은 총본사 전용 메뉴입니다. 가맹점 정산 내역·수수료 내역·잔액 현황은 정산관리 하위 메뉴에서 조회 가능합니다. 정산 실행 처리가 필요하면 총본사에 요청하십시오.
분할결제 이메일 설정이 비활성화되어 있습니다.
분할관리 > 이메일설정은 총본사만 접근 가능합니다. 이메일 템플릿 변경이 필요하면 총본사에 문의하십시오. 이메일 발송 이력 조회 및 재발송은 분할관리 > 이메일관리에서 가능합니다.
가맹점에 결제 서비스를 활성화했는데 가맹점이 URL을 볼 수 없다고 합니다.
업체정보에서 해당 서비스의 사용여부가 Y로 설정되어 있는지 확인하십시오. N 상태이면 가맹점 포털에 URL이 표시되지 않습니다. 저장 후 가맹점에 재로그인 또는 페이지 새로고침을 안내하십시오.
API 문서는 어디서 확인하나요?
연동·배포 > 가맹 API 출시 > API 문서 탭에서 확인할 수 있습니다. 본사·총판 역할도 이 탭은 열람 가능합니다. PG사 연동 실행은 총본사 전용입니다.
수수료 관리와 본사정책의 수수료 설정 차이는 무엇인가요?
업체관리 > 수수료관리는 특정 가맹점에만 적용되는 개별 수수료율을 설정합니다. 본사정책 > 수수료·리스크는 시스템 전체 기본 수수료 정책으로 총본사만 접근 가능합니다. 개별 수수료가 등록된 가맹점은 기본 정책보다 개별 수수료가 우선 적용됩니다.
총판과 본사의 접근 권한에 차이가 있나요?
아니오, 본사와 총판은 완전히 동일한 접근 권한을 가집니다. 두 역할 모두 총본사 전용 메뉴(본사정책, 통보관리, 정산실행·배포·대기 등)에는 접근할 수 없습니다.
