# 가맹점 정산방법 필드 (tb_settlement_setting)

| UI 항목 | 필드명 | 비고 |
|---------|--------|------|
| 정산주기 | `calcCycle` | RT, D+N, W+N, WK1W/WK2W/WK1WT/WK2WT 등 |
| 정산마감시간 | `calcCloseTime` | TIME |
| 정산자동개시시간 | `calcStartTime` | TIME |
| 정산구분 | `calcProcType` | MANUAL / AUTO / FUMBANKING |
| 이체및송금구분 | `transferType` | MANUAL / AUTO / NONE (펌뱅킹 연동) |
| 이체주기(일) | `transferCycleDays` | |
| 이체시간 | `transferExecTime` | TIME, 펌뱅킹 연동 시 |
| 정산제외여부 | `calcExcludeYn` | Y/N |
| 정산제외대상 | `calcExcludeTarget` | NONE, WEB, OFFLINE, BOTH |
| 지급보류 | `payHoldYn` | |
| 정산최소금액 | `calcMinAmt` | 미만 시 다음 주기 이월(배치 로직 연동 예정) |
| 이체및송금최소금액 | `autoTransferMin` | 펌뱅킹 송금 하한 |

**PostgreSQL** 운영 DB에는 `pg-app/src/main/resources/db/V25_merchant_settlement_method_extend.sql` 실행 후 배포하세요.
