# 정산주기(calc_cycle) 전체 명세

본 문서는 **현재 구현 로직과 동일**하게, 저장 코드·정규화·자동 실행 경로·집계 방식을 한곳에 정리합니다. 구현 근거는 `SettlementPeriodResolver`, `SettlementCycleTiming`, `SettlementAutoRunService`, `SettlementCalcService`, `SettlementScheduledJob`, `HqSettlementCycleAdminService`(내장 `BUILT_INS`)입니다.

---

## 1. 공통: 저장값 정규화

`SettlementPeriodResolver.normalizeCalcCycle` 적용 후 비교·실행 판별이 이루어집니다.

| 입력(예) | 정규화 결과 | 비고 |
|-----------|-------------|------|
| 공백·소문자·`+` 제거 | 대문자 등으로 통일 | |
| `TM05` | `TM5` | |
| `1D`…`12D` (구 코드) | `H1`…`H12` | `4D`→`H4`, `12D`→`H12` 등 |
| `REALTIME` | `RT` | |
| 그 외 | `trim`·대문자·`+` 제거만 | `WK1W` 등 그대로 |

**NONE**: 자동 정산 대상에서 제외(가맹 설정에 따라).

---

## 2. 자동 실행이 도는 조건(운영)

| 항목 | 내용 |
|------|------|
| 스케줄 | `SettlementScheduledJob`: 기본 `app.settlement.autoRunCron` = **매분** (`0 * * * * *`). M5·H1 등 격자 정각을 맞추려면 **매분 실행이 전제**입니다. |
| 스위치 | `app.settlement.autoRunEnabled=true` 일 때만 스케줄 Bean 등록. |
| 가맹 | `settlement_setting.calc_proc_type = AUTO` 인 가맹만 배치에서 처리(`requireAutoProcType=true`). |
| 정산 제외 영업일 | `calc_exclude_yn=Y` 이고 당일이 비영업일(토·일 + 가맹 소속 총판 영업일·휴일)이면 스킵. |
| 영업일·공휴 | `W+N`·`WK*`·`D1~D30` 의 +N·역산은 `SettlementBusinessHolidayService` 가 **가맹 소속 총판** 영업일·휴일(본사 영업일설정·상속)을 반영. 도래 정산일이 비영업일이면 **다음 영업일**로 미룸. |
| 달력 주기 공통 | `calc_close_time`(마감 시각)이 설정되어 있으면 **현재 시각이 마감 이후**일 때만 `execute` 경로 진입. `D1+`·`W`·`WK` 는 `calc_start_time` 도 설정 시 **개시 이후**만. |
| 달력 주기당 1일 1회 | 동일 가맹·동일 **정산일(달력일)** 에 이미 정산 실행이 있으면(`alreadyDoneToday`) **추가 자동 `execute` 없음**. (서브데이 격자는 이 제한 **밖** — 아래 3절) |

## 3. 실행 경로 분류(로직 그대로)

### A. 분·시간 격자 — **스케줄 매분** + 격자 정각

**대상 코드(정규화 후):**  
`M5`, `M10`, `M30`, `H1`, `H2`, `H4`, `H6`, `H8`, `H12`,  
그리고 **`TM5`·`TM10`·`TM30`·`TH1`·`TH2`·`TH4`·`TH6`·`TH8`·`TH12`**  
(이들은 격자 시각 판별 시 **plain 격자**로 환산: `TM5`→`M5`, `TH12`→`H12`.)

| 구분 | 격자 시각(`shouldRunSubDailyNow`) | 집계·저장 방식(`triggerSubDailyAutoSettlement`) |
|------|-----------------------------------|------------------------------------------------|
| **M5 / M10 / M30** | 분이 각각 5·10·30의 배수인 분 정각 | **직전 N분** 구간 합산 1건(`appendSubDailyGridAggregateSettlement`). `period_end_at` = 격자 배타 상한. |
| **H1 / H2 / … / H12** | 시각 **분=0** 이고 **시 % N = 0** (N=1,2,4,6,8,12) | **직전 N시간** 구간 합산 1건(동일). `calc_dt`는 격자 **구간 시작일** 기준(자정에 끝나는 밤 구간도 전일과 같은 정산일에 묶이도록 구현됨). |
| **TM* / TH*** | 위와 **동일한 격자 시각** | **당일 00:00 ~ 현재** 전체 재집계 1행(`recalcTodayIntradayAuto`, T0식). 격자는 “언제 돌지”만 담당. |

**RT·T0:** 이 스케줄 루프에서는 `isRealtimeCode` 분기로 **건너뜀**(아래 B).

### B. 실시간 계열 — **승인(결제완료) 노티 등**에서 호출

**대상:** `RT`, `T0`  
(`SettlementCalcService.triggerRealtimeAutoSettlementIfDue`)

| 코드 | 동작 |
|------|------|
| **RT** | 승인 1건(또는 해당 건)만 집계한 실행 1건 추가(건당 마감). |
| **T0** | 승인 시마다 당일 00:00~현재까지 **전체 재집계** 후 당일 행 1건 갱신(`recalcTodayIntradayAuto`). |

### C. 달력·영업일 기반 — **스케줄 매분** + “오늘이 정산일”일 때만 `execute` 1회

**대상:** `D0`~`D90`, `W1`~`W28`, `WK1W`/`WK2W`/`WK1WT`/`WK2WT`/`WK1WM`/`WK2WM`  
`SettlementPeriodResolver.resolveAutoPeriodWindow`가 **오늘**을 정산 실행일로 판단할 때만 `PeriodWindow` 반환 → `SettlementCalcService.execute(from,to,mid)`.

| 코드 | 요약 |
|------|------|
| **D0** | 집계 기준일 = 정산일(당일 하루). 자동은 추가로 **`isD0AutoBatchAllowedNow`**: 서울 **00:00 ≤ 시각 &lt; 23:51** 안에서만. |
| **D1~D30** | 집계 기준일 = 정산일에서 **N영업일 역산**한 하루. |
| **D31~D90** | 집계 기준일 = 정산일에서 **N달력일 역산**한 하루. |
| **W+N** | 월~일 주간 구간 중, 일요일 마감 후 **+N영업일**(도래일 비영업일 시 다음 영업일 보정)로 **오늘이 정산일**일 때만 해당 주 구간 집계. |
| **WK*** | 1주 또는 격주 2주(월~일/14일) 마감 후 **영업일 3·10·30일째** 등 규칙으로 정해진 **오늘이 정산일**일 때만 해당 구간 집계. |

세부·워킹데이: `docs/정산주기_영업일_가이드.md` 참고.

## 4. 코드별 요약 표(내장 표준과 동일 범주)

| 저장 코드 | 유형 | 자동 실행 트리거 | 집계 구간(개념) |
|-----------|------|------------------|-----------------|
| NONE | — | 없음 | — |
| RT | 실시간 | 승인 노티 | 건별 |
| T0 | 실시간 | 승인 노티 | 당일 0시~현재(재집계) |
| M5,M10,M30 | 격자 | 매분 스케줄 중 격자 정각 | 직전 N분 |
| H1,H2,H4,H6,H8,H12 | 격자 | 매분 스케줄 중 격자 정각 | 직전 N시간 |
| TM5,TM10,TM30 | 격자+당일합산 | M계열과 동일 시각 | 당일 0시~현재(재집계) |
| TH1,TH2,TH4,TH6,TH8,TH12 | 격자+당일합산 | H계열과 동일 시각 | 당일 0시~현재(재집계) |
| D0~D90 | 달력 | 정산일·마감·D0시간대·당일 미실행 | `resolveAutoPeriodWindow` |
| W1~W28 | 주간+오프셋 | 동상 | 동상 |
| WK1W,WK2W,WK1WT,WK2WT,WK1WM,WK2WM | 주간 WK | 동상 | 동상 |

커스텀 등록 시 검증 허용 범위는 `HqSettlementCycleAdminService.validateCycleCode` 메시지와 `INTRADAY_CODES`·`WK_CODES`·D/W 패턴과 일치합니다.

---

## 5. 수동 「정산실행」

화면에서 기간·가맹을 지정한 실행은 `execute(..., manualExecuteRules=true)`로, **AUTO 가맹 제외·달력 주기·마감·영업일** 등 별도 규칙이 적용됩니다. 서브데이(RT/M/H 등)와 동일 저장 테이블을 쓰나, **자동 격자 스케줄과는 별 경로**입니다.
