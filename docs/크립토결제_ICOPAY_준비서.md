## 관리 메뉴 (현행)

```
본사설정
 └─ 크립토설정          → 수탁 주소 · 가맹별 설정 (/hq/cryptoSettings)

결제관리
 ├─ 결제내역
 └─ 크립토내역          → 입금 대기 · Tx 확정 (/calc/cryptoPayList)  ※결제내역 바로 아래

정산관리
 ├─ 수수료내역
 └─ 크립토정산          → 반자동 Tx · AUTO (/settlement/cryptoPayoutQueue)  ※수수료내역 바로 아래
```

| 메뉴 | 위치 | 화면 |
|---|---|---|
| 크립토설정 | 본사설정 | 수탁·가맹 설정 |
| 크립토내역 | 결제관리 (결제내역 밑) | 입금 목록·확정 |
| 크립토정산 | 정산관리 (수수료내역 밑) | 출금 큐 |

B안(본사정책)에서는 **결제·URL → 크립토설정** 탭으로 동일 설정 화면을 엽니다.  
입금/출금은 결제관리·정산관리 메뉴를 그대로 사용합니다.
