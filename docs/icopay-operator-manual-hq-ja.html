📋 命名原則

ICOPAYは単一APIの背後で複数の決済代行会社を統合するプラットフォームです。本マニュアルの統合機能（チェックアウト、URL決済、統合取引等）では中立的なICOPAY用語を使用します。「JPAY専用」表記はJPAY固有機能にのみ使用されます。

2. 加盟店管理

加盟店管理

加盟店の登録・更新・手数料管理・変更履歴を担当するコアメニューです。本社・総販代理店ともに全アクセスが可能です。

2-1. 新規加盟店登録

加盟店管理 > 加盟店管理
①加盟店管理 > 加盟店管理 メニューへ → [新規登録] ボタンをクリック
②基本情報の入力 — 店舗名、法人番号、代表者名、連絡先、メール、住所
③精算構成の設定 — 精算サイクル、手数料率、振込先口座
④利用する決済サービスを有効化（Web決済・定期・再購入・分割払い・チャットボット）。Web決済時はカード認証方式（本社ポリシーに従う / 3DS / 2DS）を選択 — URL・APIインライン同一。定期の初回は常に3DS
⑤保存 → 加盟店コードが自動生成 → 決済URLを確認
⑥加盟店アカウント（ID・仮パスワード）を生成し担当者へ通知

2-2. 加盟店情報の照会・編集

加盟店管理 > 加盟店情報照会
  • 店舗名・法人番号・ステータス（有効/無効）で検索
  • 加盟店詳細 → 基本情報・決済設定・精算設定タブで編集
  • 加盟店ステータスの切り替え：有効 / 一時停止 / 無効
  • お知らせタブ：加盟店向けお知らせの登録・管理

2-3. 手数料管理

加盟店管理 > 手数料管理

加盟店ごとの個別手数料率を設定します。本社ポリシーの基本手数料（スーパー管理者専用）とは独立して適用されます。

①設定対象の加盟店を選択
②決済手段ごとの個別手数料率を入力（クレジットカード・ウォレット送金・QRなど）
③適用期間（開始日・終了日）を設定 — プロモーション手数料期間に対応
④保存 → 対象加盟店のみに即時適用（基本ポリシーより優先）
加盟店ごとの個別手数料が登録されると、基本ポリシー手数料より優先して適用されます。個別手数料が未登録の加盟店は自動的に基本ポリシー手数料が適用されます。
🔒 基本手数料ポリシー（本社ポリシー > 手数料・リスク）はスーパー管理者専用です。
基本手数料ポリシーの変更が必要な場合は、スーパー管理者にお問い合わせください。

2-4. 加盟店変更履歴

加盟店管理 > 加盟店変更履歴
  • 加盟店情報の変更履歴全件照会（変更日時・項目・変更前後の値）
  • 担当者別変更履歴のフィルタリング
  • CSVエクスポート

3. 決済管理

決済管理

加盟店ごとの決済履歴を照会し、返金・取消処理を行います。

3-1. 決済履歴照会

決済管理 > 決済履歴
検索条件説明
期間決済日時の範囲（最大90日）
加盟店店舗名または加盟店コードでフィルタ
決済手段クレジットカード、ウォレット、QR、仮想口座など
決済ステータス成功 / 失敗 / 取消 / 返金 / 保留
注文番号加盟店の注文IDで直接検索

3-2. 返金処理

決済管理 > 決済履歴 > 詳細
①決済履歴から返金対象の取引を選択
②取引詳細画面 → [返金申請] ボタンをクリック
③返金金額を入力（全額または部分返金）
④返金理由を入力して確認
⑤返金完了後、ステータスが 返金済み に変更
注意： 返金は決済後180日以内のみ可能です。期間超過の場合はスーパー管理者にお問い合わせください。

3-3. 取消処理

決済管理 > 決済履歴 > 詳細
  • 当日決済分：即時ボイド処理が可能
  • 翌日以降の決済分：返金処理として対応
  • 取消完了後、加盟店・購入者に自動通知

3-4. 統合履歴 / 日別統合 / 統合チェック

決済管理 > 統合履歴 / 日別統合 / 統合チェック
  • 統合履歴：全PGチャネルの統合取引リスト
  • 日別統合：日付別集計統計 — 取引件数・金額合計
  • 統合チェック：PG通知データと内部データの整合性検証

5. チャットボット管理

チャットボット管理
✅ チャットボット管理（基本設定・商品管理・注文管理）は本社・総販代理店ともに全アクセス可能です。

5-1. 基本設定

チャットボット管理 > 基本設定
①加盟店を選択 → チャットボット運営モードを選択
②商品スロット数を設定（加盟店が登録可能な商品の最大数）
③チャットボット決済URL・QRコードを確認して加盟店に案内
④埋め込みスクリプト発行 — 加盟店のウェブサイトへのウィジェット挿入用
運営モード説明決済方式
SALE_PREPAID販売 — 前払い注文時に即時決済
SALE_POSTPAID販売 — 後払い商品提供後に請求
RESERVATION_PREPAID予約 — 前払い予約時に即時決済
RESERVATION_POSTPAID予約 — 後払い予約後に現地決済
HYBRID_RESERVATION_PREPAIDハイブリッド予約 — 前払い予約金先払い＋残金後払い
FACE_TO_FACE_POSTPAID対面 — 後払い現地サービス後に決済リンク送付

5-2. 商品管理

チャットボット管理 > 商品管理
①加盟店を選択 → 商品リストへ
②商品登録：商品名、説明、価格、画像、カテゴリ、在庫有無
③商品の有効化 / 無効化（チャットボット内の表示制御）
④スロット上限を超えた場合は追加登録不可 → スロット数の調整が必要

5-3. 注文管理

チャットボット管理 > 注文管理
  • 注文番号・顧客情報・決済ステータス・金額・日時の照会
  • 注文詳細の確認および返金処理
  • 後払い注文：決済請求リンクの再送
  • 注文統計：日別・週別・月別の注文状況

6. 分割払い管理

分割払い管理
🔒 分割払い管理 > メール設定はスーパー管理者専用です。
メールテンプレート・送信サーバーの設定変更が必要な場合はスーパー管理者にご連絡ください。

6-1. 進行管理

分割払い管理 > 進行管理
①加盟店を選択 → [新規分割払い契約] を登録
②総支払金額と分割回数を設定（例：30,000円 / 3回分割 → 10,000円 × 3）
③各回の支払期限（Due Date）を設定
④契約保存 → 各回の決済URLが自動生成
⑤顧客に各回の決済URLを送付（メール・SMS・リンク共有）
項目説明
契約リスト進行中の契約ステータス照会
各回決済URL各回の決済リンクの確認・コピー
決済状況追跡各回の決済完了/未決済状況
契約取消/修正進行中の分割払い契約の変更または取消

6-2. メール管理

分割払い管理 > メール管理
  • 分割払い通知メールの送信履歴照会
  • 特定回のメール再送
  • 送信失敗件の確認と再処理
メールテンプレート・送信サーバーの設定はメール設定メニュー（スーパー管理者専用）で管理されます。本社・総販代理店はメール管理（送信履歴照会・再送）のみ利用可能です。

9. よくある質問（FAQ）

本社ポリシーメニューが表示されません。
ICOPAY V2.0では、旧「本社設定」が「本社ポリシー」ハブグループに変更され、スーパー管理者専用メニューとなっています。バージョン履歴は本社ポリシー > プラットフォーム > アップデート内容で確認できます。
通知管理メニューにアクセスできません。
通知管理はスーパー管理者専用メニューです。決済通知URL・アラート設定の変更が必要な場合はスーパー管理者にご連絡ください。本社・総販代理店は通知管理（運営管理配下）で通知受信履歴を照会できます。
精算実行・精算デプロイメニューが表示されません。
精算実行・精算デプロイ・精算待機・統合精算はスーパー管理者専用メニューです。加盟店精算履歴・手数料履歴・残高状況は精算管理のサブメニューで照会可能です。精算処理が必要な場合はスーパー管理者にご連絡ください。
分割払いのメール設定が無効になっています。
分割払い管理 > メール設定はスーパー管理者専用です。メールテンプレートの変更はスーパー管理者にお問い合わせください。メール送信履歴の照会と再送は分割払い管理 > メール管理でご利用いただけます。
加盟店にサービスを有効化したのに、加盟店がURLを確認できないと言っています。
加盟店情報で該当サービスの使用可否がYに設定されているかご確認ください。Nの状態では、加盟店ポータルにURLが表示されません。保存後に加盟店に再ログインまたはページのリロードをご案内ください。
APIドキュメントはどこで確認できますか？
連携・デプロイ > 加盟店API公開 > APIドキュメントタブで確認できます。本社・総販代理店の役割もこのタブは閲覧可能です。PG連携実行はスーパー管理者専用です。
手数料管理と本社ポリシーの手数料設定の違いは何ですか？
加盟店管理 > 手数料管理は特定の加盟店にのみ適用される個別手数料率を設定します。本社ポリシー > 手数料・リスクはシステム全体の基本手数料ポリシーで、スーパー管理者専用です。個別手数料が登録された加盟店には、基本ポリシーよりも個別手数料が優先適用されます。
総販代理店と本社のアクセス権限に違いはありますか？
いいえ、本社と総販代理店は完全に同一のアクセス権限を持ちます。両役割ともスーパー管理者専用メニュー（本社ポリシー、通知管理、精算実行・デプロイ・待機など）にはアクセスできません。
