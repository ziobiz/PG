PG별로 **매뉴얼을 분리**했습니다. 가맹점에는 아래 해당 문서(MD·PDF)만 배포하면 됩니다.

| 배포 대상 | 문서 (MD / PDF 동명) |
|-----------|----------------------|
| ChillPay 연동 가맹 | `가맹점_ChillPay_API_연동가이드.md` · `.pdf` |
| JPAY 연동 가맹 | `가맹점_JPAY_API_연동가이드.md` · `.pdf` |
