# ICOPAY 가맹점 API 연동 매뉴얼 — 목차·배포 안내

가맹점에게는 **ICOPAY 통합 문서만** 노출합니다.  
결제대행사(운영 PG) 이름·PG별 URL은 가맹 화면에 **넣지 않습니다**.

---

## 공식 전달 경로 (필수)

가맹점은 **별도 메일·파일 배포 없이**, 관리자 로그인 후 아래 메뉴에서 연동합니다.

1. 본사: 배포설정 → **가맹점 API 생성**으로 브로커 시크릿·API 배포 완료  
2. 가맹점: **로그인 → 업체관리 → 가맹점API** (`/comp/merchantApiPortal`)  
3. 화면에 표시되는 내용이 곧 연동 스펙입니다.  
   - 연동 키(compId·브로커 시크릿·API 베이스 URL)  
   - 연동 빠른 시작(3단계)  
   - Checkout 엔드포인트·**파라미터 규격 표**  
   - 샘플·체크리스트·WordPress(해당 시)  
   - **활성화된 기능 안내**(해당 가맹에 켜진 부가 기능만)

본사 **API배포문서**(`/hq/merchantApiDeployDocs`)는 위와 **동일 키트**의 미리보기입니다.  
가맹점에 ZIP/MD를 따로 보낼 필요가 없습니다.

---

## 기능별 문서 노출 (필수)

가맹점마다 켜진 기능만 배포 문서·화면에 넣습니다. **미사용 기능 매뉴얼을 같이 주면 혼란**이 생기므로 금지합니다.

| 기능 | 가맹 플래그(요지) | 문서에 포함되는 경우 |
|------|-------------------|---------------------|
| 기본 Checkout·Webhook | API 배포 완료 | 항상(채널 ON인 인라인/리다이렉트/WP만) |
| 정기결제(구독) | `apiJpaySubscriptionUseYn=Y` (+ 본사 구독 ON) | 구독 Checkout 엔드포인트·체크리스트·기능 안내 |
| 챗봇결제 | `chatbotPaymentUseYn=Y` | 「활성화된 기능 안내」챗봇 안내만 (구독·분할 매뉴얼 미포함) |
| 분할결제 | `splitPayEnabledYn=Y` | 「활성화된 기능 안내」분할 안내만 |

메뉴 노출도 동일 플래그를 따릅니다(챗봇관리·분할관리·구독내역 등).  
오프라인 HTML 전체 매뉴얼을 가맹에 일괄 배포하지 말고, **로그인 후 가맹점API 화면**을 공식 문서로 쓰세요.
