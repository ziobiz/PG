### 1.2 오류 가능 원인 (어제 개발 못한 이유 추정)

1. **로컬 실행 실패**
   - gradlew.bat 경로/실행 오류 (PowerShell `&&` 미지원, 경로 인코딩 등)
   - JAVA_HOME 미설정 또는 Java 17 미설치

2. **API 주소 불일치**
   - site를 Live Server(5500)로 띄우고 pg-app을 8080으로 띄운 경우, `PG_API_BASE`가 비어 있으면 API 호출이 5500으로 감 → 실패
   - 해결: `?api=http://localhost:8080` 또는 config.js에서 localhost일 때 `http://localhost:8080` 설정

3. **시드 데이터 부족**
   - DataLoader: HQ01(총본사), M001/M002(가맹점, parent=HQ01)만 존재
   - 업체구분 계층: 총본사→본사→총판→지사→대리점→가맹점
   - **본사(REGIONAL)** 없음 → 총판 등록 시 상위 선택 불가
   - **대리점(AGENCY)** 없음 → 가맹점 등록 시 상위 선택 불가
   - M001/M002는 MERCHANT인데 parent가 HQ01(HEADQUARTERS) → 검증 규칙상 부적합 (가맹점 상위는 대리점이어야 함)

4. **상위지점 검색 모달**
   - compReg의 parentComp [검색] 버튼 → `openParentCompSearchModal()` 호출
   - 모달은 index.html에 있음. compReg이 placeholder로 로드되면 모달은 부모 document에 있어 `getElementById`로 접근 가능 (같은 document면 OK)
   - **iframe 사용 시**: compReg이 iframe 안에 있으면 `document.getElementById('parentCompSearchModal')`은 iframe의 document를 참조 → 모달이 없을 수 있음
   - app.js의 contentMode: `placeholder` vs `iframe` 확인 필요

- [ ] 업체관리 → 등록 버튼 → 업체등록 탭 표시

### 2.2 config.js (로컬 API) ✅ 적용됨
- [x] localhost/127.0.0.1일 때 `PG_API_BASE = 'http://localhost:8080'` 자동 설정
- [ ] site를 5500 등 다른 포트에서 띄워도 API는 8080으로 호출

### 2.3 시드 데이터 보완 (DataLoader) ✅ 적용됨
- [x] HQ01 → R01(본사) → D01(총판) → B01(지사) → A01(대리점) → M001, M002(가맹점) 체인 추가
- [x] M001, M002의 parent를 A01(대리점)로 변경

### 2.4 업체등록 폼 동작
- [ ] 업체구분 선택 시 해당 섹션(본사/총판·지사·대리점/가맹점) 표시
- [ ] 상위 지점 [검색] 클릭 → 모달 오픈 → API 호출 → 선택 시 parentComp, parentId 반영
- [ ] 저장 시 필수값 검증 (상위지점 필수 등)
- [ ] 저장 성공 → 수수료관리 또는 업체관리로 이동

### 2.5 contentMode (placeholder vs iframe)
- [ ] `SITE_CONFIG.contentMode === 'placeholder'` 이면 compReg HTML이 index.html과 같은 document에 삽입 → parentCompSearchModal 접근 가능
- [ ] iframe이면 모달이 index에 있어도 iframe 내부에서 `parent.document.getElementById` 필요할 수 있음 → 확인

## 3. 권장 수정 사항

### 3.1 config.js - localhost 시 API 주소 명시
```javascript
} else if (host === 'localhost' || host === '127.0.0.1') {
  window.PG_API_BASE = 'http://localhost:8080';
} else {
  window.PG_API_BASE = '';
}
```
→ localhost에서 항상 8080으로 API 호출 (site 포트와 무관)

### 3.2 DataLoader - 시드 데이터 보완
본사(R01)→총판(D01)→지사(B01)→대리점(A01) 체인 추가, M001/M002 parent를 A01로 변경

### 3.3 로컬 실행 배치
- `로컬_실행.bat`: `cd pg-app` 후 `gradlew.bat bootRun` (경로 확인)
- `로컬_실행_java.bat`: gradle wrapper jar 사용 (wrapper 존재 여부 확인)
