본사 키트 JSON의 integrationModes.json · integrationModes.php 와 함께 사용하세요.

① JSON (REST 직접 호출)

  1. docs/unified-checkout-api-parameters.html — Prepare API 파라미터 표 (표 1.1·1.2)
  2. json/README.txt
  3. unified-prepare-request.json — prepare 요청 본문
  4. unified-prepare-response.example.json — 응답 예시

가맹 서버에서 POST .../merchant/checkout/prepare → sessionToken → /v1/embed-checkout/{compId}

② PHP

  1. php/icopay_config.example.php → icopay_config.php (document root 밖 권장)
  2. php/IcopayMerchantApi.php — API 클라이언트
  3. checkout_unified.php — 통합 checkout (권장)
  4. checkout_chillpay.php | checkout_jpay.php — 레거시 PG별
  5. notify_webhook.php — 웹훅 스텁
  6. common/icopay-checkout.js — postMessage 수신

JSP (Java 11+)

  1. jsp/icopay-config.example.properties
  2. jsp/IcopayMerchantApi.sample.java
  3. checkout-chillpay.jsp | checkout-jpay.jsp
  4. jsp/notify-webhook.jsp

연동 순서

주문 생성 → 서버 prepare (JSON REST 또는 PHP) → sessionToken → embed → postMessage / 웹훅
