2. ข้อกำหนดล่วงหน้า (HQ)

  
  

    

Item

Note

    

Merchant crypto use = Y

Company detail or HQ Policy → Pay·URL → Crypto settings

    

Allowed assets

e.g. USDT only for first go-live

    

Merchant receive wallet

One network + address per enabled asset (settlement payout)

    

HQ custody wallet

ICOPAY deposit address for that asset×network

    

Company use = Y

Unused / permanent stop blocks crypto

  

  
3. Prepare (แนะนำ)

  
  

POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

  
Header: 
Content-Type: application/json
, 
X-Icopay-Merchant-Broker-Secret
 (same live secret as cards).

  
{
  "compId": "6000000064",
  "orderNo": "ORD-CRYPTO-001",
  "amount": "10000",
  "displayCurrency": "JPY",
  "payMeans": "CRYPTO",
  "productName": "Sample product",
  "lang": "ENG",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR",
    "firstName": "Gildong",
    "lastName": "Hong"
  }
}

  

    

Field

Required

Description

    

payMeans

M*

CRYPTO
 (aliases: checkoutMeans / paymentMeans)

    

amount

M

Display amount; ICOPAY quotes to USD then remittance asset

    

displayCurrency

O

JPY/USD/… — merchant crypto display currency if omitted

    

assetCode / networkCode

O

Optional; shopper can pick on ICOPAY crypto page

    

buyer name/email

M*

Latin letters for name/email; phone digits (same as crypto UI)

  

  

Response:
 
pgVendor
 always 
ICOPAY
. Use 
payUrl
 / 
sessionToken
.
    Crypto session tokens may start with 
cr_
.

  
Alternative: 
POST /api/pay/crypto/prepare
 with 
compId
 (same product rules).

  
4. URL

  
  

    

URL

When

/checkout-all/{compId}

Unified (card + crypto) when web pay and crypto use are both ON

    

/checkout/{compId}

Card URL pay (existing)

  

  
5. Callback / Result

  
  
ไม่ต้องลงทะเบียน Callback คริปโตแยกที่ Payment notify URL
    ยืนยันเงินเข้า → ICOPAY → 
/noti/crypto
 → NOTI ส่งต่อไปยัง callbackUrl บัตรเดิม

  

    
จับคู่คำสั่งซื้อด้วย 
orderid
/
orderNo

    
ทำแบบ idempotent

    
ฟิลด์เพิ่ม: 
assetCode
, 
networkCode
, 
depositTxHash
