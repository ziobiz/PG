ICOPAY 加密货币 Checkout API — 商户对接

Doc ID: ICOPAY-CRYPTO-CHECKOUT-001 · v1.0 · 2026-10-15 · ICOPAY neutral crypto

相关: 统一 Checkout 流程 · Prepare 参数

1. 范围

在已对接银行卡的同一商户 MID 上增加加密货币支付。对客/对商户仅显示 ICOPAY。

推荐: 统一 prepare 增加 payMeans=CRYPTO。Callback/Result 复用 银行卡 NOTI 注册（按 Comp-Id）。

2. 前提（总部设置）

ItemNote
Merchant crypto use = YCompany detail or HQ Policy → Pay·URL → Crypto settings
Allowed assetse.g. USDT only for first go-live
Merchant receive walletOne network + address per enabled asset (settlement payout)
HQ custody walletICOPAY deposit address for that asset×network
Company use = YUnused / permanent stop blocks crypto

3. Prepare（推荐）

POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

Header: Content-Type: application/json, X-Icopay-Merchant-Broker-Secret (same live secret as cards).

{
  "compId": "6000000064",
  "orderNo": "ORD-CRYPTO-001",
  "amount": "10000",
  "displayCurrency": "JPY",
  "payMeans": "CRYPTO",
  "productName": "Sample product",
  "lang": "ENG",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR",
    "firstName": "Gildong",
    "lastName": "Hong"
  }
}
FieldRequiredDescription
payMeansM*CRYPTO (aliases: checkoutMeans / paymentMeans)
amountMDisplay amount; ICOPAY quotes to USD then remittance asset
displayCurrencyOJPY/USD/… — merchant crypto display currency if omitted
assetCode / networkCodeOOptional; shopper can pick on ICOPAY crypto page
buyer name/emailM*Latin letters for name/email; phone digits (same as crypto UI)

Response: pgVendor always ICOPAY. Use payUrl / sessionToken. Crypto session tokens may start with cr_.

Alternative: POST /api/pay/crypto/prepare with compId (same product rules).

4. URL 渠道

URLWhen
Crypto payment URLCrypto-only link on company crypto card
/checkout-all/{compId}Unified (card + crypto) when web pay and crypto use are both ON
/checkout/{compId}Card URL pay (existing)

5. Callback / Result

勿在公司详情「支付通知 URL」单独注册加密 Callback。 入金确认 → ICOPAY → /noti/crypto → NOTI 转发至既有银行卡 callbackUrl。
  • 用 orderid/orderNo 匹配订单
  • 幂等处理
  • 额外字段: assetCode, networkCode, depositTxHash

6. 上线检查

  • HQ crypto use + asset + custody + receive wallet for the MID
  • prepare with payMeans=CRYPTO → open payUrl → small deposit → HQ Crypto deposits confirm
  • Callback received on existing card URL; store crypto fields
  • Card regression still OK
