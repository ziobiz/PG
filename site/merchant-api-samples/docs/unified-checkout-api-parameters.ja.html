表 1.1 · ICOPAY 統合 Checkout Prepare API リクエストパラメータ

文書 ID: ICOPAY-CHECKOUT-PREPARE-001 · v1.0 · PG 非依存の統合インライン checkout（ChillPay/JPAY 自動振分）

エンドポイント: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

ヘッダー: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret（ブローカーシークレット強制時は必須）

表 1.1 — リクエスト本文（JSON ルート）

番号項目タイプ長さ必須説明備考
1compIdString64M*加盟店企業コード*または merchantId。ICOPAY 付与。
2merchantIdNumber—O加盟店組織 IDcompId の代替可
3orderNoString64M注文・取引参照番号ChillPay 運用: 英数字・-・_ のみ、最大 20。JPAY 運用: 最大 64。
4amountNumber12M決済金額> 0。JPY/KRW は整数推奨。
5currencyString3OISO 4217 通貨USD, JPY, KRW, THB… 省略時は加盟店基準通貨。
6productNameString500O商品・注文説明決済画面に表示
7itemString500OproductName の別名productName がない場合に使用
8langString5O決済画面 UI 言語KOR · ENG · JPN · CHN · THA（または ko/en/ja/zh/th）
9buyerObject—M購入者連絡先・配送 prefill表 1.2 参照。buyerPrefill と同等。

表 1.2 — buyer オブジェクト

番号項目タイプ長さ必須説明備考
1emailString254M購入者メールICOPAY 必須
2phoneString32Mローカル電話番号国番号 + を除去、ローカル番号のみ。
3countryIso2String2M国 ISO 3166-1 alpha-2例: KR, US, TH — 大文字
4addressString200O配送住所 1 行目任意 prefill
5address2String200O配送住所 2 行目
6cityString100O都市
7stateString100O州・県
8postcodeString20O郵便番号zip の別名
9shippingAddressString200O別配送先住所address と異なる場合
10shippingPhoneString32O別配送先電話

リクエストサンプル

{
  "compId": "M000123",
  "orderNo": "ORD-20260501001",
  "amount": 10000,
  "currency": "USD",
  "productName": "Sample product",
  "lang": "ENG",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR"
  }
}

連携方式

  • JSON — 加盟店サーバーから REST を直接呼び出し。キット integrationModes.json を参照。
  • PHP — IcopayMerchantApi::prepareUnifiedCheckout() + checkout_unified.php。
