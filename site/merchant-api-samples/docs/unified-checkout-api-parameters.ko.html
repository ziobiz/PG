표 1.1 · ICOPAY 통합 Checkout Prepare API 요청 파라미터

문서 ID: ICOPAY-CHECKOUT-PREPARE-001 · v1.2 · PG 무관 통합 인라인 checkout (ICOPAY 통합)

엔드포인트: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

헤더: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret (브로커 시크릿 강제 시 필수)

필수값 — 빠지면 prepare가 ICOPAY BUYER_* 로 실패합니다 (결제대행사 영문 오류가 아님)

  • 표 1.1: compId 또는 merchantId, orderNo, amount, buyer
  • 표 1.2: buyer.email, buyer.phone(로컬 번호, 국가번호 + 제거), buyer.countryIso2(대문자 2자, 예: KR, TH, JP)

빈 문자열도 누락입니다. 응답에 errorCode, messageKey, 5개국어 messages(KOR/ENG/JPN/CHN/THA)가 포함됩니다.

표 1.1 — 요청 본문(JSON 루트)

번호항목타입길이필수설명비고
1compIdString64M*가맹점 업체코드*또는 merchantId. ICOPAY 부여.
2merchantIdNumber—O가맹 조직 IDcompId 대체 가능
3orderNoString64M주문·거래 참조번호영숫자·-·_ 권장, 최대 64.
4amountNumber12M결제 금액> 0. JPY/KRW는 정수 권장.
5currencyString3OISO 4217 통화USD, JPY, KRW, THB… 생략 시 가맹 기준통화.
6productNameString500O상품·주문 설명결제창 표시
7itemString500OproductName 별칭productName 없을 때 사용
8langString5O결제창 UI 언어KOR · ENG · JPN · CHN · THA (또는 ko/en/ja/zh/th)
9buyerObject—M구매자 연락처·배송 prefill표 1.2 필수 하위: email·phone·countryIso2 (ICOPAY). buyerPrefill 동일.

표 1.2 — buyer 객체

ICOPAY 필수(M): email, phone(로컬 번호, 국가번호 + 제거), countryIso2(ISO2 대문자). 빈 문자열도 누락입니다. 필드별 오류: BUYER_EMAIL_REQUIRED / BUYER_PHONE_REQUIRED / BUYER_COUNTRY_REQUIRED. 카드번호는 ICOPAY 결제창에서 입력합니다. 카드 명의자 이름·성은 결제창에서 필수(prepare prefill: firstName/lastName 권장).

번호항목타입길이필수설명비고
1emailString254M구매자 이메일필수. 누락 → BUYER_EMAIL_REQUIRED
2phoneString32M로컬 전화번호국가번호 + 제거. 누락 → BUYER_PHONE_REQUIRED
3countryIso2String2M국가 ISO 3166-1 alpha-2예: KR, US, TH — 대문자. 누락 → BUYER_COUNTRY_REQUIRED
4addressString200O배송 주소 1행선택 prefill
5address2String200O배송 주소 2행
6cityString100O도시
7stateString100O주·도
8postcodeString20O우편번호zip 별칭
9firstNameString80O이름(카드 명의 prefill)권장. 결제창에서 필수
10lastNameString80O성(카드 명의 prefill)권장. 결제창에서 필수
11shippingAddressString200O별도 배송지 주소address 와 다를 때
12shippingPhoneString32O별도 배송지 전화

errorCode (필수값)

errorCode의미
BUYER_REQUIREDbuyer 객체 누락, 또는 email·phone·countryIso2 없음(빈 문자열 포함)
BUYER_EMAIL_REQUIREDbuyer.email 누락
BUYER_PHONE_REQUIREDbuyer.phone 누락(로컬 번호)
BUYER_COUNTRY_REQUIREDbuyer.countryIso2 누락 또는 ISO2 아님
BUYER_JSON_INVALIDbuyer JSON 형식 오류
