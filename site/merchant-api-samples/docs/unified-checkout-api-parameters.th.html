ตาราง 1.1 · ICOPAY Unified Checkout Prepare API พารามิเตอร์คำขอ

รหัสเอกสาร: ICOPAY-CHECKOUT-PREPARE-001 · v1.0 · Checkout แบบ inline รวมศูนย์ไม่ผูก PG (ChillPay/JPAY แยกอัตโนมัติ)

Endpoint: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

Headers: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret (จำเป็นเมื่อบังคับใช้ broker secret)

ตาราง 1.1 — Request body (JSON root)

ลำดับรายการประเภทความยาวบังคับคำอธิบายหมายเหตุ
1compIdString64M*รหัสบริษัทร้านค้า*หรือ merchantId ที่ ICOPAY กำหนดให้
2merchantIdNumber—Oรหัสองค์กรร้านค้าใช้แทน compId ได้
3orderNoString64Mเลขอ้างอิงคำสั่งซื้อ/ธุรกรรมChillPay: ตัวอักษร-ตัวเลข - _ เท่านั้น สูงสุด 20 JPAY: สูงสุด 64
4amountNumber12Mจำนวนเงินชำระ> 0 แนะนำใช้จำนวนเต็มสำหรับ JPY/KRW
5currencyString3Oสกุลเงิน ISO 4217USD, JPY, KRW, THB… ค่าเริ่มต้นจากสกุลเงินหลักของร้านค้า
6productNameString500Oคำอธิบายสินค้า/คำสั่งซื้อแสดงบนหน้าชำระเงิน
7itemString500Oชื่อทางเลือกของ productNameใช้เมื่อไม่มี productName
8langString5Oภาษา UI หน้าชำระเงินKOR · ENG · JPN · CHN · THA (หรือ ko/en/ja/zh/th)
9buyerObject—Mข้อมูลติดต่อผู้ซื้อและ prefill การจัดส่งดูตาราง 1.2 buyerPrefill เทียบเท่ากัน

ตาราง 1.2 — ออบเจ็กต์ buyer

ลำดับรายการประเภทความยาวบังคับคำอธิบายหมายเหตุ
1emailString254Mอีเมลผู้ซื้อICOPAY กำหนดให้ต้องมี
2phoneString32Mเบอร์โทรท้องถิ่นตัดรหัสประเทศ + ใช้เฉพาะเลขท้องถิ่น
3countryIso2String2Mประเทศ ISO 3166-1 alpha-2เช่น KR, US, TH — ตัวพิมพ์ใหญ่
4addressString200Oที่อยู่จัดส่งบรรทัด 1prefill ทางเลือก
5address2String200Oที่อยู่จัดส่งบรรทัด 2
6cityString100Oเมือง
7stateString100Oรัฐ/จังหวัด
8postcodeString20Oรหัสไปรษณีย์ชื่อทางเลือก: zip
9shippingAddressString200Oที่อยู่จัดส่งแยกเมื่อต่างจาก address
10shippingPhoneString32Oเบอร์จัดส่งแยก
