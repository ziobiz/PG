ICOPAY Unified Checkout API — Request Parameters (Spec ICOPAY-CHECKOUT-PREPARE-001 v1.2)
======================================================================================

POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare
Content-Type: application/json
X-Icopay-Merchant-Broker-Secret: {brokerSecret}  (when enforce is on)

REQUIRED — prepare fails with ICOPAY BUYER_* if omitted (empty string = missing)
  Table 1.1: compId or merchantId, orderNo, amount, buyer
  Table 1.2: buyer.email, buyer.phone (local digits; strip +country), buyer.countryIso2 (2 uppercase letters)
  Field codes: BUYER_EMAIL_REQUIRED / BUYER_PHONE_REQUIRED / BUYER_COUNTRY_REQUIRED
  Response messages: KOR / ENG / JPN / CHN / THA  (ICOPAY error, not a third-party English message)

Table 1.1 — Request body
No.  Parameter     Type     Len   M/O   Description                    Remark
1    compId        String   64    M*    Merchant company code          *Or merchantId
2    merchantId    Number   -     O     Internal org unit id
3    orderNo       String   64    M     Order reference                max 64, alnum - _ recommended
4    amount        Number   12    M     Payment amount (>0)
5    currency      String   3     O     ISO 4217 (USD,JPY,KRW,THB…)
6    productName   String   500   O     Product description
7    item          String   500   O     Alias for productName
8    lang          String   5     O     UI: KOR|ENG|JPN|CHN|THA
9    buyer         Object   -     M     See Table 1.2

Table 1.2 — buyer object
No.  Parameter          Type     Len   M/O   Remark
1    email              String   254   M     Required. Missing → BUYER_EMAIL_REQUIRED
2    phone              String   32    M     Local number (no +country). Missing → BUYER_PHONE_REQUIRED
3    countryIso2        String   2     M     ISO2 e.g. KR. Missing/invalid → BUYER_COUNTRY_REQUIRED
4    address            String   200   O     Shipping prefill
9    firstName          String   80    O     Cardholder prefill (required on checkout page)
10   lastName           String   80    O     Cardholder prefill (required on checkout page)
5-12 optional shipping fields — see HTML/MD doc
