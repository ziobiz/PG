표 1.1 · ICOPAY Unified Checkout Prepare API Request Parameters

Spec ID: ICOPAY-CHECKOUT-PREPARE-001 · v1.0 · PG-agnostic inline checkout (ChillPay/JPAY auto-routing)

Endpoint: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

Headers: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret (required when broker secret enforce is on)

Table 1.1 — Request body (JSON root)

No.ParameterTypeLenM/ODescriptionRemark
1compIdString64M*Merchant company code*Or merchantId. Assigned by ICOPAY.
2merchantIdNumber—OInternal org unit idAlternative to compId
3orderNoString64MOrder / transaction referenceChillPay op: alnum, -, _ only, max 20. JPAY op: max 64. No + / # etc.
4amountNumber12MPayment amount> 0. JPY/KRW: integer recommended.
5currencyString3OISO 4217 currencyUSD, JPY, KRW, THB… Default from merchant profile.
6productNameString500OProduct / order descriptionShown on checkout page
7itemString500OAlias for productNameUsed if productName omitted
8langString5OCheckout UI languageKOR · ENG · JPN · CHN · THA (or ko/en/ja/zh/th). Also langCode, locale.
9buyerObject—MBuyer contact & optional shipping prefillSee Table 1.2. Key buyerPrefill is equivalent.

Table 1.2 — buyer object

No.ParameterTypeLenM/ODescriptionRemark
1emailString254MBuyer emailRequired by ICOPAY for all merchants
2phoneString32MLocal phone numberStrip country dial code (+82…). Local digits only.
3countryIso2String2MCountry ISO 3166-1 alpha-2e.g. KR, US, TH — uppercase
4addressString200OShipping address line 1Optional prefill
5address2String200OShipping address line 2
6cityString100OCity
7stateString100OState / province
8postcodeString20OPostal codeAlias: zip
9shippingAddressString200OSeparate shipping streetIf different from address
10shippingPhoneString32OSeparate shipping phone

Sample request

{
  "compId": "M000123",
  "orderNo": "ORD-20260501001",
  "amount": 10000,
  "currency": "USD",
  "productName": "Sample product",
  "lang": "ENG",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR"
  }
}

Integration modes

  • JSON — Direct REST from merchant server. See kit integrationModes.json.
  • PHP — IcopayMerchantApi::prepareUnifiedCheckout() + checkout_unified.php.
