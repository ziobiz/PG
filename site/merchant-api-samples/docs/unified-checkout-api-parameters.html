Table 1.1 · ICOPAY Unified Checkout Prepare API Request Parameters

Spec ID: ICOPAY-CHECKOUT-PREPARE-001 · v1.2 · PG-agnostic inline checkout (ICOPAY unified)

Endpoint: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

Headers: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret (required when broker secret enforce is on)

Required — omit these and prepare fails with ICOPAY BUYER_* (not a third-party English error)

  • Table 1.1: compId or merchantId, orderNo, amount, buyer
  • Table 1.2: buyer.email, buyer.phone (local digits; strip +country), buyer.countryIso2 (2 uppercase letters, e.g. KR, TH, JP)

Empty strings count as missing. Response includes errorCode, messageKey, and messages in KOR/ENG/JPN/CHN/THA.

Table 1.2 — buyer object

Required for ICOPAY (M): email, phone (local digits; strip + country code), countryIso2 (uppercase ISO2). Empty strings fail. Missing fields return BUYER_EMAIL_REQUIRED / BUYER_PHONE_REQUIRED / BUYER_COUNTRY_REQUIRED. Card number is entered on the ICOPAY checkout page. Cardholder first/last name is required there (optional prefill: firstName/lastName).
