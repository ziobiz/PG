表 1.1 · ICOPAY 统一 Checkout Prepare API 请求参数

文档 ID: ICOPAY-CHECKOUT-PREPARE-001 · v1.2 · 与 PG 无关的统一内联 checkout（ICOPAY 统一）

端点: POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

请求头: Content-Type: application/json, Accept: application/json, X-Icopay-Merchant-Broker-Secret（强制校验 broker 密钥时必填）

必填 — 缺省则 prepare 以 ICOPAY BUYER_* 失败（不是第三方英文报错）

  • 表 1.1：compId 或 merchantId、orderNo、amount、buyer
  • 表 1.2：buyer.email、buyer.phone（本地号码，去掉 +国家码）、buyer.countryIso2（两位大写，如 KR、TH、JP）

空字符串视为缺失。响应包含 errorCode、messageKey 以及 5 语 messages（KOR/ENG/JPN/CHN/THA）。

表 1.1 — 请求体（JSON 根节点）

编号项目类型长度必填说明备注
1compIdString64M*商户企业代码*或 merchantId。由 ICOPAY 分配。
2merchantIdNumber—O商户组织 ID可替代 compId
3orderNoString64M订单/交易参考号建议字母数字、-、_，最长 64。
4amountNumber12M支付金额> 0。JPY/KRW 建议使用整数。
5currencyString3OISO 4217 货币USD, JPY, KRW, THB… 省略时使用商户基准货币。
6productNameString500O商品/订单说明显示于支付页
7itemString500OproductName 别名未提供 productName 时使用
8langString5O支付页 UI 语言KOR · ENG · JPN · CHN · THA（或 ko/en/ja/zh/th）
9buyerObject—M购买者联系信息及配送预填表 1.2 必填: email·phone·countryIso2（ICOPAY）。buyerPrefill 等效。

表 1.2 — buyer 对象

ICOPAY 必填(M): email、phone（本地号码，去掉 + 国家码）、countryIso2（ISO2 大写）。 卡号等由 ICOPAY 结账页采集。

编号项目类型长度必填说明备注
1emailString254M购买者邮箱必填。缺省 → BUYER_EMAIL_REQUIRED
2phoneString32M本地电话号码去除国家区号 +。缺省 → BUYER_PHONE_REQUIRED
3countryIso2String2M国家 ISO 3166-1 alpha-2例: KR, US, TH — 大写。缺省 → BUYER_COUNTRY_REQUIRED
4addressString200O配送地址第 1 行可选预填
5address2String200O配送地址第 2 行
6cityString100O城市
7stateString100O省/州
8postcodeString20O邮政编码zip 别名
9firstNameString80O名（持卡人预填）建议。支付页必填
10lastNameString80O姓（持卡人预填）建议。支付页必填
11shippingAddressString200O独立配送地址与 address 不同时使用
12shippingPhoneString32O独立配送电话

请求示例

{
  "compId": "M000123",
  "orderNo": "ORD-20260501001",
  "amount": 10000,
  "currency": "USD",
  "productName": "Sample product",
  "lang": "ENG",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR"
  }
}

errorCode（必填项）

errorCode含义
BUYER_REQUIRED缺少 buyer，或缺少 email/phone/countryIso2（含空字符串）
BUYER_EMAIL_REQUIRED缺少 buyer.email
BUYER_PHONE_REQUIRED缺少 buyer.phone
BUYER_COUNTRY_REQUIRED缺少或无效的 buyer.countryIso2
BUYER_JSON_INVALIDbuyer JSON 格式错误

对接方式

  • JSON — 商户服务器直接调用 REST。参见套件 integrationModes.json。
  • PHP — IcopayMerchantApi::prepareUnifiedCheckout() + checkout_unified.php。
