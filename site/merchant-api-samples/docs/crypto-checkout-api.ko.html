ICOPAY 크립토 Checkout API — 가맹 연동

Doc ID: ICOPAY-CRYPTO-CHECKOUT-001 · v1.0 · 2026-10-15 · ICOPAY neutral crypto

관련: 통합 Checkout 흐름 · Prepare 파라미터

1. 범위

이미 카드가 연동된 동일 가맹 MID에 크립토 결제를 추가합니다. 가맹·구매자 화면에는 항상 ICOPAY만 표시됩니다(PG명 미노출).

권장: 카드와 같은 통합 prepare에 payMeans=CRYPTO를 넣습니다. Callback/Result는 카드용 NOTI 등록분을 재사용합니다(Comp-Id 매칭).

2. 전제 (본사 설정)

항목비고
크립토 사용 = Y업체상세 또는 본사정책 → 결제·URL → 크립토설정
허용자산1차 오픈은 USDT만 권장
가맹 수취 지갑활성 자산마다 네트워크+주소 1세트(정산 출금용)
대표수탁지갑해당 자산×네트워크 ICOPAY 입금 주소
업체 사용 = Y미사용·영구정지면 크립토 차단

3. Prepare (권장)

POST {publicApiBaseUrl}/api/middleware/v1/merchant/checkout/prepare

헤더: Content-Type: application/json, X-Icopay-Merchant-Broker-Secret (카드와 동일 Live 시크릿).

{
  "compId": "6000000064",
  "orderNo": "ORD-CRYPTO-001",
  "amount": "10000",
  "displayCurrency": "JPY",
  "payMeans": "CRYPTO",
  "productName": "샘플 상품",
  "lang": "KOR",
  "buyer": {
    "email": "buyer@example.com",
    "phone": "1012345678",
    "countryIso2": "KR",
    "firstName": "Gildong",
    "lastName": "Hong"
  }
}
필드필수설명
payMeansM*CRYPTO (별칭: checkoutMeans / paymentMeans)
amountM표시금액 → ICOPAY가 USD 청구 후 자산 송금액 안내
displayCurrencyOJPY/USD 등. 생략 시 가맹 크립토 표시통화
assetCode / networkCodeO생략 가능 — 결제창에서 선택
buyer 성명·이메일M*성명·이메일 영문, 전화 숫자(결제창과 동일)

응답: pgVendor는 항상 ICOPAY. payUrl / sessionToken 사용. 크립토 세션은 cr_ 접두일 수 있습니다.

대체: POST /api/pay/crypto/prepare (compId 포함).

4. URL 채널 (비 API)

URL언제
크립토 결제 URL크립토 전용 (업체 크립토설정 카드)
/checkout-all/{compId}웹결제+크립토 사용 모두 ON일 때 통합(카드/크립토 선택)
/checkout/{compId}기존 카드 URL 결제

5. Callback / Result

ICOPAY 업체상세 「결제통보 URL」에 크립토 전용 Callback을 새로 등록하지 않습니다. 흐름: 입금 확정 → ICOPAY → POST /noti/crypto → NOTI가 Comp-Id로 기존 카드 callbackUrl에 릴레이.

기존 웹훅 핸들러를 확장하세요.

  • orderid / orderNo로 주문 매칭
  • 멱등 성공 처리 (JPAY 호환 returncode 등)
  • 추가 필드: assetCode, networkCode, depositTxHash
  • pgKind/van이 crypto이면 결제수단=크립토로 저장

상태 조회: GET .../merchant/checkout/status 또는 GET /api/pay/crypto/status.

6. 오픈 전 체크리스트

  • 본사 크립토 사용·자산·수탁·가맹 수취 설정
  • prepare(payMeans=CRYPTO) → payUrl → 소액 입금 → 크립토내역 확정
  • 기존 Callback으로 수신·크립토 필드 저장
  • 카드 결제 회귀 정상
